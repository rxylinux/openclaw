# 量化策略

## 目录说明

本目录用于记录和整理量化投资策略相关内容。

## 建议子目录

```
量化策略/
├── 策略设计/          # 策略构思和设计文档
├── 回测报告/          # 历史回测结果
├── 实盘记录/          # 实盘交易记录
├── 因子研究/          # 因子挖掘和分析
├── 风险控制/          # 风险管理策略
├── 代码实现/          # Python/其他代码
└── 策略优化/          # 参数优化和改进
```

## 使用建议

1. 每个策略单独一个文件夹
2. 命名格式：`策略类型-策略名称-创建日期`
3. 包含完整的文档：设计、回测、实盘
4. 定期复盘和更新
