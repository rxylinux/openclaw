# 财务指标计算和解读

## 利润表指标

### 营收增长率

**公式**：
```
营收增长率 = (本期营收 - 上期营收) / 上期营收 × 100%
```

**判断标准**：
| 增长率 | 评价 |
|-------|------|
| > 20% | 高增长 |
| 10-20% | 健康增长 |
| 0-10% | 低增长 |
| < 0% | 负增长 |

### 毛利率

**公式**：
```
毛利率 = (营收 - 营业成本) / 营收 × 100%
```

**解读**：
- 反映产品定价权和成本控制能力
- 行业差异大，需同行业对比

**典型行业毛利率**：
| 行业 | 典型毛利率 |
|-----|----------|
| 软件SaaS | 70-90% |
| 医药 | 60-80% |
| 消费电子 | 30-50% |
| 零售 | 20-35% |
| 超市 | 15-25% |

### 营业利润率

**公式**：
```
营业利润率 = 营业利润 / 营收 × 100%
```

**解读**：
- 反映主营业务盈利能力
- 排除一次性损益影响

### 净利率

**公式**：
```
净利率 = 净利润 / 营收 × 100%
```

**判断标准**：
| 净利率 | 评价 |
|-------|------|
| > 20% | 优秀 |
| 10-20% | 良好 |
| 5-10% | 一般 |
| < 5% | 较低 |

## 资产负债表指标

### 流动比率

**公式**：
```
流动比率 = 流动资产 / 流动负债
```

**判断标准**：
| 比率 | 评价 |
|-----|------|
| > 2.0 | 很强 |
| 1.5-2.0 | 良好 |
| 1.0-1.5 | 一般 |
| < 1.0 | 风险 |

### 速动比率

**公式**：
```
速动比率 = (流动资产 - 存货) / 流动负债
```

**解读**：
- 比流动比率更严格
- 排除存货变现风险

### 资产负债率

**公式**：
```
资产负债率 = 总负债 / 总资产 × 100%
```

**判断标准**：
| 比率 | 评价 |
|-----|------|
| < 40% | 健康 |
| 40-60% | 适中 |
| 60-80% | 较高 |
| > 80% | 危险 |

### 商誉占比

**公式**：
```
商誉占比 = 商誉 / 总资产 × 100%
```

**风险阈值**：
- > 30%：高风险，需关注减值风险
- 20-30%：中等风险
- < 20%：正常

## 现金流量表指标

### 自由现金流

**公式**：
```
自由现金流 = 经营现金流 - 资本开支
```

**解读**：
- 正值：公司有现金用于分红、回购、还债
- 负值：可能处于投资扩张期

### FCF利润率

**公式**：
```
FCF利润率 = 自由现金流 / 营收 × 100%
```

**判断标准**：
| 利润率 | 评价 |
|-------|------|
| > 15% | 优秀 |
| 10-15% | 良好 |
| 5-10% | 一般 |
| < 5% | 偏低 |

### 经营现金流/净利润

**公式**：
```
OCF/净利润 = 经营现金流 / 净利润
```

**判断标准**：
| 比值 | 评价 |
|-----|------|
| > 1.2 | 优秀 |
| 1.0-1.2 | 良好 |
| 0.8-1.0 | 一般 |
| < 0.8 | 差 |

## 盈利质量指标

### GAAP vs Non-GAAP 差异

**公式**：
```
差异率 = (Non-GAAP - GAAP) / GAAP × 100%
```

**常见调整项**：
- 股票补偿（合理）
- 重组费用（合理）
- 资产减值（需警惕）
- "一次性"项目（需警惕）

## 效率指标

### 应收账款周转天数（DSO）

**公式**：
```
DSO = (应收账款 / 营收) × 365
```

**判断标准**：
| DSO | 评价 |
|-----|------|
| < 30天 | 优秀 |
| 30-45天 | 良好 |
| 45-60天 | 一般 |
| > 60天 | 需关注 |

### 存货周转天数（DIO）

**公式**：
```
DIO = (存货 / 营业成本) × 365
```

**判断标准**：
| DIO | 评价 |
|-----|------|
| < 30天 | 优秀 |
| 30-60天 | 良好 |
| 60-90天 | 一般 |
| > 90天 | 需关注 |

## 股东回报指标

### ROE（净资产收益率）

**公式**：
```
ROE = 净利润 / 股东权益 × 100%
```

**判断标准**：
| ROE | 评价 |
|-----|------|
| > 20% | 优秀 |
| 15-20% | 良好 |
| 10-15% | 一般 |
| < 10% | 偏低 |

**杜邦分析**：
```
ROE = 净利率 × 资产周转率 × 权益乘数
```

### 股息收益率

**公式**：
```
股息收益率 = 年度股息 / 股价 × 100%
```

### 股息支付率

**公式**：
```
股息支付率 = 年度股息 / 净利润 × 100%
```

**判断标准**：
| 支付率 | 可持续性 |
|-------|---------|
| < 50% | 可持续 |
| 50-70% | 需关注 |
| 70-100% | 风险 |
| > 100% | 不可持续 |
