## 使用指南

### 如何记录新交易

1. 复制上面的"新交易记录模板"
2. 在相应的年份/月份文件夹中创建新的 markdown 文件
3. 填写所有相关字段
4. 坚持在买入时立即记录投资逻辑
5. 在卖出后及时进行执行复盘

### 如何复盘现有交易

1. 查阅相关交易记录文件
2. 对比预期目标和实际结果
3. 分析偏差原因
4. 记录经验教训
5. 更新相关策略和知识库

### 如何搜索历史交易

- 按股票代码搜索
- 按时间范围搜索
- 按策略类型搜索
- 按收益范围搜索
- 按复盘状态搜索
