# 美股完整股票拆解分析

## 概述

本技能提供美股上市公司**5维度专业投行级别分析**能力，包括：
- **第1步 —— 公司概览**：业务模式、收入来源拆分、核心竞争优势
- **第2步 —— 关键财务数据**：营收、净利润、估值指标、资产负债率、自由现金流、同比对比
- **第3步 —— 股价表现**：各时间段价格变动、52周高低点、与标普500对比
- **第4步 —— 华尔街一致预期**：分析师评级分布、目标价、最新评级调整
- **第5步 —— 机构资金动向**：前5大机构持仓、对冲基金动向

**核心原则**：
- ✅ 每个指标必须标注数据来源和日期
- ✅ 数据不可获取时明确说明，不估算或编造
- ✅ 数据超过30天时标记提示
- ✅ 使用清晰的Markdown标题结构和表格

## 快速开始

### 单股分析
当用户询问"分析一下苹果公司 AAPL"时：

1. **获取公司概览**：业务模式、收入来源、竞争优势
2. **获取财务数据**：营收、净利润、PE、PS、PEG等关键指标
3. **获取股价表现**：各时间段涨跌幅、52周高低点
4. **获取华尔街预期**：分析师评级、目标价
5. **获取机构动向**：机构持仓变化、对冲基金动向

## 核心能力

### 第1步 —— 公司概览

**核心目标**：
- 用通俗易懂的语言解释公司业务
- 说明业务模式和所有收入来源
- 按总收入百分比拆分收入结构
- 用一句话总结核心竞争优势

**必须包含的内容**：

→ **公司业务描述**：
- 用大白话解释这家公司是做什么的
- 避免金融术语，让小学生都能听懂
- 说明公司解决什么问题、谁为此付费、为什么客户选择它

→ **业务模式**：
- 主要业务模式说明（产品销售/服务订阅/平台/广告等）
- 各业务板块收入来源
- 按总收入百分比拆分各业务板块

→ **核心竞争优势**：
- 用一句话总结公司的核心竞争优势
- 说明为什么客户选择它而不是替代品

**输出模板示例**：

```
### 第1步 —— 公司概览

**公司业务**：
苹果公司是一家消费电子公司，主要卖手机、电脑、平板、手表这些设备，同时提供音乐、视频、云存储等服务。相当于你进了苹果店，从手机到耳机都能买到，还能订阅他们的音乐和视频服务。

客户主要是普通消费者（买iPhone、Mac的普通人）和企业客户（用iPhone、Mac办公的公司员工）。为什么选苹果？设备好用、系统流畅、设备之间互联方便，而且苹果品牌有面子。

**业务模式与收入来源**：
- iPhone销售（45%）：卖手机，最大收入来源
- 服务收入（22%）：App Store、Apple Music、iCloud、Apple TV+订阅
- Mac销售（12%）：卖笔记本电脑和台式机
- iPad销售（8%）：卖平板电脑
- 可穿戴设备（7%）：Apple Watch、AirPods
- 其他产品（6%）：Apple TV、HomePod、配件

**核心竞争优势**：
生态封闭但好用，设备之间无缝连接，品牌忠诚度极高，客户很少换安卓。
```

### 第2步 —— 关键财务数据

**核心目标**：
- 获取最新财务数据（TTM和最近季度）
- 每个数字标注来源和日期
- 计算同比变化
- 评估财务健康度

**必须包含的指标**：

→ **营收数据**：
- 营收（TTM，过去12个月）
- 营收（最近一个季度）
- 与去年同比对比

→ **利润数据**：
- 净利润（TTM）
- 净利润（最近季度）
- 每股收益EPS（TTM）
- 每股收益EPS（最近季度）

→ **估值指标**：
- 市盈率P/E（当前）
- 预期市盈率Forward P/E
- 市销率P/S
- PEG比率

→ **财务健康指标**：
- 资产负债率Debt-to-Equity
- 总债务
- 自由现金流（TTM）

**数据来源要求**：
- 每个指标后标注：来源（如Yahoo Finance、公司财报）+ 日期
- 示例：`营收：$3833亿（来源：Yahoo Finance，日期：2025-02-20）`
- 如果数据超过30天，标注：⚠️ 数据超过30天，可能已过期

**输出模板示例**：


## 数据获取方式

本技能使用以下数据源获取美股信息：

### 主要数据源

1. **Yahoo Finance**：股价、财务数据、估值指标
2. **SEC EDGAR**：公司财报、13F机构持仓文件
3. **TipRanks/Bloomberg**：分析师评级、目标价
4. **公司官网**：最新财报、投资者关系资料

### 搜索策略

- 使用 `mcp__web-search-prime__webSearchPrime` 搜索最新财务数据和新闻
- 使用 `mcp__web-reader__webReader` 获取SEC文件和公司财报详细信息
- 优先使用最近30天内的数据
- 数据超过30天时标注⚠️提示

## 注意事项

1. **数据来源标注**：每个指标后必须标注来源和日期

5. **合规要求**：不构成投资建议，仅作信息整理和分析
6. **数据验证**：多来源交叉验证关键数据
