# 公众号文章获取和定时推送需求

## 📋 需求概述

### 需求 1：公众号推送文章获取
**目标**：能够获取公众号的文章内容，用于推送

**可能的方案**：
1. **第三方 API**（新榜、即刻、知乎等）
   - 优点：稳定、有官方文档
   - 缺点：可能有费用、API 限制

2. **爬取方式**（浏览器自动化）
   - 优点：免费、无限制
   - 缺点：需要反爬虫、维护成本高

3. **RSS/订阅源**（如果公众号提供）
   - 优点：最简单、自动更新
   - 缺点：不是所有公众号都提供

---

### 需求 2：定时获取指定公众号文章
**目标**：每天固定时间获取指定公众号的最新文章，整理发给我

**功能要求**：
- 定时触发（如每天 8:00）
- 支持多个公众号
- 获取最新文章列表
- 整理成易读的格式
- 发送给用户

---

## 🔍 需要确认的信息

### 关于公众号
1. **目标公众号**：
   - 是科技类的公众号吗？
   - 有具体名称吗？（如：新智元、机器之心、量子位等）
   - 需要支持多个公众号吗？

2. **文章要求**：
   - 需要文章内容本身还是只要标题和链接？
   - 需要图片吗？
   - 需要作者和时间吗？

3. **获取频率**：
   - 每天几次？
   - 具体时间？（如 8:00, 12:00, 20:00）

4. **推送方式**：
   - 通过飞书？
   - 还是保存到文件？

---

## 🎯 推荐的技术方案

### 方案 A：使用新榜 API（推荐）
**流程**：
```
获取文章列表 → 获取文章内容 → 整理成 Markdown → 发送给用户
```
- 优点：稳定、有官方文档
- 缺点：需要 API 密钥、有限流

### 方案 B：爬取 + 代理池
**流程**：
```
使用浏览器自动化 + 代理轮换 → 获取文章 → 整理 → 发送给用户
```
- 优点：免费、无限制
- 缺点：需要维护代理、反爬虫策略
