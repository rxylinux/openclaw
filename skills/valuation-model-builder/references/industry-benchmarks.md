# 行业基准数据

## 市场风险溢价（Equity Risk Premium, ERP）

### 定义

市场风险溢价 = 市场预期收益率 - 无风险利率

### 权威数据来源

#### 1. Damodaran 数据（纽约大学）

**网址：** http://pages.stern.nyu.edu/~adamodar/

**常用数据：**

| 市场 | ERP | 更新日期 |
|------|-----|----------|
| 美国 | 5.0-6.0% | 每月更新 |
| 中国 | 7.0-8.0% | 每月更新 |
| 欧洲 | 4.5-5.5% | 每月更新 |
| 新兴市场 | 6.5-8.5% | 每月更新 |

**中国 ERP 特点：**
- 高于美国（新兴市场风险溢价）
- 波动性较大（市场成熟度低）
- 长期平均约 7.5%

#### 2. 本地市场数据

**计算方法：**
```
市场风险溢价 = 市场历史平均收益率 - 无风险利率
```

**中国市场历史数据（2000-2023）：**
- 上证综指平均年化收益率：约 8-10%
- 无风险利率（10 年国债）：约 3-4%
- 计算得到的 ERP：约 5-7%

**选择建议：**
- 优先使用 Damodaran 最新数据
- 如无数据，使用本地市场历史平均
- 考虑市场情绪调整（牛市/熊市）

### 使用原则

1. **优先使用权威来源**
   - Damodaran 数据为首选
   - 券商研究次选

2. **根据市场选择**
   - 美股公司：使用美国 ERP
   - A 股公司：使用中国 ERP
   - 跨国公司：加权平均

3. **考虑时间因素**
   - 使用最新数据（每月更新）
   - 避免使用过时数据（超过 6 个月）

## 无风险利率（Risk-Free Rate）

### 定义

无风险利率 = 完全无风险投资的收益率

### 选择标准

1. **主权信用高**
   - 政府违约概率接近零

2. **流动性好**
   - 交易活跃，买卖价差小

3. **期限匹配**
   - 与估值期限相近

### 常用数据来源

#### 1. 美国 10 年期国债收益率

**数据来源：**
- 美联储官网：https://www.federalreserve.gov/
- 美国财政部：https://www.treasury.gov/
- Yahoo Finance：https://finance.yahoo.com/

**当前水平（2024-2025）：**
- 范围：4.0-4.5%
- 影响因素：美联储利率政策、通胀预期

#### 2. 中国 10 年期国债收益率

**数据来源：**
- 中国人民银行官网：http://www.pbc.gov.cn/
- 中央国债登记结算公司：https://www.chinabond.com.cn/
- 东方财富：https://data.eastmoney.com/bond/

**当前水平（2024-2025）：**
- 范围：2.5-3.0%
- 影响因素：中国货币政策、经济增速

#### 3. 其他市场

| 市场 | 数据来源 | 当前水平 |
|------|----------|----------|
| 欧元区 | 欧洲央行 | 2.5-3.0% |
| 日本 | 日本央行 | 0.5-1.0% |
| 英国 | 英国央行 | 3.5-4.0% |

### 使用原则

1. **匹配估值货币**
   - 人民币估值 → 中国国债
   - 美元估值 → 美国国债

2. **使用 10 年期国债**
   - 标准做法
   - 平衡短期波动和长期稳定

3. **使用最新数据**
   - 每日更新
   - 避免使用过时数据

## Beta 系数

### 定义

Beta = 衡量股票相对于市场的波动性

### Beta 的含义

- **Beta = 1.0**：与市场波动相同
- **Beta > 1.0**：比市场波动大（高波动性）
- **Beta < 1.0**：比市场波动小（低波动性）

### Beta 范围与行业特征

#### 低 Beta（0.3-0.7）

**典型行业：**
- 公用事业（电力、水务、燃气）
- 消费必需品（食品、饮料、日用品）
- 基础设施（高速公路、机场）

**特点：**
- 防御性强，经济下行影响小
- 现金流稳定，风险低
- 增长缓慢

#### 中等 Beta（0.7-1.2）

**典型行业：**
- 制造业（汽车、机械、化工）
- 银行
- 保险
- 零售

**特点：**
- 周期性适中
- 受经济影响中等
- 现金流相对稳定

#### 高 Beta（1.2-2.0+）

**典型行业：**
- 科技（互联网、软件、半导体）
- 早期成长公司
- 新能源
- 生物医药

**特点：**
- 高成长预期
- 高风险高回报
- 经济敏感性强

### 数据来源

#### 1. Bloomberg

**特点：**
- 最权威的金融数据平台
- 提供调整后 Beta（去除短期波动）
- 全球覆盖

**获取方式：**
- 机构订阅（昂贵）

**获取方式：**

#### 3. Yahoo Finance

**网址：** https://finance.yahoo.com/

**特点：**
- 免费
- 数据质量中等
- 提供 Beta 数据

**获取方式：**

- 查看 "数据" → "Beta"

### Beta 调整

#### 为什么要调整？

原始 Beta 可能包含短期噪音，需要平滑处理。

#### 调整方法（Blume 方法）

```
调整后 Beta = 2/3 × 原始 Beta + 1/3
```

**示例：**
- 原始 Beta = 1.5
- 调整后 Beta = 2/3 × 1.5 + 1/3 = 1.33

#### 何时需要调整？

- 原始 Beta 数据波动大
- 公司近期发生重大事件（并购、重组）
- Beta 远离 1.0

### 无杠杆 Beta（Unlevered Beta）

#### 定义

无杠杆 Beta = 去除资本结构影响的 Beta

#### 计算公式

```
无杠杆 Beta = 有杠杆 Beta / [1 + (1 - 税率) × (债务/权益)]
```

#### 使用场景

1. **可比公司 Beta 调整**
   - 当可比公司资本结构不同时
   - 需要统一到目标公司资本结构

2. **目标公司 Beta 估算**
   ```
   目标公司有杠杆 Beta = 无杠杆 Beta × [1 + (1 - 税率) × (债务/权益)]
   ```

#### 示例

**可比公司 Beta：**
- 可比公司 A：Beta = 1.2，债务/权益 = 0.3
- 可比公司 B：Beta = 1.5，债务/权益 = 0.5
- 可比公司 C：Beta = 1.0，债务/权益 = 0.2

**步骤 1：计算无杠杆 Beta**
```
无杠杆 Beta A = 1.2 / [1 + (1 - 25%) × 0.3] = 1.05
无杠杆 Beta B = 1.5 / [1 + (1 - 25%) × 0.5] = 1.15
无杠杆 Beta C = 1.0 / [1 + (1 - 25%) × 0.2] = 0.89
```

**步骤 2：平均无杠杆 Beta**
```
平均无杠杆 Beta = (1.05 + 1.15 + 0.89) / 3 = 1.03
```

**步骤 3：调整到目标公司资本结构**
```
目标公司 Beta = 1.03 × [1 + (1 - 25%) × 0.4] = 1.34
```

## 企业所得税率

### 中国标准税率

- **标准税率**：25%
- **高新技术企业**：15%
- **小型微利企业**：20%（有优惠）

### 高新技术企业认定

**标准：**
- 拥有核心自主知识产权
- 研发费用占比符合要求
- 高新技术产品收入占比 ≥ 60%
- 其他指标符合规定

### 各行业实际税率

| 行业 | 实际税率范围 | 说明 |
|------|--------------|------|
| 银行 | 20-25% | 税收优惠少 |
| 保险 | 15-25% | 部分公司有优惠 |
| 互联网 | 10-20% | 高新技术企业多 |
| 制造业 | 15-25% | 部分高新技术企业 |
| 零售 | 20-25% | 税收优惠少 |
| 公用事业 | 15-25% | 部分有优惠 |

### 使用原则

1. **优先使用公司实际税率**
   - 来源：公司财报
   - 计算：所得税费用 / 税前利润

2. **多年度平均**
   - 使用 3-5 年平均实际税率
   - 平滑年度波动

3. **考虑未来变化**
   - 高新技术资格到期
   - 税收政策变化

## 资本成本行业差异

### 各行业 WACC 典型范围

| 行业 | WACC 范围 | 说明 |
|------|-----------|------|
| 公用事业 | 5-7% | 低风险，Beta 低 |
| 消费必需品 | 6-8% | 低风险，稳定现金流 |
| 银行 | 6-9% | 监管严格，资本要求高 |
| 保险 | 7-10% | 风险中等 |
| 地产 | 8-12% | 周期性强，风险高 |
| 制造业 | 8-11% | 周期性强 |
| 消费非必需品 | 9-12% | 周期性较强 |
| 医药 | 10-14% | 研发风险高 |
| 半导体 | 10-15% | 技术风险高 |
| 互联网 | 12-18% | 高风险高增长 |
| 早期科技 | 15-25% | 极高风险 |

### 影响因素

1. **Beta 系数**
   - Beta 高 → WACC 高

2. **债务成本**
   - 信用评级好 → 债务成本低

3. **资本结构**
   - 债务占比高 → WACC 可能降低（但风险增加）

4. **行业风险**
   - 行业稳定性 → 影响风险溢价
