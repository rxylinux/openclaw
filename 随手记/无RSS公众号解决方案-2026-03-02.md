## 🏆 最佳方案：wewe-rss (推荐)

### 为什么推荐？

1. **基于微信读书** - 比直接爬取公众号更稳定
2. **v2.x 新接口** - 更加稳定，避免频繁失效
3. **完全免费** - 开源项目，无任何费用
4. **Docker一键部署** - 3分钟搞定
5. **完全自动化** - 扫码后自动更新（30分钟一次）

### GitHub 项目

https://github.com/cooderl/wewe-rss

### 核心功能

- ✅ 微信公众号订阅（基于微信读书）
- ✅ 获取公众号历史发布文章
- ✅ 后台自动定时更新内容（每30分钟）
- ✅ 微信公众号RSS生成（支持 .atom、.rss、.json格式）
- ✅ 支持全文内容输出，让阅读无障碍
- ✅ 所有订阅源导出OPML
- ✅ 标题过滤支持

### Docker 部署（SQLite版本 - 最简单）

```bash
# 1. 拉取镜像
docker pull cooderl/wewe-rss-sqlite:latest

# 2. 创建数据目录
mkdir -p ~/wewe-rss/data
chmod 755 ~/wewe-rss/data

# 3. 启动容器
docker run -d \
  --name wewe-rss \
  -p 4000:4000 \
  -e DATABASE_TYPE=sqlite \
  -e AUTH_CODE=your_secure_password_here \
  -v ~/wewe-rss/data:/app/data \
  --restart unless-stopped \
  cooderl/wewe-rss-sqlite:latest
```

### 配置说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `DATABASE_TYPE` | 数据库类型 | sqlite |
| `AUTH_CODE` | 访问授权码（必填） | 无 |
| `FEED_MODE` | 输出模式 | fulltext |
| `CRON_EXPRESSION` | 定时更新表达式 | `35 5,17 * * *` |
| `MAX_REQUEST_PER_MINUTE` | 每分钟最大请求数 | 60 |

### 部署后操作

1. **访问管理界面**
   ```
   http://your-server-ip:4000
   ```

2. **扫码授权**
   - 在"账号管理"中添加微信读书账号
   - 扫码登录（建议用小号）
   - 授权后自动获取公众号内容

3. **添加公众号订阅**
   - 复制任意一篇文章链接
   - 在"订阅管理"中粘贴链接
   - 系统自动识别公众号ID

4. **获取RSS地址**
   ```
   # 单个公众号
   http://your-server-ip:4000/feeds/MP_WXS_123.rss

   # 全部订阅（OPML导出）
   http://your-server-ip:4000/feeds/all.rss

   # JSON格式
   http://your-server-ip:4000/feeds/all.json
   ```

## 🥈 备选方案：we-mp-rss (WeRSS)

### GitHub 项目

https://github.com/rachelos/we-mp-rss

### Docker 部署

```bash
# 1. 拉取镜像
docker pull ghcr.io/rachelos/we-mp-rss:latest

# 2. 创建数据目录
mkdir -p ~/we-mp-rss/data
chmod 755 ~/we-mp-rss/data

# 3. 启动容器
docker run -d \
  --name we-mp-rss \
  -p 8001:8001 \
  -e DB="sqlite:////app/data/we_mp_rss.db" \
  -e USERNAME=admin \
  -e PASSWORD=your_secure_password_here \
  -v ~/we-mp-rss/data:/app/data \
  --restart unless-stopped \
  ghcr.io/rachelos/we-mp-rss:latest
```

### 访问管理界面

```
http://your-server-ip:8001
用户名: admin
密码: your_secure_password_here
```

## 🔧 集成到你的工作流

### 方案 1：直接调用 RSS API

```python
import feedparser

# 获取 wewe-rss 的RSS
rss_url = "http://localhost:4000/feeds/all.rss"

# 读取RSS
feed = feedparser.parse(rss_url)

# 遍历文章
for entry in feed.entries:
    print(entry.title)
    print(entry.link)
    print(entry.published)
```

### 方案 2：集成到 tech-rss-fetcher.py

修改 `tech-rss-fetcher.py`，添加自定义RSS源：

```python
# 添加自定义公众号RSS
custom_rss_sources = [
    {
        'name': '你的公众号',
        'url': 'http://localhost:4000/feeds/MP_WXS_123.rss',
        'category': '自定义',
        'description': '从wewe-rss获取',
        'limit': 5
    }
]

# 合并到现有RSS源
self.rss_sources.extend(custom_rss_sources)
```

## 💡 最佳实践建议

### 1. 使用小号授权
- 避免主微信号被封风险
- 建议注册专门的微信读书账号

### 2. 定期检查授权状态
- 微信读书授权可能过期
- 建议每周检查一次

### 3. 备份RSS列表
- 导出OPML文件
- 保存到本地

### 4. 多个服务互备
- wewe-rss + we-mp-rss 双保险
- 一个失效，另一个顶上
