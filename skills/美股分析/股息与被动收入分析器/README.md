# 股息与被动收入分析器

## 概述

股息与被动收入分析器提供**股息投资分析**能力，系统评估公司股息价值和复利收益。

## 核心特性

- ✅ **股息概况**：股息率、发放频率、除息日
- ✅ **增长记录**：CAGR、连续增长、股息贵族
- ✅ **可持续性**：派息率、FCF覆盖、债务风险
- ✅ **行业对比**：同行股息指标
- ✅ **收入预测**：5/10/20年复利预测
- ✅ **风险评估**：削减风险、危险区距离

## 股息贵族标准

- 股息贵族：连续25年增长
- 股息之王：连续50年增长
- 股息冠军：10年+5%年均增长

## 注意事项

1. 每个指标标注来源
2. 不估算股息率
3. [ASSUMPTION]标注假设
4. 展示计算过程
5. 不构成投资建议
