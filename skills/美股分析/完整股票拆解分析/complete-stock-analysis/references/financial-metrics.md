# 财务指标解释

## 估值指标

### 市盈率 P/E (Price-to-Earnings Ratio)
- **定义**: 股价 / 每股收益 (EPS)
- **含义**: 投资者愿意为每1美元收益支付的倍数
- **解读**: 越高可能表示高增长预期或高估；越低可能表示价值投资或低估
- **正常范围**: 行业差异大，通常15-25为合理

### 预期市盈率 Forward P/E
- **定义**: 股价 / 预期下一年每股收益
- **含义**: 基于未来预期的估值倍数
- **用途**: 比 P/E 更具前瞻性

### 市销率 P/S (Price-to-Sales Ratio)
- **定义**: 市值 / 营收
- **用途**: 适用于亏损公司或成长型公司
- **解读**: 越低通常越便宜

### PEG 比率 (Price/Earnings-to-Growth Ratio)
- **定义**: P/E / 预期盈利增长率 (%)
- **含义**: 将增长率纳入考虑的估值指标
- **解读**:
  - PEG = 1: 估值合理
  - PEG < 1: 可能低估
  - PEG > 1: 可能高估

## 盈利指标

### 每股收益 EPS (Earnings Per Share)
- **基本 EPS**: (净利润 - 优先股股息) / 加权平均普通股数量
- **稀释 EPS**: 考虑所有可转换证券后的 EPS（更保守）

### 自由现金流 FCF (Free Cash Flow)
- **定义**: 经营现金流 - 资本支出
- **含义**: 公司可自由支配的现金
- **用途**: 评估公司产生现金的能力、分红能力、偿债能力

## 财务健康指标

### 资产负债率 Debt-to-Equity
- **定义**: 总负债 / 股东权益
- **含义**: 公司财务杠杆水平
- **解读**:
  - < 0.5: 低杠杆
  - 0.5 - 1.0: 中等杠杆
  - > 1.0: 高杠杆（高风险）
- **注意**: 资本密集型行业（公用事业、金融）通常有更高 D/E

### 总债务 Total Debt
- **短期债务**: 一年内到期的债务
- **长期债务**: 一年后到期的债务

## 股价表现指标

### 52周区间
- **52周最高价**: 过去52周的最高交易价
- **52周最低价**: 过去52周的最低交易价
- **位置**: (当前价 - 最低价) / (最高价 - 最低价)

### 相对强弱 Relative Strength
- **定义**: 股票表现 vs 基准指数（如标普500）
- **计算**: 股票涨跌幅 - 指数涨跌幅
- **解读**: 正值表示跑赢指数，负值表示跑输指数

## 分析师指标

### 评级分类
| 评级 | 含义 |
|------|------|
| 买入 Buy | 预期跑赢大盘，强烈推荐 |
| 持有 Hold | 预期与大盘表现持平 |
| 卖出 Sell | 预期跑输大盘，建议回避 |

### 目标价 Target Price
- **平均目标价**: 所有分析师目标价的算术平均
- **价格空间**: (平均目标价 - 当前价) / 当前价

## 机构指标

### 机构持仓
- **占流通盘比例**: 机构持股数 / 总流通股数
- **变动**: 本季度持股数 vs 上季度持股数

### 13F 文件
- **提交频率**: 季度（季度结束后45天内）
- **内容**: 机构持仓披露（管理资产超过1亿美元的机构）
- **注意**: 存在滞后性，通常1.5个月延迟

## 时间周期说明

### 财务报告周期
- **Q1**: 1-3月，5月15日前提交10-Q
- **Q2**: 4-6月，8月14日前提交10-Q
- **Q3**: 7-9月，11月14日前提交10-Q
- **Q4/年报**: 10-12月，2月28日前提交10-K
- **TTM**: 过去12个月（滚动计算）

### 股价表现周期
- **YTD (Year-to-Date)**: 当年1月1日至今
- **1个月/3个月/6个月/1年**: 回溯对应时间窗口
