# 竞争格局分析指南

## 核心目标

找出谁是这个行业的玩家，这家公司混得怎么样，谁强谁弱，为什么。

## 分析四维

### 1. 竞争对手都有谁？

**要找的数据**:
- 行业前5-10大公司
- 各家公司市场份额
- 各家业务范围（是否直接竞争）

**列对手方法**:
- 搜索"行业排名 龙头"
- 搜索"行业格局 市场份额"
- 搜索"行业主要玩家"

**输出要求**:
- 列出3-5家主要对手
- 标注每家的市场份额（如有）
- 说明是否直接竞争（卖同样的东西）

### 2. 定价权谁更牛？

**判断标准**:

| 特征 | 定价权强 | 定价权弱 |
|------|----------|----------|
| 能涨价 | 想涨就涨，客户照买 | 涨价客户就跑 |
| 不降价 | 价格战能扛住 | 被迫降价求活 |
| 利润率 | 毛利率>40% | 毛利率<20% |
| 客户粘性 | 客户不轻易换 | 客户谁便宜选谁 |

**判断方法**:
- 毛利率对比（谁的高就是定价权强）
- 价格战表现（谁敢不降价）
- 客户复购率（谁的老客户多）

**输出模板**:
```
定价权排序（从强到弱）:
1. 公司A - 毛利率60%，敢涨价客户不离
2. 公司B - 毛利率45%，价格战不太跟
3. 本公司 - 毛利率30%，勉强抗住
4. 公司C - 毛利率15%，被迫降价求活
```

### 3. 产品实力谁更强？

**对比维度**:

| 维度 | 评价方法 | 数据来源 |
|------|----------|----------|
| 技术水平 | 专利数、研发投入占比 | 财报+专利数据库 |
| 产品质量 | 客户投诉率、退货率 | 新闻+消费者报告 |
| 产品丰富度 | 产品线数量、覆盖场景 | 公司官网+产品目录 |
| 创新速度 | 新品上市频率、技术迭代周期 | 新闻+产品发布历史 |
| 成本控制 | 毛利率、生产效率 | 财报数据 |

**输出要求**:
- 用雷达图或表格对比各家公司
- 标注每家的优势领域（技术/成本/质量/丰富度）
- 指出谁家产品领先，谁家落后

**对比模板**:
```
产品实力对比:

| 维度 | 本公司 | 对手A | 对手B | 对手C |
|------|--------|-------|-------|-------|
| 技术水平 | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| 成本控制 | ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐ | ⭐⭐⭐⭐ |
| 产品丰富度 | ⭐⭐ | ⭐⭐⭐ | ⭐⭐ | ⭐⭐⭐ |
| 创新速度 | ⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ | ⭐⭐ |

结论:
- 对手A技术最强，专利最多 ✅
- 本公司成本控制最好，毛利率最高 ✅
- 对手C产品最丰富，覆盖面最广 ✅
```

### 4. 规模谁更大？

**对比指标**:

| 指标 | 意义 | 数据来源 |
|------|------|----------|
| 营收规模 | 谁卖得更多 | 财报 |
| 市场份额 | 谁占的更大 | 行业研报 |
| 产能规模 | 谁能造更多 | 公司公告 |
| 员工人数 | 谁的团队更大 | 年报 |
| 客户数量 | 谁的客户更多 | 年报/访谈 |

**输出要求**:
- 排出营收规模榜（Top 5）
- 说明市场份额分布（CR3/CR5）
- 标注谁是老大、谁是老二

**排名模板**:
```
规模排名:

| 排名 | 公司 | 营收 | 市场份额 | 增速 |
|------|------|------|----------|------|
| 1 | 对手A | 1000亿 | 30% | +15% |
| 2 | 本公司 | 800亿 | 24% | +20% |
| 3 | 对手B | 600亿 | 18% | +10% |
| 4 | 对手C | 500亿 | 15% | +5% |

结论: 本公司行业老二，规模排第二，但增速第一
```

### 5. 竞争壁垒谁更硬？

**壁垒类型判断**:

| 壁垒类型 | 典型案例 | 强/弱判断方法 |
|----------|----------|--------------|
| **技术壁垒** | 光刻机、芯片设计 | 专利数、研发投入、技术门槛 |
| **规模壁垒** | 台积电、京东 | 产能、网络效应、资本开支 |
| **渠道壁垒** | 茅台、可口可乐 | 销售网络、渠道控制力 |
| **品牌壁垒** | 爱马仕、LV | 品牌价值、客户忠诚度 |
| **资质壁垒** | 银行、医药 | 牌照、审批、认证 |
| **成本壁垒** | 拼多多、比亚迪 | 供应链整合、规模效应 |
| **网络效应** | 微信、淘宝 | 用户数量、生态完整性 |

**判断方法**:
- 看新进入者难度（这行还有新公司能进来吗？）
- 看被替代可能性（客户能轻易换别人家吗？）
- 看壁垒持续性（这壁垒能扛5年吗？）

**输出模板**:
```
竞争壁垒对比:

公司A:
- 技术壁垒: ⭐⭐⭐⭐⭐ (专利5000+项，10年研发积累)
- 规模壁垒: ⭐⭐⭐⭐⭐ (产能全球第一)
- 渠道壁垒: ⭐⭐ (销售网络一般)

本公司:
- 技术壁垒: ⭐⭐⭐ (专利2000项，中等水平)
- 规模壁垒: ⭐⭐⭐ (产能行业前三)
- 渠道壁垒: ⭐⭐⭐⭐⭐ (覆盖全国)

结论:
- 对手A技术+规模双壁垒，很难撼动 🏰️
- 本公司渠道强，能快速铺货，但技术落后 ⚠️
```

### 评分解读

| 总分 | 竞争地位 | 解释 |
|------|----------|------|
| 40-50分 | 🏆 领导者 | 多维度领先，压制对手 |
| 35-39分 | 🥈 强者 | 2-3个维度领先 |
| 30-34分 | 🥉 中游 | 有优势有短板，混得下去 |
| 25-29分 | 📊 追赶者 | 整体落后，局部突围 |
| 0-24分 | 📉 落后者 | 多维度被压制 |

## 数据获取建议

### 搜索关键词

**行业格局**:
- `<行业> 市场格局 市场份额`
- `<行业> 龙头 对比 排名`
- `<行业> 竞争对手 分析`

**竞对信息**:
- `<竞对公司名> 市场份额 业务`
- `<竞对公司名> 竞争优势 劣势`

**对比数据**:
- `<行业> 毛利率 定价权 对比`
- `<行业> 研发投入 技术实力`
- `<行业> 产能规模 排名`

### 查阅来源

- 行业研报（券商深度分析、格局判断）
- 公司年报（管理层讨论与竞争章节）
- 新闻媒体（行业报道、竞争事件）
- 上市公司公告（重大合作、并购、诉讼）
