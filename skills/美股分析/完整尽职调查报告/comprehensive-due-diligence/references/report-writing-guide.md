# 投行研究报告撰写指南

## 投行评级体系

### 评级定义标准

| 评级 | 定义 | 潜在回报 | 风险特征 | 适用场景 |
|------|------|----------|----------|----------|
| **Strong Buy** | 强烈买入 | > 20% | 风险可控，催化剂明确 | 强劲基本面 + 低估值 + 明确催化剂 |
| **Buy** | 买入 | 10% - 20% | 风险适中 | 基本面良好 + 合理估值 |
| **Hold** | 持有 | ±10% | 风险收益平衡 | 估值合理，等待催化剂 |
| **Underweight** | 低配 | 0% - 10% | 风险偏高 | 相对基准配置减少 |
| **Sell** | 卖出 | < 0% | 风险高 | 基本面恶化或估值过高 |
| **Strong Sell** | 强烈卖出 | < -10% | 风险极高 | 严重问题或显著高估 |

### 投资回报时间框架

- **短期：** 0-6 个月
- **中期：** 6-12 个月（标准投行时间框架）
- **长期：** 12-24 个月

## 目标价设定方法

### 方法一：DCF（现金流折现）

**适用场景：**
- 现金流稳定、可预测的公司
- 成熟行业
- 资本密集型行业

**优点：**
- 理论严谨
- 反映内在价值
- 考虑长期增长

**缺点：**
- 假设敏感
- 对高增长公司不确定性高
- 不适用于亏损公司

### 方法二：倍数法（相对估值）

**适用场景：**
- 可比公司充足的行业
- 盈利稳定的公司
- 快速估值

**常用倍数：**
- P/E（市盈率）- 最常用
- EV/EBITDA - 资本密集型
- P/B（市净率）- 金融业
- P/S（市销率）- 亏损或高增长公司
- FCF Yield（自由现金流收益率）

### 方法三：SOVP（分部加总）

**适用场景：**
- 多元化公司
- 不同业务板块估值差异大
- 部分可分拆价值

**方法：**
1. 将公司拆分为独立业务单元
2. 分别估值每个单元
3. 加总并减去企业层面成本
4. 调整现金和债务

### 方法四：混合方法

**最佳实践：**
- DCF（40%）+ 倍数法（40%）+ SOVP（20%）
- 加权平均
- 根据公司特点调整权重

## 报告撰写最佳实践

### 执行摘要写作

**要素：**
1. **投资逻辑** - 为什么这只股票值得投资
2. **关键催化剂** - 什么将推动股价
3. **风险提示** - 主要下行风险

**写作技巧：**
- 开篇直接点明核心论点
- 3 句话概括完整投资故事
- 避免技术术语，使用通俗语言

### 业务概览写作

**内容要素：**
- 公司做什么（通俗语言）
- 如何赚钱
- 规模和增长
- 竞争优势

**写作技巧：**
- 假设读者是聪明的投资者但非行业专家
- 使用类比帮助理解
- 聚焦关键差异化因素

### 财务分析写作

**关键要点：**
- 不仅列数字，要解释含义
- 对比同行和行业
- 识别趋势和拐点
- 强调异常或关键变化

**写作技巧：**
- 使用表格呈现数据
- 用文字解释"这意味着什么"
- 标注数据来源和日期

### 估值分析写作

**透明度原则：**
- 明确所有假设
- 说明假设依据
- 展示敏感性分析
- 提供 Bull/Base/Bear 情景

**写作技巧：**
- 用表格清晰展示
- 解释倍数选择理由
- 对比历史和同业

### 风险分析写作

**原则：**
- 诚实披露风险
- 量化风险可能影响
- 说明风险监测方法
- 避免淡化风险

**写作技巧：**
- 按重要性排序
- 提供缓解因素
- 区分公司特有和系统性风险

## 报告质量检查清单

### 数据完整性

- [ ] 所有财务指标有来源和日期
- [ ] 无未标注来源的数据
- [ ] 无估算或编造数据
- [ ] 前瞻性陈述标注 [ASSUMPTION]

### 分析质量

- [ ] 投资逻辑清晰
- [ ] 催化剂具体可识别
- [ ] 估值方法合理
- [ ] 风险识别全面
- [ ] 结论与论证一致

### 结构完整性

- [ ] 执行摘要完整
- [ ] 业务分析充分
- [ ] 财务分析深入
- [ ] 增长分析有依据
- [ ] 估值分析透明
- [ ] 风险分析全面
- [ ] 催化剂明确
- [ ] 结论明确

### 写作质量

- [ ] 语言清晰简洁
- [ ] 避免歧义
- [ ] 逻辑严密
- [ ] 专业但不晦涩
- [ ] 格式规范

## 常见错误避免

### 数据错误

1. **来源缺失：** 每个数据必须有来源
2. **日期不明：** 必须注明数据日期
3. **估算数据：** 不得估算或编造
4. **混淆数据：** GAAP vs 非 GAAP 必须区分

### 分析错误

1. **循环论证：** 结论需要独立证据支持
2. **选择性偏差：** 只关注支持性证据
3. **过度拟合：** 用过多假设达到目标价
4. **忽视风险：** 低估或忽略关键风险

### 写作错误

1. **模糊表述：** 避免可能、或许等词
2. **技术术语：** 不解释专业术语
3. **冗长累赘：** 不简洁直接
4. **格式混乱：** 结构不清晰

## 投行报告 vs 卖方报告 vs 买方报告

### 投行报告特点

**受众：** 机构投资者、对冲基金、资产管理

**特点：**
- 深度分析
- 数据详实
- 估值透明
- 风险全面
- 更新及时

### 卖方报告（券商）特点

**受众：** 散户、机构

**特点：**
- 倾向乐观
- 侧重催化剂
- 分析相对简洁
- 评级较多 Hold/Buy

### 买方报告特点

**受众：** 内部投资委员会

**特点：**
- 更为保守
- 风险敏感
- 注重下行保护
- 可能不公开

## 报告更新机制

### 触发更新的情况

1. **财报发布：** 季度/年度财报后更新
2. **重大事件：** 并购、重组、管理层变动
3. **行业变化：** 监管变化、技术突破
4. **目标价达成：** 股价触及目标价
5. **评级调整：** 基本面或估值变化

### 更新类型

- **Full Update：** 完整重写报告
- **Flash Update：** 快速更新关键数据
- **Rerating：** 仅调整评级
- **Price Target Update：** 仅调整目标价
