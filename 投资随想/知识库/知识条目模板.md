TXN 的业务模式具有以下特点：
1. 高毛利率：约 65-75%，由于专注于模拟和嵌入式芯片
2. 强大定价权：在特定细分市场有领先地位
3. 周期性需求：汽车和工业需求的周期性影响
4. 长期增长：受益于汽车电子化和工业自动化趋势

## 使用指南

### 如何创建新知识条目

1. 复制上面的模板
2. 根据知识类型填写相关信息
3. 保存到相应的分类目录：
   - 公司分析 → `知识库/公司分析/`
   - 行业分析 → `知识库/行业分析/`
   - 策略方法 → `知识库/策略方法/`
   - 市场洞察 → `知识库/市场洞察/`
   - 错误教训 → `知识库/错误教训/`

### 如何更新现有知识条目

1. 找到对应的知识条目文件
2. 在"最后更新"字段更新日期
3. 如有新信息，更新核心内容
4. 更新元数据中的相关信息

### 如何验证知识

1. 检查信息来源的可靠性
2. 对比多个数据源
3. 验证关键数据的准确性
4. 更新验证状态为"已验证"
