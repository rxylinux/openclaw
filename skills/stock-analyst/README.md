# 完整股票拆解分析 Skill

作为顶级投行高级股票研究分析师，生成完整的股票分析报告。

## 功能特性

### ✅ 严格的数据标注
- 每个指标都标注数据来源和日期
- 超过30天的数据会明确标记提示
- 不估算或编造任何数字

### 📊 完整的5步分析流程

#### 第1步——公司概览
- 用通俗易懂的语言解释公司业务
- 业务模式及所有收入来源（按总收入百分比拆分）
- 核心竞争优势总结

#### 第2步——关键财务数据
- **营收**（TTM及最近一个季度）
- **净利润和每股收益（EPS）**
- **估值比率**（P/E、Forward P/E、P/S、PEG）
- **资产负债率**（Debt-to-Equity）和总债务
- **自由现金流**（TTM）
- **与去年同期季度的同比对比**

#### 第3步——股价表现
- **价格变动**：1个月、3个月、6个月、1年、年初至今
- **52周最高价和最低价**
- **与标普500同期表现对比**

#### 第4步——华尔街一致预期
- **覆盖该股票的分析师数量**
- **买入/持有/卖出评级分布**
- **平均目标价、最高目标价、最低目标价**
- **最近一次分析师上调或下调评级**

#### 第5步——机构资金动向
- **前5大机构持仓者**及其上季度持仓变动情况
- **值得关注的对冲基金动向**（新建仓或清仓）

## 使用方法

### 基本使用

```bash
cd /root/.openclaw/workspace/skills/stock-analyst

# 分析股票（提供股票代码或公司名称）
python3 scripts/analyze.py --stock AAPL

# 保存报告到指定文件
python3 scripts/analyze.py --stock AAPL --output /path/to/report.md
```

### 参数说明

- `--stock`：股票代码（如AAPL）或公司名称（如Apple Inc.）
- `--output`：报告输出文件路径（可选，默认保存到临时目录）

## 数据来源

本Skill使用以下权威数据源：

| 数据源 | 用途 | 更新频率 |
|--------|------|---------|
| **Bloomberg** | 股价、估值比率、市场数据 | 实时 |
| **FactSet** | 华尔街一致预期、机构持仓 | 每日 |
| **SEC文件** | 财报、资产负债表、现金流量表 | 季度/年度 |

## 报告输出

报告采用清晰的Markdown结构，包含：

### 📋 内容结构

1. **标题部分**
   - 股票代码
   - 公司名称
   - 报告日期
   - 分析师信息

2. **免责声明**
   - 投资风险提示

4. **数据有效性说明**

   - 明确数据截止日期

## 合规说明

### ✅ 数据来源标注
- 每个指标都标注具体来源（Bloomberg、FactSet、SEC文件等）
- 每个数据都标注具体日期
- 超过30天的数据明确标记提示

### ✅ 不估算或编造
- 所有数据都来自公开数据源
- 不进行任何估算或预测（除非明确标注为"一致预期"）
- 数据不可获取时明确说明

### ✅ 数据有效期标记
- 数据超过30天时，显示警告图标 ⚠️
- 明确标注数据截止日期
- 标注数据是TTM还是最近季度

## 注意事项

### ⚠️ 数据时效性
- Bloomberg数据：实时更新，但某些指标可能有延迟
- FactSet数据：每日更新，但分析师评级可能有延迟
- SEC文件：季度或年度更新，数据可能过时

### ⚠️ 数据完整性
- 某些股票可能没有足够的历史数据
- 新上市公司的数据可能不完整
- 小盘股的机构覆盖可能不足

### ⚠️ 分析限制
- 本Skill仅基于公开数据进行分析
- 不考虑非公开信息（如内幕消息）
- 不考虑市场情绪和投资者心理因素
