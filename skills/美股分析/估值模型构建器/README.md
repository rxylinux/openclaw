# 估值模型构建器

## 概述

估值模型构建器提供**专业估值分析**能力，包括DCF、可比公司、历史对比、分析师目标价、情景分析。

## 核心特性

- ✅ **DCF模型**：完整计算、敏感性分析
- ✅ **可比公司**：同行估值对比
- ✅ **历史估值**：5年历史分析
- ✅ **分析师目标价**：华尔街共识
- ✅ **情景分析**：乐观/基准/悲观
