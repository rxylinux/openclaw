# 微信公众号文章获取 - 研究总结

## 📋 研究目标

寻找免费的、自动化的方案获取微信公众号文章，用于定时推送

---

## ❌ 已尝试的失败方案

### 1. 直接爬取微信公众号
- **问题**：反爬虫机制严格，需要登录态，URL 加密有时效性
- **结果**：无法持续获取

### 2. agent-browser 搜索
- **问题**：不支持微信搜索，返回 0 结果
- **结果**：无法使用

### 3. site:mp.weixin.qq.com 搜索
- **问题**：搜索引擎限制，搜索结果为空
- **结果**：无法通过搜索引擎获取

### 4. RSSHub (rsshub.app)
- **问题**：网络不可达，连接超时
- **结果**：无法访问

### 5. WeRss (werss.app)
- **问题**：需要扫码授权，无法在无人值守环境使用
- **结果**：无法自动化

---

## ✅ 成功方案：多平台 RSS 聚合

### 核心思路

**不直接获取微信公众号文章，而是从多个高质量 RSS 源获取相关内容**

## 📝 实现方案

### 核心脚本

**`/root/.openclaw/workspace/scripts/tech-rss-fetcher.py`**

功能：
- 获取 6 个 RSS 源的最新文章
- 格式化为 Markdown
- 保存到文件
- 支持定时推送

### 工作流程

```
定时任务（每天 8:00）
    ↓
tech-rss-fetcher.py 获取 RSS
    ↓
生成 Markdown 文件
    ↓
message-sender.py 拆分消息
    ↓
逐条推送到飞书
    ↓
更新 heartbeat-state.json
```

## 🔧 集成到定时任务

### Cron 配置

```bash
# 每天 8:00 和 20:00 获取科技 RSS 内容
0 8 * * * /root/.openclaw/workspace/scripts/fetch-tech-rss.sh >> /root/.openclaw/logs/tech-rss.log 2>&1
0 20 * * * /root/.openclaw/workspace/scripts/fetch-tech-rss.sh >> /root/.openclaw/logs/tech-rss.log 2>&1
```

### 推送脚本

**`/root/.openclaw/workspace/scripts/fetch-tech-rss.sh`**

```bash
#!/bin/bash
cd /root/.openclaw/workspace

# 1. 获取 RSS 内容
python3 /root/.openclaw/workspace/scripts/tech-rss-fetcher.py

# 2. 读取生成的文件
LATEST_FILE=$(ls -t /root/.openclaw/workspace/temp/tech-rss-articles/*.md | head -1)

# 3. 使用消息拆分工具
python3 /root/.openclaw/workspace/scripts/message-sender.py --file "$LATEST_FILE"

# 4. 更新状态
python3 << 'PYTHON'
import json
from datetime import datetime, timezone

state_file = "/root/.openclaw/workspace/memory/heartbeat-state.json"
with open(state_file, 'r') as f:
    state = json.load(f)

state['tasks']['tech_rss'] = {
    'status': 'completed',
    'last_run': datetime.now(timezone.utc).isoformat()
}

with open(state_file, 'w') as f:
    json.dump(state, f, indent=2, ensure_ascii=False)
PYTHON
```

## 🎓 经验总结

### 关键启示

1. **不要执着于单一方案**
   - 微信公众号不是唯一的内容源
   - 多平台 RSS 覆盖更全面

2. **免费方案可行**
   - 公开 RSS 源质量高
   - 无需付费 API

3. **稳定性优先**
   - 选择成熟、稳定的协议
   - 避免依赖需要授权的服务

4. **简单即是美**
   - RSS 协议简单、可靠
   - 易于维护和扩展
