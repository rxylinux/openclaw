# 财务指标计算方法

## 利润表指标

### 毛利率 (Gross Margin)
```
毛利率 = (营收 - 销售成本) / 营收 × 100%
```

### 营业利润率 (Operating Margin)
```
营业利润率 = 营业利润 / 营收 × 100%
```

### 净利润率 (Net Margin)
```
净利润率 = 净利润 / 营收 × 100%
```

### 每股收益 EPS (Earnings Per Share)
```
基本 EPS = (净利润 - 优先股股息) / 加权平均普通股数量
稀释 EPS = (净利润 - 优先股股息) / 稀释后加权平均普通股数量
```

## 资产负债表指标

### 流动比率 (Current Ratio)
```
流动比率 = 流动资产 / 流动负债
```

### 速动比率 (Quick Ratio)
```
速动比率 = (流动资产 - 存货) / 流动负债
```

### 债务股权比 (Debt-to-Equity)
```
债务股权比 = 总负债 / 股东权益
```

### 净债务 (Net Debt)
```
净债务 = 总债务 - 现金及现金等价物
```

## 现金流指标

### 自由现金流 FCF (Free Cash Flow)
```
自由现金流 = 经营活动现金流 - 资本支出
```

### FCF 利润率 (FCF Margin)
```
FCF 利润率 = 自由现金流 / 营收 × 100%
```

## 效率指标

### ROE (Return on Equity)
```
ROE = 净利润 / 股东权益 × 100%
```

### ROA (Return on Assets)
```
ROA = 净利润 / 总资产 × 100%
```

### 资产周转率 (Asset Turnover)
```
资产周转率 = 营收 / 总资产
```

## 现金转换周期

### 应收账款天数 DSO
```
DSO = (应收账款 / 营收) × 365
```

### 存货天数 DIO
```
DIO = (存货 / 销售成本) × 365
```

### 应付账款天数 DPO
```
DPO = (应付账款 / 销售成本) × 365
```

### 现金转换周期 CCC
```
CCC = DSO + DIO - DPO
```

## 估值指标

### P/E (Price-to-Earnings)
```
P/E = 股价 / 每股收益 (EPS)
```

### Forward P/E
```
Forward P/E = 股价 / 预期下一年每股收益
```

### P/S (Price-to-Sales)
```
P/S = 市值 / 营收
```

### P/B (Price-to-Book)
```
P/B = 股价 / 每股账面价值
```

### EV/EBITDA
```
EV/EBITDA = 企业价值 / EBITDA
企业价值 = 市值 + 净债务
EBITDA = 营业利润 + 折旧摊销
```

## 增长率计算

### 同比增长 (Year-over-Year)
```
同比增长率 = (本期数值 - 去年同期数值) / 去年同期数值 × 100%
```

### 环比增长 (Quarter-over-Quarter)
```
环比增长率 = (本期数值 - 上期数值) / 上期数值 × 100%
```

## 复合增长率

### CAGR (Compound Annual Growth Rate)
```
CAGR = (期末值 / 期初值)^(1/年数) - 1
```
