# 价格涨跌幅监控使用说明

## 功能说明

自动监控rxy的所有持仓股票，当涨跌幅超过±5%时，立即推送预警到飞书。

## 技术方案

### 数据源
- **A股**：腾讯财经API (http://qt.gtimg.cn/q=sz000001)
- **港股**：腾讯财经API (http://qt.gtimg.cn/q=hk00700)
- **美股**：腾讯财经API (http://qt.gtimg.cn/q=usABCL)

### 监控逻辑
1. 首次运行：记录基准价格到 `holdings-price.json`
2. 后续运行：对比上次价格，计算涨跌幅
3. 超过±5%：生成预警消息，保存到 `price-alert.txt`
4. 正常范围：不推送，静默监控

## 运行方式

### 手动运行
```bash
python3 /root/.openclaw/workspace/scripts/price-monitor.py
```

### 定时运行（推荐）
设置cron任务，每天收盘后自动运行：
```bash
# 编辑crontab
crontab -e

# 添加以下行（每天15:30运行）
30 15 * * 1-5 python3 /root/.openclaw/workspace/scripts/price-monitor.py >> /root/.openclaw/workspace/logs/price-monitor.log 2>&1
```

## 故障排查

### 无法获取股价
1. 检查网络连接
2. 检查腾讯财经API是否可访问
3. 查看 `price-monitor.log` 日志文件

### 预警未推送
1. 检查 `temp/price-alert.txt` 是否生成
2. 检查飞书推送是否正常

### 涨跌幅计算错误
1. 检查 `holdings-price.json` 中的价格记录
2. 重新运行脚本，重新记录基准价格

## 维护

### 添加新股票
编辑 `holdings-price.json`，添加新股票信息：
```json
{
  "stocks": {
    "新股票": {
      "code": "000001.SZ",
      "last_price": null,
      "last_check": null
    }
  }
}
```

### 删除股票
编辑 `holdings-price.json`，删除对应的股票信息。

### 重置基准价格
将 `last_price` 设置为 `null`，下次运行时会重新记录。
