# 数据源说明

## 主要数据源

### Bloomberg
- **覆盖范围**: 全球股票、期货、外汇、债券
- **数据类型**: 实时报价、历史价格、财务报表、分析师预期、新闻
- **更新频率**: 实时（延迟15分钟）
- **可靠性**: ⭐⭐⭐⭐⭐

### FactSet
- **覆盖范围**: 全球上市公司
- **数据类型**: 财务数据、估值指标、机构持仓、分析师评级
- **更新频率**: 每日
- **可靠性**: ⭐⭐⭐⭐⭐

### SEC EDGAR
- **覆盖范围**: 美国上市公司
- **数据类型**: 10-K、10-Q、8-K、DEF 14A等官方文件
- **更新频率**: 实时（公司提交后即时更新）
- **可靠性**: ⭐⭐⭐⭐⭐（官方数据）

### Yahoo Finance
- **覆盖范围**: 全球主要市场
- **数据类型**: 股价、基本信息、财务数据
- **更新频率**: 延迟15分钟
- **可靠性**: ⭐⭐⭐⭐
- **注意**: 免费版本数据可能不完整

### Finviz
- **覆盖范围**: 美股
- **数据类型**: 筛选指标、财务比率、Insider交易
- **更新频率**: 每日
- **可靠性**: ⭐⭐⭐⭐

## 数据类型对应关系

| 数据类型 | 首选数据源 | 备选数据源 |
|----------|------------|------------|
| 股价/涨跌幅 | Bloomberg | Yahoo Finance, Finviz |
| 财务报表 | SEC EDGAR | FactSet, Yahoo Finance |
| 估值比率 | FactSet | Yahoo Finance, Finviz |
| 分析师评级 | Bloomberg | FactSet, Yahoo Finance |
| 机构持仓 | SEC 13F | FactSet, Bloomberg |
| 目标价 | Bloomberg | FactSet, TipRanks |

## 数据新鲜度提示

- **实时数据**: Bloomberg Terminal、Yahoo Finance（延迟）
- **每日更新**: 财务比率、估值指标、分析师评级
- **季度更新**: 财务报表（10-Q）、机构持仓（13F）
- **年度更新**: 年报（10-K）

## 注意事项

1. **数据来源标注**: 每个数据点必须注明来源和日期
2. **数据过期**: 超过30天的数据需用 ⚠️ 标记
3. **数据不可得**: 明确说明"数据不可获取"而非估算
4. **数据冲突**: 多源数据不一致时，以权威来源（SEC、Bloomberg）为准
