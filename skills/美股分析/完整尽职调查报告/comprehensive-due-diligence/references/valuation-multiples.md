# 估值倍数指南

## 常用估值倍数

### P/E（市盈率，Price-to-Earnings）

#### 定义
**公式：** P/E = 股价 / 每股收益（EPS）

#### 类型

**1. P/E (TTM)**
- 基于**过去12个月**的 EPS
- 确定数据
- 反映历史盈利

**2. Forward P/E**
- 基于**未来12个月**预期 EPS
- 预测数据
- 反映未来盈利

#### 适用场景
- ✅ 盈利稳定的公司
- ✅ 可比公司估值
- ✅ 周期性公司（需调整）
- ❌ 亏损公司
- ❌ 高波动盈利

#### 正常范围
- **成长股：** 20-30+
- **成熟股：** 15-20
- **价值股：** 10-15
- **周期股：** 8-12（周期高点）

#### 注意事项
- ⚠️ 盈利暂时性扭曲时失真
- ⚠️ 需要调整非经常性项目
- ⚠️ 不同会计准则不可直接对比

---

### EV/EBITDA（企业价值/息税折旧摊销前利润）

#### 定义
**公式：** EV/EBITDA = (市值 + 净债务) / EBITDA

**其中：**
- EV（企业价值）= 市值 + 债务 - 现金
- EBITDA = 息税前利润 + 折旧 + 摊销

#### 优点
- ✅ 排除资本结构影响
- ✅ 排除税收、折旧政策影响
- ✅ 适用于资本密集型行业
- ✅ 可跨国比较（忽略税收差异）

#### 适用场景
- ✅ 资本密集型行业（公用事业、电信、能源）
- ✅ 有高债务公司
- ✅ 折旧差异大的行业
- ✅ 并购估值

#### 正常范围
- **公用事业：** 8-12x
- **电信：** 6-9x
- **工业：** 10-14x
- **科技：** 15-25x

---

### P/B（市净率，Price-to-Book）

#### 定义
**公式：** P/B = 股价 / 每股净资产

#### 适用场景
- ✅ 金融业（银行、保险）
- ✅ 资产密集型行业
- ✅ 周期性行业
- ✅ 账面价值稳定行业

#### 正常范围
- **银行：** 0.8-1.5x
- **保险：** 0.9-1.2x
- **工业：** 1.5-3.0x

#### 注意事项
- ⚠️ 不适用于轻资产行业（科技、服务）
- ⚠️ 账面价值可能失真（商誉、无形资产）

---

### P/S（市销率，Price-to-Sales）

#### 定义
**公式：** P/S = 市值 / 营收

#### 适用场景
- ✅ 亏损公司
- ✅ 早期成长公司
- ✅ 盈利波动大的公司
- ✅ 同行业对比

#### 正常范围
- **SaaS/软件：** 5-15x
- **零售：** 0.5-2x
- **科技：** 3-10x
- **工业：** 1-3x

---

### FCF Yield（自由现金流收益率）

#### 定义
**公式：** FCF Yield = 自由现金流 / 市值

#### 适用场景
- ✅ 现金流稳定的公司
- ✅ 资本密集型行业
- ✅ 评估估值吸引力

#### 正常范围
- **吸引：** > 6%
- **正常：** 4%-6%
- **偏高：** < 4%

## 倍数使用注意事项

### GAAP vs 非 GAAP

**问题：** 许多公司报告调整后 EPS

**原则：**
- 明确标注使用 GAAP 或非 GAAP
- 两种都报告最佳
- 对比时保持一致

### 周期性调整

**问题：** 周期性公司盈利波动大

**方法：**
- 使用正常化盈利（峰值到谷值平均）
- 或使用周期平均 P/E
- 或使用 EV/EBITDA

### 负面 EPS

**问题：** 亏损公司无法用 P/E

**替代：**
- P/S
- EV/Revenue
- 或等到盈利

### 非经常性项目

**问题：** 一次性收入或费用扭曲盈利

**方法：**
- 调整 EPS 排除非经常性项目
- 使用调整后 P/E
- 或使用 EV/EBITDA

## 历史估值区间分析

### 5年历史估值

**目的：** 了解估值相对历史位置

**方法：**

| 估值指标 | 5年最低 | 5年最高 | 5年平均 | 当前值 | 百分位 |
|----------|---------|---------|---------|--------|--------|
| P/E (TTM) | 15x | 35x | 22x | 28x | 70% |

**解读：**
- 当前估值处于 5 年 [低/中/高] 区间
- 相对历史 [低估 / 合理 / 高估]

### 估值分位数

**定义：** 当前估值相对历史的位置

**解读：**
- < 25%：显著低估
- 25%-50%：低估
- 50%-75%：合理
- > 75%：高估

## 可比公司估值步骤

### 第一步：选择可比公司

**标准：**
- 同行业
- 相似商业模式
- 相似规模（可选）
- 相似增长特征（可选）

**数量：** 至少 5 家

### 第二步：收集数据

**需要数据：**
- 股价、市值
- EPS（TTM 和预测）
- EBITDA
- 债务、现金
- 收入

### 第三步：计算倍数

| 公司 | P/E (TTM) | P/E (Fwd) | EV/EBITDA | P/B | P/S |
|------|-----------|-----------|------------|-----|-----|
| 目标公司 | | | | | |
| 同行1 | | | | | |
| 同行2 | | | | | |
| 同行3 | | | | | |
| 同行4 | | | | | |
| 同行5 | | | | | |
| **中位数** | **[x]** | **[x]** | **[x]** | **[x]** | **[x]** |

### 第四步：选择目标倍数

**原则：**
- 使用中位数或平均值
- 考虑异常值
- 解释为何选择特定倍数

**示例：**
```
目标 P/E = 可比公司中位数 = 20x
```

### 第五步：计算目标价

**公式：**
```
目标价 = EPS × 目标 P/E
或
企业价值 = EBITDA × 目标 EV/EBITDA
股权价值 = 企业价值 - 净债务
目标价 = 股权价值 / 股数
```

## 估值陷阱

### 价值陷阱

**定义：** 低估值但基本面恶化的公司

**识别信号：**
- P/E 极低但盈利下降
- 股息率高但不可持续
- 债务问题
- 行业衰退

### 成长陷阱

**定义：** 高估值但增长不及预期

**识别信号：**
- P/E 极高但增长放缓
- 竞争加剧
- 市场饱和

## 注意事项

1. **一致性：** 对比时使用相同时间范围
2. **数据质量：** 使用最新数据
3. **异常值：** 识别和处理异常倍数
4. **背景考虑：** 考虑利率、宏观环境
5. **多倍数：** 不要依赖单一倍数
