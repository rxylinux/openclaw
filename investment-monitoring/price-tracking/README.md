# 价格涨跌幅监控

## 功能说明

监控rxy的所有持仓股票，当涨跌幅超过±5%时，立即推送预警到飞书。

## 可选方案

### 方案1：手动输入（最简单）
- rxy每天收盘后提供每只股票的收盘价
- 记录下来，第二天对比计算涨跌幅
- 超过±5%立即推送预警

**优点：**
- 最简单，不需要额外工具
- 不依赖外部API，稳定可靠

**缺点：**
- 需要rxy每天手动提供价格

**示例格式：**
```
双环传动 12.50
美的集团 68.30
中芯国际 45.20
...
```

### 方案2：安装akshare库（最推荐）
- akshare是开源的财经数据接口库
- 可以获取A股、港股、美股的实时数据
- 需要使用虚拟环境安装

**优点：**
- 数据全面，支持A股、港股、美股
- 免费开源，持续更新
- 接口稳定

**缺点：**
- 需要安装Python库
- 可能需要使用虚拟环境

**安装命令：**
```bash
python3 -m venv ~/.openclaw/venv
source ~/.openclaw/venv/bin/activate
pip install akshare
```

### 方案3：定期截图/图片识别
- rxy截图持仓界面
- 使用OCR识别价格
- 自动记录并计算涨跌幅

**优点：**
- 不需要手动输入
- 可以获取完整持仓信息

**缺点：**
- 需要OCR技术支持
- 可能识别不准确

### 方案4：暂不实时监控
- 继续监控基本面和产业链动态
- rxy自己盯盘，有特殊情况告诉我
- 专注挖掘铲子股和分析投资机会

**优点：**
- 专注核心价值挖掘
- 不被短期波动干扰

**缺点：**
- 无法及时捕捉异常波动

## 预警规则

- **涨跌幅超过+5%**：推送上涨预警 📈
- **涨跌幅超过-5%**：推送下跌预警 📉
- **涨跌幅在±5%以内**：正常，不推送

## 预警消息格式

```

📈 双环传动 (002472.SZ)

   当前价格：12.57
   时间：2026-02-26 15:00:00

   下跌 5.20%

   当前价格：44.84

```
