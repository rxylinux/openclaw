# 风险评估方法论

## 实质性风险定义

### 风险分类

**按影响分类：**
- 财务风险
- 运营风险
- 战略风险
- 监管风险
- 市场风险

**按概率分类：**
- 高概率：> 50%
- 中概率：20-50%
- 低概率：< 20%

**按影响分类：**
- 高影响：影响 > 20%
- 中影响：影响 10-20%
- 低影响：影响 < 10%

---

## 风险排序矩阵

### 风险矩阵

```
影响 \ 概率 | 高 | 中 | 低 |
|-----------|-----|-----|-----|
| 高 | 高优先级 | 高优先级 | 中优先级 |
| 中 | 高优先级 | 中优先级 | 低优先级 |
| 低 | 中优先级 | 低优先级 | 低优先级 |
```

### 优先级定义

- **高优先级**：高影响 × 高/中概率，需立即关注
- **中优先级**：高影响 × 低概率 或 中影响 × 中/高概率
- **低优先级**：低影响或低概率

---

## 做空比例分析

### 做空比例解读

```
做空比例范围：

< 3%：做空兴趣低
3-5%：正常水平
5-10%：需关注
10-20%：高做空兴趣
> 20%：极高做空兴趣
```

### 趋势分析

```
做空比例趋势：

上升 → 消极信号
稳定 → 中性
下降 → 积极信号
```

---

## 内部人交易分析

### 净买入/卖出

```
净买卖比例：

买入/卖出 > 3:1 → 强烈积极信号
1:1-3:1 → 积极信号
1:1 → 无明确信号
1:1-1:3 → 消极信号
> 1:3 → 强烈消极信号
```

### 交易模式

```
积极信号：
- 高管现金直接买入
- 多位高管同步买入
- 内部人净买入

消极信号：
- 高管大量卖出
- 多位高管同步卖出
- 内部人净卖出

中性信号：
- 期权行权后卖出（正常）
- 稀疏交易
```

## 会计质量评估

### GAAP vs 调整后

```
差异评估：

< 10%：差异小
10-20%：需审查
20-30%：差异大
> 30%：严重差异
```

### 调整项目类型

**合理调整：**
- 一次性重组费用
- 一次性资产减值
- 投资损益

**存疑调整：**
- 频繁的非经常性项目
- 会计估计调整
- 收入确认调整

---

## 审计意见分析

### 审计意见类型

```
标准无保留：无问题
带强调事项段：需关注
保留意见：有问题
否定意见：严重问题
无法表示意见：无法审计
```

### 持续经营风险

```
审计师提及：高风险
管理层披露：中风险
无提及：低风险
```

---

## 财报重述分析

### 重述影响

```
重述频率：

0 次：无问题
1 次：轻微
2-3 次：需关注
> 3 次：严重问题
```

### 重述原因

**严重原因：**
- 会计错误
- 内部控制缺陷
- 欺诈

**轻微原因：**
- 技术性错误
- 解释变更
- 细小错误
