# 股息投资分析框架

## 概述

股息投资分析采用**6维度方法**，系统评估股息价值和可持续性。

## 6个分析维度

### 第1步：股息概况
- 年度股息
- 股息率计算
- 发放频率
- 除息日/派息日

### 第2步：增长记录
- 1/3/5/10年CAGR
- 连续增长年数
- 股息贵族/之王地位

### 第3步：可持续性
- 派息率（净利润）
- 现金流派息率
- 债务/EBITDA
- 利息保障倍数

### 第4步：行业对比
- 股息率对比
- 增长率对比
- 派息率对比
- FCF覆盖对比

### 第5步：收入预测
- 投资假设
- DRIP复利计算
- 5/10/20年收益

### 第6步：风险评估
- 削减情景
- 距离危险区
- 管理层承诺

## 股息贵族标准

| 类型 | 定义 | 例子 |
|------|------|------|
| 股息贵族 | 连续25年增长 | 3M、可口可乐 |
| 股息之王 | 连续50年增长 | 美国自来水、宝洁 |
| 股息冠军 | 10年+5%年均增长 | 部分REITs |

## 可持续性指标

### 安全阈值
- 派息率 < 75%
- FCF派息率 < 100%
- 债务/EBITDA < 3x
- 利息保障 > 3x

### 危险信号
- 派息率持续上升
- 营收下滑但派息维持
- 大额并购或重组
- 周期性行业低谷期

## 复利计算

**无DRIP**（现金分红）：
```
收入 = 初始投资 × 股息率 × 年数
```

**有DRIP**（再投资）：
```
复利因子 = (1 + 股息率 × 增长率)^年数
收入 = 初始投资 × 复利因子 × 股息率
```

**复利效应示例**：
- 0.42%股息率 + 4%增长
- 20年后：收益率增至24.9%
- 增益：2.93x
