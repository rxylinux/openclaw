## 项目研究：transcribee 🐝

### 项目信息
- **仓库**: https://github.com/itsfabioroma/transcribee
- **作者**: Fabio Roma
- **许可证**: MIT License
- **版本**: 1.0.0

### 核心功能
一个开源的 macOS 转录工具，支持：
- YouTube 视频、Instagram Reels、TikTok 视频转录
- 本地音频/视频文件转录
- **说话人区分** (speaker diarization)
- **自动分类** - 使用 Claude 根据内容自动归类到知识库
- 构建自组织的个人知识库

### 技术栈
**核心依赖**:
- `@anthropic-ai/sdk` (v0.67.0) - Claude API，用于自动分类
- `elevenlabs` (v1.57.0) - ElevenLabs API，用于转录
- `dotenv` (v16.5.0) - 环境变量管理
- `tsx` (v4.19.4) - TypeScript 执行器

**外部工具**:
- `yt-dlp` - 下载视频/音频（支持 YouTube、Instagram、TikTok）
- `ffmpeg` - 音频提取和处理
- `ffprobe` - 媒体文件元数据提取

### 工作流程
1. **下载/提取音频**
   - URL: 使用 yt-dlp 下载音频
   - 本地文件: 使用 ffmpeg 提取音频（如果是视频）

2. **转录**
   - 调用 ElevenLabs `scribe_v1_experimental` 模型
   - 启用 speaker diarization
   - 获取带时间戳和说话人ID的词级数据

3. **自动分类**
   - 读取现有知识库结构 (`~/Documents/transcripts/`)
   - 将转录文本发送给 Claude
   - Claude 分析内容并推荐分类路径（单层分类）
   - 置信度评估：high/medium/low

4. **保存文件**
   - 创建目录: `~/Documents/transcripts/{category}/{title}-{date}/`
   - `transcript.txt` - 带说话人标签的转录文本
   - `metadata.json` - 完整元数据（来源、分类、转录统计）
   - `transcript-raw.json` (可选，--raw flag) - 原始 ElevenLabs 响应

### Claude 分类提示词设计
Claude 会收到：
1. 视频信息（URL、标题）
2. 当前知识库结构（树状字符串）
3. 新转录文本（如果太长会被截取开头、中间、结尾）

分类原则：
- 优先使用现有分类（语义匹配）
- 不匹配时创建新分类
- 使用 kebab-case 命名
- 只用**单层**分类（如 "ai-podcasts" 而非 "technology/ai/podcasts"）

### 技术亮点
1. **智能截断** - 超长转录文本会抽取开头、中间、结尾三部分给 Claude
2. **Token 估算** - 保守估计 4 字符 = 1 token
3. **并发文件写入** - Promise.all 同时写入多个文件
4. **容错处理** - 元数据提取失败时降级使用基础信息
5. **Shell 别名支持** - 推荐添加 `alias transcribee="noglob /path/to/transcribee/transcribe.sh"`

### Clawdbot 集成

然后在对话中直接说："Transcribe this video: https://youtube.com/watch?v=..."

### 限制
- 仅支持 macOS（在 Sonoma 上测试）
- 需要 Node.js 18+
- 需要 ElevenLabs 和 Anthropic API keys
- 单层分类（无法创建嵌套文件夹结构）

### 成本考虑
- ElevenLabs 转录按音频时长收费
- Claude 分类按 token 计费
- 长视频可能需要较多费用

## 关键代码片段

### Token 估算
```typescript
function estimateTokens(text: string): number {
    return Math.ceil(text.length / 4);
}
```

### 智能截断策略
```typescript
function truncateTranscript(text: string, maxTokens: number = 150000): string {
    const estimated = estimateTokens(text);
    if (estimated <= maxTokens) return text;

    const targetChars = maxTokens * 4;
    const chunkSize = Math.floor(targetChars / 3);

    const beginning = text.slice(0, chunkSize);
    const middle = text.slice(
        Math.floor(text.length / 2 - chunkSize / 2),
        Math.floor(text.length / 2 + chunkSize / 2)
    );
    const end = text.slice(-chunkSize);

    return `${beginning}\n\n[... middle section ...]\n\n${middle}\n\n[... later section ...]\n\n${end}`;
}
```

### 说话人转换
```typescript
export function wordsToTranscript(words: Word[]): string {
    const lines: string[] = [];
    let currentSpeaker = words[0].speaker_id;
    let currentSentence: string[] = [];

    const flush = () => {
        if (currentSentence.length) {
            lines.push(`${currentSpeaker}: ${currentSentence.join(' ').replace(/\s+([.,!?;:])/g, '$1')}`);
            currentSentence = [];
        }
    };

    for (const token of words) {
        if (token.speaker_id !== currentSpeaker) {
            flush();
            currentSpeaker = token.speaker_id;
        }

        if (token.type !== 'spacing') {
            currentSentence.push(token.text);
        }
    }

    flush();
    return lines.join('\n');
}
```

## 总结评价

**优点**：
- ✅ 自动化程度高（下载→转录→分类→存储全流程）
- ✅ 智能分类，知识库自我组织
- ✅ 说话人区分，适合对话类内容
- ✅ 支持多种来源（YouTube、本地、社交平台）
- ✅ 作为 Clawdbot skill，可语音调用

**缺点**：
- ❌ 仅支持 macOS
- ❌ 单层分类，深度组织能力有限
- ❌ 依赖两个付费 API（ElevenLabs + Claude）
- ❌ 没有搜索功能（需要外部工具搜索 metadata.json）

**适用场景**：
- 大量消费视频内容（播客、访谈、教学视频）
- 需要在 LLM 中查询视频内容
- 希望构建个人知识库但不愿手动整理
- 预算充足（愿意为 API 付费）

**潜在改进方向**：
- 跨平台支持（Linux/Windows）
- 多层分类体系
- 内置搜索功能（全文搜索 metadata.json）
- 批量处理
- Web UI 可视化知识库
