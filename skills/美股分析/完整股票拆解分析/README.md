# 美股分析技能

## 概述

美股分析技能提供**5维度专业投行级别**的股票研究分析能力，涵盖公司概览、财务数据、股价表现、华尔街一致预期、机构资金动向等核心维度。

## 核心特性

- ✅ **5维度分析框架**：公司概览、财务数据、股价表现、华尔街预期、机构动向
- ✅ **数据来源标注**：每个指标都标注来源和日期
- ✅ **时效性提醒**：数据超过30天自动标注
- ✅ **不编造数据**：数据不可获取时明确说明
- ✅ **清晰输出格式**：使用Markdown标题和表格

## 快速开始

### 分析单只股票

当用户询问"分析一下苹果公司 AAPL"时，技能会自动执行5步分析：

1. **第1步 —— 公司概览**：业务模式、收入来源、竞争优势
2. **第2步 —— 关键财务数据**：营收、净利润、估值指标
3. **第3步 —— 股价表现**：涨跌幅、52周高低点、与标普500对比
4. **第4步 —— 华尔街一致预期**：分析师评级、目标价
5. **第5步 —— 机构资金动向**：机构持仓、对冲基金动向

### 使用脚本获取数据

```bash
# 获取股票数据
python3 scripts/fetch_us_stock_data.py AAPL
```

## 数据源

### 主要数据源

1. **Yahoo Finance**：股价、财务数据、估值指标
2. **SEC EDGAR**：公司财报、13F机构持仓文件
3. **TipRanks/Bloomberg**：分析师评级、目标价
4. **公司官网**：最新财报、投资者关系资料

### 数据时效性

| 数据类型 | 更新频率 | 滞后时间 |
|---------|---------|---------|
| 股价 | 实时 | 0-15分钟 |
| 新闻 | 实时 | 0-1小时 |
| 财报 | 季度 | 45-60天 |
| 机构持仓（13F） | 季度 | 45天 |
| 分析师评级 | 不定期 | 0-7天 |

## 核心原则

1. **数据来源标注**：每个指标后必须标注来源和日期
2. **不编造数据**：数据不可获取时明确说明，不估算或编造
3. **时效性提醒**：数据超过30天时标注⚠️提示
4. **客观中立**：避免强烈买入/卖出建议，提供分析框架
5. **合规要求**：不构成投资建议，仅作信息整理和分析

获取美股股票数据的脚本，支持获取实时股价、财务数据、估值指标等。

**依赖安装**：
```bash

```

**使用方式**：
```bash
python3 scripts/fetch_us_stock_data.py AAPL
```
