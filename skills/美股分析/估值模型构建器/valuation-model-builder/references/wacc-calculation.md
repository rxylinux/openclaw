# WACC 计算指南

## WACC 概述

WACC（Weighted Average Cost of Capital）加权平均资本成本，是公司债务和股权融资的加权平均成本，是 DCF 估值中的关键折现率。

### WACC 公式

```
WACC = (E/V) × Re + (D/V) × Rd × (1 - t)
```

**变量定义：**
- `E` = 权益市值 (Market Cap)
- `D` = 债务市值 (Debt)
- `V` = 企业价值 (Enterprise Value = E + D)
- `Re` = 股权成本 (Cost of Equity)
- `Rd` = 债务成本 (Cost of Debt)
- `t` = 有效税率 (Tax Rate)

---

## 第 1 步：计算股权成本 (Re)

### CAPM 模型

```
Re = Rf + β × ERP
```

### 无风险利率 (Rf)

**标准定义：** 投资于无风险资产（如美国国债）的预期回报率

**最佳选择：10年期美国国债收益率**

| 到期期限 | 适用场景 | 收益率（示例） |
|----------|----------|----------------|
| 3个月 | 短期估值 | 约 5.0% |
| 2年 | 中短期 | 约 4.5% |
| 10年 | **标准选择** | **约 4.0%** |
| 30年 | 长期估值 | 约 4.2% |

**数据来源：**
- **美联储 FRED 数据库** (GS10): 免费，每日更新
- **Yahoo Finance** (^TNX): 免费，实时
- **Bloomberg**: 付费，实时

**当前查询：** 搜索 "10 year treasury yield" 或访问 treasury.gov

### Beta (β)

**定义：** 衡量股票相对于整个市场波动性的指标

**解读：**

| Beta 值 | 波动性 | 典型行业/公司 |
|---------|--------|---------------|
| 0.0 - 0.5 | 显著低于市场 | 公用事业、房地产信托 |
| 0.5 - 0.8 | 低于市场 | 消费必需品、医疗保健 |
| 0.8 - 1.2 | 接近市场 | 大部分蓝筹公司 |
| 1.2 - 1.5 | 高于市场 | 科技、工业 |
| 1.5 - 2.0+ | 显著高于市场 | 生物科技、小盘成长股 |

**数据来源：**
- **Yahoo Finance**: 股票页面 → Statistics → Beta
- **Bloomberg**: 专业终端
- **Finviz**: 筛选工具

**计算方法：**
- 通常使用 2-5 年周数据
- 回归：股票收益 vs 标普 500 收益

**调整后 Beta (Adjusted Beta):**
```
Adjusted β = 0.67 × Raw β + 0.33
```
- 许多机构使用调整后 Beta，使其向 1 回归

### 股权风险溢价 (ERP)

**定义：** 投资者要求超过无风险利率的额外回报，以补偿股票投资风险

**权威数据源：**

| 来源 | ERP 建议 | 更新频率 | 网站 |
|------|----------|----------|------|
| **Aswath Damodaran (NYU)** | **5.2%** (2024) | 年度 | stern.nyu.edu |
| Morningstar/Ibbotson | 5.0% | 季度 | morningstar.com |
| Duff & Phelps | 5.5% | 年度 | duffandphelps.com |
| 历史平均 (1928-2023) | 5.5% | - | 以上数据平均 |

**推荐使用：** Damodaran 的数据（学术界权威）

**ERP 影响因素：**
- 经济不确定性 ↑ → ERP ↑
- 市场波动性 ↑ → ERP ↑
- 投资者风险厌恶 ↑ → ERP ↑

### 股权成本计算示例

```
Rf = 4.0% (10年期美债)
β = 1.2 (科技股)
ERP = 5.2% (Damodaran)

Re = 4.0% + 1.2 × 5.2%
   = 4.0% + 6.24%
   = 10.24%
```

## 第 2 步：计算债务成本 (Rd)

### 债务成本定义

公司为债务融资支付的利率（税后）

### 计算方法

#### 方法 1：公司债券收益率（最优）

**适用：** 有公开交易债券的公司

**步骤：**
1. 查找公司债券的到期收益率 (YTM)
2. 如果有多只债券，使用加权平均

**数据来源：**
- **FINRA Market Data**: bondfinder.com
- **Bloomberg**: 专业终端
- **Morningstar**: 债券数据

#### 方法 2：信用利差估算（次优）

**适用：** 无公开债券时

**步骤：**
1. 确定公司信用评级（S&P, Moody's, Fitch）
2. 查找该评级相对于国债的信用利差
3. 债务成本 = 无风险利率 + 信用利差

**信用利差参考（示例）：**

| 评级 | 信用利差范围 | 典型公司 |
|------|--------------|----------|
| AAA | 0.5% - 1.0% | Microsoft, J&J |
| AA | 1.0% - 1.5% | Apple, Visa |
| A | 1.5% - 2.5% | Home Depot, Costco |
| BBB | 2.5% - 3.5% | Ford, GM |
| BB 及以下 | > 3.5% | 高收益债券 |

**数据来源：**
- **FRED**: 美联储经济数据
- **Bloomberg**: 信用利差数据

#### 方法 3：利息支出估算（备选）

**适用：** 私有公司或无债券数据

```
Rd ≈ 利息支出 / 平均债务余额
```

**数据来源：** 公司财报 (10-K/10-Q)

### 税后债务成本

```
税后债务成本 = Rd × (1 - t)
```

其中 `t` = 有效税率

**示例：**
```
Rd = 6.0% (债券收益率)
t = 21% (美国企业税率)

税后 Rd = 6.0% × (1 - 0.21)
         = 6.0% × 0.79
         = 4.74%
```

## 第 3 步：确定资本结构

### 权益市值 (E)

```
E = 股价 × 稀释后股数
```

**数据来源：**
- 股价：Yahoo Finance、Bloomberg
- 稀释后股数：最新 10-Q

### 债务市值 (D)

**包含项目：**
- 短期债务
- 长期债务
- 融资租赁负债
- 可转换债券（如未转换为股权）

**不包含：**
- 应付账款（经营性负债）
- 递延收入（经营性负债）

**数据来源：** 最新 10-Q 资产负债表

### 企业价值 (V)

```
V = E + D
```

### 资本结构权重

```
权益权重 = E / V
债务权重 = D / V
```

**示例：**
```
E = $800 亿
D = $200 亿
V = $1,000 亿

权益权重 = 800 / 1,000 = 80%
债务权重 = 200 / 1,000 = 20%
```

---

## 第 4 步：计算 WACC

### 完整计算示例

**假设：**
- 权益市值 E = $800 亿
- 债务市值 D = $200 亿
- 企业价值 V = $1,000 亿
- 股权成本 Re = 10.24%
- 税前债务成本 = 6.0%
- 有效税率 t = 21%

**计算：**

```
税后债务成本 = 6.0% × (1 - 0.21) = 4.74%

权益权重 = 800 / 1,000 = 80%
债务权重 = 200 / 1,000 = 20%

WACC = (E/V) × Re + (D/V) × Rd × (1 - t)
     = 80% × 10.24% + 20% × 4.74%
     = 8.19% + 0.95%
     = 9.14%
```

### WACC 计算表

| 输入 | 数值 | 来源 |
|------|------|------|
| 无风险利率 (Rf) | 4.0% | 10年期美债 |
| Beta (β) | 1.2 | Yahoo Finance |
| 股权风险溢价 (ERP) | 5.2% | Damodaran |
| 股权成本 (Re) | 10.24% | CAPM 计算 |
| 税前债务成本 | 6.0% | 公司债券 YTM |
| 有效税率 | 21% | 最新财报 |
| 税后债务成本 | 4.74% | 计算 |
| 权益权重 | 80% | 市值计算 |
| 债务权重 | 20% | 市值计算 |
| **WACC** | **9.14%** | **最终计算** |

## WACC 典型范围

### 按行业分类

| 行业 | 典型 WACC 范围 | 特点 |
|------|----------------|------|
| 公用事业 | 6% - 8% | 低 Beta，高债务 |
| 消费必需品 | 7% - 9% | 稳定现金流 |
| 科技行业 | 9% - 12% | 高 Beta，成长性 |
| 工业 | 8% - 10% | 中等风险 |
| 金融 | 8% - 11% | 杠杆高，监管严 |
| 小盘股 | 11% - 15% | 高风险，高 Beta |

### 按公司规模

| 市值分类 | 典型 WACC 范围 | Beta 范围 |
|----------|----------------|----------|
| 大盘股 (> $100亿) | 8% - 10% | 0.8 - 1.2 |
| 中盘股 ($20-100亿) | 9% - 11% | 1.0 - 1.4 |
| 小盘股 (< $20亿) | 11% - 15% | 1.2 - 2.0 |

## WACC 调整

### 私营公司或无 Beta 数据

**方法：使用行业平均 Beta**

```
步骤：
1. 确定公司行业分类
2. 查找行业平均 Beta（去杠杆）
3. 根据目标公司资本结构重新杠杆化

去杠杆 Beta = 行业 Beta / (1 + (1-t) × D/E)
重新杠杆 Beta = 去杠杆 Beta × (1 + (1-t) × 目标 D/E)
```

### 国际公司 WACC

**调整要素：**
1. **无风险利率**：使用本国政府债券
2. **股权风险溢价**：调整国家风险溢价
3. **货币**：保持一致（本地货币或 USD）

**公式：**
```
国际 ERP = 美国 ERP + 国家风险溢价
```

### 高成长公司

**问题：** CAPM 可能低估成长股的股权成本

**调整方法：**
- 使用行业 Beta 但加上成长溢价
- 或使用更高 ERP（如 6-7%）

## 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 使用账面价值而非市值 | 权重错误 | 使用市场价值 |
| 使用错误的无风险利率 | Re 偏差 | 使用 10年期美债 |
| 忘记税盾效应 | WACC 虚高 | 债务成本 × (1-t) |
| 混淆税前和税后债务成本 | WACC 错误 | 明确使用税后 |
| 使用过时的 Beta | Re 不准确 | 使用最新数据 |

## 数据检查清单

计算 WACC 前确认：

- [ ] 无风险利率来源和日期
- [ ] Beta 数据来源和计算期间
- [ ] ERP 数据来源
- [ ] 债务成本基于实际债券利率
- [ ] 税率使用有效税率而非法定税率
- [ ] 权益和债务使用市值而非账面价值
- [ ] 资本结构反映当前而非历史状况
- [ ] 国际公司考虑国家风险溢价
