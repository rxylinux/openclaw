# 风险与下行提示指南

## 核心目标

识别这家公司最大的风险点，既要找"硬伤"（能死人的），也要找"软肋"（拖后腿的）。

## 分析四问

### 1. 业务风险是什么？

**要看的风险类型**:

| 风险类型 | 判断方法 | 数据来源 |
|----------|----------|----------|
| 客户集中 | 前五大客户占比 | 年报/访谈 |
| 产品依赖 | 单一产品收入占比 | 年报/产品目录 |
| 市场萎缩 | 所在行业需求下滑 | 行业数据 |
| 技术迭代 | 新品上市速度/技术生命周期 | 研发投入/专利 |
| 价格战 | 毛利率持续下降趋势 | 财报数据 |
| 产能过剩 | 产能利用率/存货周转 | 年报/公告 |
| 监管收紧 | 政策变化/合规成本 | 新闻/公告 |

**判断标准**:

| 风险程度 | 评级 | 解释 |
|----------|------|------|
| 🔴 致命 | 业务面临灭顶之灾风险 | 客户或产品失去，营收腰斩 |
| 🔴 高危 | 严重伤害核心业务 | 利润率持续恶化，市场份额大幅下滑 |
| 🟠 需关注 | 中度伤害业务 | 增速放缓，利润率承压 |
| 🟡 一般风险 | 正常经营风险 | 成本波动、竞争加剧等正常风险 |

**输出要求**:
- 列出2-4个关键业务风险点
- 评估每个风险的严重程度（致命/高危/关注/一般）
- 说明风险对业务的影响程度

### 2. 财务风险在哪里？

**要看的指标**:

| 指标 | 风险信号 | 阈值 |
|------|----------|------|
| 资产负债率 | 杠杆过高 | >70% |
| 流动比率 | 短期偿债困难 | <1.0 |
| 应收账款周转 | 回款困难 | >120天 |
| 存货周转 | 滞销风险 | >180天 |
| 经营现金流 | 现金流负或下降 | 持续为负或大幅下滑 |
| 净利润增速 | 盈利能力恶化 | 连续2年负增长或增速大幅下滑 |
| 毛利率 | 定价权丧失 | 连续3年下降 |
| 非经常损益占比 | 主业不赚钱 | <50% |
| 每股现金流 | 自由现金流负 | 连续为负 |

**判断标准**:

| 风险数量 | 评级 | 解释 |
|----------|------|------|
| 3个以上高危指标 | 🔴 财务危机 | 资不抵债，现金流枯竭 |
| 2个高危指标 | 🔴 财务高风险 | 高杠杆+现金流吃紧 |
| 1个高危指标 | 🟠 需关注 | 单一指标异常 |
| 无高危指标 | 🟡 财务健康 | 整体可控，个别指标需关注 |

**输出要求**:
- 列出财务风险指标（如有）
- 说明风险的持续时间（短期/长期/结构性）
- 评估财务健康度（危机/高风险/需关注/健康）

### 3. 监管威胁有多大？

**风险类型**:

| 类型 | 典型案例 | 影响 |
|------|----------|------|
| **政策收紧** | 医药集采、教育双减、房地产限购 | 降价、营收受挫 |
| **合规风险** | 环保处罚、安全监管、数据合规 | 罚款、整改成本 |
| **税收变化** | 营业税调整、税收优惠政策取消 | 利润影响 |
| **反垄断** | 滥用市场地位、高价销售 | 罚款、拆分业务 |
| **数据安全** | 用户隐私、数据泄露、网络安全 | 罚款、信任受损 |
| **出口管制** | 关税、技术封锁、实体清单 | 海外业务受阻 |
| **牌照管理** | 行业资质、准入门槛 | 暂停业务、整改 |

**判断方法**:
- 搜索"公司名 政策 风险"
- 查阅公告中"重大事项"、"风险提示"
- 关注行业监管动态

**输出要求**:
- 列出1-3个主要监管风险
- 标注影响程度（严重/一般）
- 说明公司应对措施（如有）

### 4. 什么因素会永久性伤害业务？

**永久性伤害因素**:

| 因素 | 伤害机制 | 行业案例 |
|------|----------|----------|
| **技术颠覆** | AI替代人工、电动车替代燃油车 | 翻译、电话、胶卷 |
| **人口结构** | 老龄化不利运动鞋、年轻人不爱白酒 | 需求萎缩、消费习惯改变 |
| **消费升级** | 高端化挤压中低端 | 品牌价值下降、市场份额丢失 |
| **渠道变革** | 电商挤压实体店 | 实体店关停、经销商网络失效 |
| **原材料替代** | 新材料替代传统材料 | 钢铁、铜材、塑料 |
| **能源结构** | 新能源替代化石能源 | 煤炭、石油需求长期萎缩 |
| **社会趋势** | 工作方式改变（远程办公） | 商业地产需求下降 |

**判断方法**:
- 所在行业的长期趋势分析（是否被新技术/新模式替代）
- 竞争格局变化（是否被新进入者颠覆）
- 消费习惯变化（目标用户群体偏好改变）

**输出要求**:
- 列出1-3个可能永久伤害业务的因素
- 评估每个因素的中长期影响
- 判断公司是否在积极应对（技术升级/模式转型）

## 业务风险识别

### 1. 客户集中度风险

**判断标准**:
- 前五大客户占比 >50%: 🔴 高危
- 前五大客户占比 30-50%: 🟠 需关注
- 前五大客户占比 <30%: 🟡 一般

**典型表现**:
- 大客户流失或需求下滑 → 营收大幅波动
- 议价权弱 → 利润率被压缩
- 依赖单一大客户 → 被客户拿捏

### 2. 产品依赖风险

**判断标准**:
- 单一产品占比 >60%: 🔴 高危
- 单一产品占比 40-60%: 🟠 需关注
- 单一产品占比 <40%: 🟡 一般

**典型表现**:
- 核心产品被新技术替代 → 营收腰斩
- 产品生命周期接近尾声 → 增速持续放缓
- 缺乏新品储备 → 无法接力增长

### 3. 市场萎缩风险

**判断标准**:
- 所在行业CAGR <0%: 🔴 萎缩市场
- 所在行业CAGR 0-3%: 🟠 疲软市场
- 所在行业CAGR 3-8%: 🟡 缓慢增长

**典型表现**:
- 需求持续下滑 → 营收负增长
- 市场饱和 → 增速逐年放缓
- 被新技术替代 → 传统产品被淘汰

### 4. 技术迭代风险

**判断标准**:
- 研发投入占比 <5%: 🔴 技术落后
- 新品上市周期 >3年: 🔴 创新缓慢
- 专利数量大幅少于对手: 🔴 技术壁垒脆弱

**典型表现**:
- 技术路线错误 → 产品竞争力下降
- 无法跟上行业创新 → 市场份额流失
- 核心技术被颠覆 → 业务面临生存危机

### 5. 价格战风险

**判断标准**:
- 毛利率连续3年下降: 🔴 定价权持续丧失
- 毛利率低于行业平均: 🔴 价格竞争激烈
- 销量增长但收入下降: 🔴 增收不增利

**典型表现**:
- 行业打价格战 → 利润率持续被压
- 产能过剩导致降价 → 毛利率大幅下滑
- 新进入者低价策略 → 被迫跟进

### 6. 产能过剩风险

**判断标准**:
- 产能利用率 <60%: 🔴 严重过剩
- 存货周转 >180天: 🔴 滞销严重
- 新建产能未达产: 🔴 产能爬坡期长

**典型表现**:
- 大额资本支出无法收回 → 现金流吃紧
- 存货减值准备增加 → 资产质量恶化
- 固定成本占比上升 → 利润率承压

## 财务风险识别

### 1. 高杠杆风险

**判断标准**:
- 资产负债率 >70%: 🔴 高危
- 有息负债/总负债 >60%: 🔴 债务负担重
- 利息保障倍数 <2: 🔴 利息压力大

**典型表现**:
- 借的钱太多，利润还利息都吃紧
- 宏观利率上行时债务压力剧增
- 可能触发债务违约风险

### 2. 现金流枯竭风险

**判断标准**:
- 经营现金流连续2年为负: 🔴 现金流枯竭
- 经营现金流/净利润 <0.5: 🔴 利润质量差
- 每股现金流连续为负: 🔴 无法分红

**典型表现**:
- 利润表好看，现金表难看 → 纸上富贵
- 大量应收账款未收回 → 赚的都是账面
- 需要持续融资维持运营

### 3. 应收账款风险

**判断标准**:
- 应收账款周转 >120天: 🔴 回款困难
- 坏账准备/应收账款 <5%: 🔴 风险暴露不足
- 应收账款增速 >营收增速: 🔴 激进销售导致

**典型表现**:
- 客户付款周期拉长 → 资金周转困难
- 客户信用风险上升 → 坏账风险增加
- 激进销售冲业绩 → 未来回收困难

### 4. 存货风险

**判断标准**:
- 存货周转 >180天: 🔴 滞销严重
- 存货跌价准备 <5%: 🔴 准备不足
- 存货增速 >营收增速: 🔴 生产过剩

**典型表现**:
- 产品卖不掉 → 资金占用严重
- 产品价格持续下跌 → 存货减值风险
- 预测失误导致囤货 → 资金占用浪费

## 监管风险识别

### 1. 政策风险

**典型类型**:
- 行业政策收紧 → 需求下降/降价
- 环保要求提升 → 整改成本上升
- 产业政策调整 → 发展受限
- 税收政策变化 → 利润影响

**判断方法**:
- 搜索"公司名 政策 影响"
- 关注行业监管动态
- 查阅公告风险提示章节

### 2. 合规风险

**典型类型**:
- 环保处罚 → 罚款+停产整改
- 安全事故 → 停产整顿+责任追究
- 数据合规 → 罚款+整改+信任受损
- 反垄断调查 → 罚款+业务调整

**判断方法**:
- 搜索"公司名 罚款 处罚"
- 查阅新闻和公告
- 关注监管问询函

### 3. 贸易/出口风险

**典型类型**:
- 关税提升 → 出口竞争力下降
- 技术出口管制 → 海外业务受阻
- 实体清单制裁 → 无法获取关键设备/技术

**判断方法**:
- 关注国际贸易政策
- 查阅海外收入占比
- 关注出口管制清单
