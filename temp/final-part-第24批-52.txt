- 毛利率较高主要因为海外业务占比高，海外业务利润率9%
- **评价：中等**

**成长能力分析：**

**1. 收入增长**
- 2018-2023年收入CAGR：3.8%
- 对比行业：基建行业平均CAGR约4%，中国交建略低于行业平均
- 对比其他行业：银行收入CAGR约4%，保险收入CAGR约7%，中国交建增速中等
- **评价：中等**

**2. 利润增长**
- 2018-2023年净利润CAGR：5.2%
- 对比行业：基建行业平均CAGR约5%，中国交建略高于行业平均
- **评价：良好**

**3. 订单增长**
- 2024年新签合同1.6万亿元，同比增长8%
- 合同储备2.8万亿元，足以支撑未来2-3年的收入增长
- **评价：良好**

**运营效率分析：**

**1. 资产周转率**
- 总资产周转率 = 营业收入 / 平均总资产 = 8200 / 12000 = 68%
- 对比行业：基建行业平均约72%，中国交建略低于行业平均
- **评价：中等**

**2. 人均创收**
- 员工人数约15万人，人均创收约55万元
- 对比行业：基建行业平均约35万元，中国交建高于行业平均
- **评价：优秀**

**3. 费用控制**
- 期间费用率 = 期间费用 / 营业收入 = 5.5%左右
- 对比行业：基建行业平均约7%，中国交建低于行业平均
- **评价：良好**

**4. 应收账款周转**
- 应收账款周转天数 = 应收账款 / 营业收入 × 365 = 1800 / 8200 × 365 = 80天
- 对比行业：基建行业平均约95天，中国交建优于行业平均
- **评价：良好**

**财务结构分析：**

**1. 资产负债率**
- 资产负债率 = 总负债 / 总资产 = 78%
- 对比行业：基建行业平均约76%，中国交建略高于行业平均
- 基建行业是高杠杆行业，78%的资产负债率属于合理范围
- **评价：中等**

**2. 利息保障倍数**
- 利息保障倍数 = EBITDA / 利息支出 = 5.5倍左右
- 对比行业：基建行业平均约4.5倍，中国交建优于行业平均
- **评价：良好**

**3. 流动比率**
- 流动比率 = 流动资产 / 流动负债 = 1.25倍
- 监管要求不低于1倍，中国交建符合监管要求
- **评价：中等**

**现金流质量分析：**

**1. 经营性现金流**
- 2024年经营性现金流净流出约50亿元
- 经营性现金流 / 净利润 = -15%，现金流质量差
- **评价：差**

**2. 投资性现金流**
- 2024年投资性现金流净流出约250亿元
- 主要用于固定资产投资和海外项目投资
- **评价：正常**

**3. 融资性现金流**
- 2024年融资性现金流净流入约300亿元
- 主要来自银行贷款和债券融资
- **评价：正常**

**4. 现金流结构**
- 基建项目需要大量资金垫付，经营性现金流常年为负
- 虽然现金流差，但政府项目回款有保障，风险可控
- **评价：中等**
