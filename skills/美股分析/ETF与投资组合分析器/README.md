# ETF与投资组合分析器

## 概述

ETF与投资组合分析器提供**财富管理级别投资组合分析**能力，系统评估ETF和投资组合。

## 核心特性

- ✅ **资产配置**：行业、地理、市值、风格
- ✅ **持仓分析**：前10大持仓、重叠风险、个股集中度
- ✅ **风险指标**：Beta、波动率、回撤、夏普比率、相关性
- ✅ **成本分析**：费用率、规模成本、替代品
- ✅ **收益分析**：股息率、预计收入、增长率
- ✅ **压力测试**：2008/2020/2022危机表现
- ✅ **优化建议**：3个具体可执行建议

## 数据源

| 数据源 | 用途 |
|-------|------|
| ETF招募书 | 持仓、费用 |
| 晨星 | 历史表现、风险指标 |
| Bloomberg | 实时数据 |
| SEC EDGAR | Form 497 |

## 注意事项

1. 每个数据点标注来源
2. 不编造历史收益率或费用率
3. 缺乏数据明确说明
4. 使用清晰表格展示
5. 不构成投资建议
