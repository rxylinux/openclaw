# 股息术语说明

## 基础股息概念

### 股息 (Dividend)

**定义**：公司向股东分配的利润部分，通常以现金形式支付。

**类型**：
- **现金股息**：最常见，以现金支付
- **股票股息**：以额外股票形式支付
- **特别股息**：一次性、非经常性分配

### 每股股息 (Dividend Per Share, DPS)

**定义**：每股股票获得的股息金额

**计算**：
```
年度 DPS = 季度股息 × 4
或
年度 DPS = 公告的年度股息
```

### 股息率 (Dividend Yield)

**定义**：年度股息相对于股价的回报率

**计算**：
```
股息率 = (每股年度股息 / 当前股价) × 100%
```

**解读**：
- > 5%：高股息率（可能是价值机会或风险信号）
- 3% - 5%：中等股息率
- 1% - 3%：低股息率（通常是成长股）
- < 1%：极低股息率（重点在资本增值）

**注意**：异常高的股息率可能预示股价下跌风险

### 派息率 (Payout Ratio)

**定义**：公司利润中用于支付股息的比例

**计算（基于净利润）**：
```
派息率 = (每股年度股息 / 每股收益 EPS) × 100%
```

**计算（基于自由现金流）**：
```
现金流派息率 = (年度股息总额 / 自由现金流) × 100%
```

**解读**：
- **< 50%**：保守，安全，有增长空间
- **50% - 70%**：适中，可持续
- **70% - 90%**：激进，盈利下降时风险增加
- **> 90%**：危险，可能需要削减股息

## 股息相关日期

### 宣布日 (Declaration Date)

**定义**：董事会宣布派息的日期

**意义**：公司正式承诺支付股息

### 除息日 (Ex-Dividend Date)

**定义**：股票开始无权获得本期股息的日期

**规则**：通常为股权登记日前 1 个交易日（美股）

**影响**：
- 除息日当天股价通常会下跌（约等于股息金额）
- 除息日前买入股票可获得股息
- 除息日后买入股票不能获得本期股息

### 股权登记日 (Record Date)

**定义**：股东需在这一天持有股票才能获得股息

**注意**：实际交易有结算延迟（T+2），需在登记日前 2 天买入

### 派息日 (Payment Date)

**定义**：股息实际支付到股东账户的日期

**时间**：通常在除息日后 2-4 周

## 股息增长指标

### 股息增长率 (Dividend Growth Rate, DGR)

**定义**：股息年度增长的百分比

**计算**：
```
股息增长率 = (本年股息 - 去年股息) / 去年股息 × 100%
```

### 复合增长率 (CAGR)

**定义**：多年期间股息年均复合增长率

**计算**：
```
CAGR = (期末股息 / 期初股息)^(1/年数) - 1
```

**示例**：
- 期初股息：$1.00
- 5 年后股息：$1.50
- CAGR = (1.50 / 1.00)^(1/5) - 1 = 8.45%

### 连续增长年数

**定义**：连续提高股息的年数

**意义**：
- 反映股息稳定性
- 长期连续增长是财务健康的信号

## 特殊股息类别

### 股息贵族 (Dividend Aristocrats)

**定义**：S&P 500 成分股中连续 25 年或以上增加股息的公司

**特点**：
- 通常是成熟、稳定的公司
- 有持续的现金流生成能力
- 在各行业中有竞争优势

**数量**：约 65-70 家（每年变动）

**示例公司**：
- 消费品：可口可乐 (KO)、宝洁 (PG)、高露洁 (CL)
- 公用事业：NextEra Energy (NEE)、Consolidated Edison (ED)
- 工业：3M (MMM)、Emerson Electric (EMR)
- 零售：Walmart (WMT)、Target (TGT)
- 医疗：强生 (JNJ)、Abbott (ABT)

### 股息之王 (Dividend Kings)

**定义**：连续 50 年或以上增加股息的公司

**特点**：
- 比股息贵族更稀有
- 极其稳定的商业模式
- 通常在防御性行业

**数量**：约 40-50 家

**示例公司**：
- 可口可乐 (KO)：连续 60+ 年
- 高露洁 (CL)：连续 60+ 年
- 强生 (JNJ)：连续 60+ 年
- 宝洁 (PG)：连续 65+ 年
- American States Water (AWR)：连续 65+ 年

### 消费贵族 (Consumer Aristocrats)

**定义**：连续 25 年以上增加股息的非 S&P 500 消费品公司

**特点**：
- 中小盘股
- 同样有稳健的股息增长

## 股息政策类型

### 稳定股息政策

**定义**：每期支付固定或稳步增长的股息

**特点**：
- 投资者偏好稳定
- 现金流可预测的公司采用
- 成熟公司典型政策

### 目标派息率政策

**定义**：维持派息率在目标水平（如 40-60%）

**特点**：
- 股息随利润波动
- 更灵活
- 周期性行业常用

### 剩余股息政策

**定义**：支付股息后，剩余资金用于投资

**特点**：
- 优先满足投资需求
- 股息波动较大
- 高成长公司采用

### 股息再投资计划 (DRIP)

**定义**：股息自动再投资购买额外股票

**优势**：
- 复利效应
- 通常免佣金
- 可折扣购买股票

**参与方式**：
- 通过公司直接注册
- 通过券商

## 股息风险指标

### 削减股息 (Dividend Cut)

**定义**：公司降低或暂停股息支付

**常见原因**：
- 盈利大幅下降
- 现金流紧张
- 债务压力
- 业务重组
- 监管要求

**影响**：
- 股价通常大幅下跌
- 收益型投资者撤资
- 信心受损

### 派息率过高警告信号

| 派息率 | 风险级别 | 说明 |
|--------|----------|------|
| < 50% | 低风险 | 安全，有增长空间 |
| 50% - 70% | 中等风险 | 可持续，但需监控 |
| 70% - 90% | 高风险 | 盈利下降时可能削减 |
| > 90% | 危险区 | 削减可能性高 |

### 自由现金流覆盖

**计算**：
```
FCF 覆盖率 = 自由现金流 / 年度股息总额
```

**解读**：
- > 1.5：良好覆盖
- 1.0 - 1.5：足够覆盖
- 0.8 - 1.0：紧张，可能动用现金储备
- < 0.8：危险，可能需要削减

---

## 股息收益率陷阱

### 什么是收益率陷阱

**定义**：异常高的股息率，但公司基本面恶化，股息不可持续

**识别信号**：
- 股息率远高于同行（> 2 倍）
- 派息率 > 90%
- 自由现金流为负
- 债务水平上升
- 行业衰退

**示例场景**：
- 股价下跌 50%，股息未调整 → 股息率翻倍
- 但公司可能很快削减股息

### 真正高收益 vs 收益率陷阱

| 特征 | 真正高收益 | 收益率陷阱 |
|------|------------|------------|
| 派息率 | 50-70% | > 90% |
| FCF 覆盖 | > 1.2 倍 | < 1.0 倍 |
| 股息趋势 | 稳定或增长 | 可能削减 |
| 业务趋势 | 稳定或增长 | 衰退 |
| 债务 | 适中或低 | 高且上升 |

## 股息调整

### 特别股息 vs 定期股息

**特别股息**：
- 一次性支付
- 不预期持续
- 通常来自资产出售、超额现金

**定期股息**：
- 按计划支付
- 预期持续
- 用于收益投资分析时

### 股息拆分 (Stock Split) 影响

**影响**：每股股息下降，但总股息不变

**示例**：
- 拆分前：每股 $2.00，持有 100 股 = $200
- 2:1 拆分后：每股 $1.00，持有 200 股 = $200

### 股息税收

**美国税收**：
- 合格股息：长期资本利得税率（0%、15%、20%）
- 非合格股息：普通所得税率

**合格条件**：
- 持有股票 > 60 天（普通股）或 > 90 天（优先股）
- 由美国公司或合格外国公司支付
