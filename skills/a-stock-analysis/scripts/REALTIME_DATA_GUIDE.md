## 📊 数据时效性说明

### AkShare 数据接口时效性

| 接口名称 | 数据类型 | 延迟时间 | 更新频率 |
|----------|----------|----------|----------|
| **stock_zh_a_spot_em** | 实时行情 | 15-20秒 | 交易时段实时 |
| **stock_zh_index_spot_em** | 实时指数 | 15-20秒 | 交易时段实时 |
| **stock_zh_a_hist** | 历史K线 | T+1 | 每日盘后更新 |

### ✅ stock_zh_a_spot_em 就是实时数据！

- 当前交易日的实时行情数据
- 5810只A股的实时价格
- 包含最新价、涨跌幅、成交量、市值等23个字段
- **延迟15-20秒**（正常延迟）

### ⏰ 数据时间说明

#### 交易时段
- **上午**: 9:30 - 11:30
- **下午**: 13:00 - 15:00
- **数据更新**: 交易时段内实时更新

#### 非交易时段
- **早盘前**: 9:15-9:25 集合竞价时段
- **午休**: 11:30-13:00
- **收盘后**: 15:00之后显示当日收盘价

#### 数据延迟
- **实时行情**: 延迟15-20秒（正常）
  - 从交易所 → 数据商 → 网站 → AkShare
- **K线数据**: 延迟1天（T+1）
  - 当日K线在收盘后更新

### 📅 如何判断数据日期

#### 方法1: 查看"60日涨跌幅"字段
```python
# 如果"60日涨跌幅"有值，说明是交易日的实时数据
quote_data['60日涨跌幅']  # 例如: 10.62
```

#### 方法2: 对比历史数据
```python
import akshare as ak

# 获取历史数据最新一天
hist_df = ak.stock_zh_a_hist(symbol='002472', period='daily')
latest_hist_date = hist_df.iloc[-1]['日期']  # 例如: 2025-12-31

# 获取实时数据
spot_df = ak.stock_zh_a_spot_em()
current_price = spot_df[spot_df['代码'] == '002472']['最新价']

# 如果当前价格不等于历史最新收盘价，说明是新的交易日
if current_price != hist_df.iloc[-1]['收盘']:
    print("✅ 实时数据是交易日的最新数据")
```

#### 方法3: 查看"今开"字段
```python
quote_data['今开']  # 如果有开盘价，说明是交易日
```

### ⚠️ 注意事项

1. **非交易时段**
   - 周末、节假日显示最后一个交易日收盘价
   - 盘前显示参考价（非正式开盘价）

2. **系统时间问题**
   - 如果系统时间不准确（如设置为2026年）
   - 数据仍然是实时数据，但时间戳会混乱

3. **数据延迟**
   - 15-20秒延迟是正常的
   - 不需要更"实时"的数据
   - 高频交易需要L2行情（付费）

### 📊 数据来源

**AkShare → 东方财富 → 上海/深圳证券交易所**

- AkShare 从东方财富抓取数据
- 东方财富从交易所获取数据
- 延迟主要在网络传输
