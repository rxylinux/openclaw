# 数据源详细说明

## A股 数据源

### 1. 同花顺 (10jqka.com.cn)

**优先级**: 1
**类型**: 综合
**覆盖内容**:
- 实时行情、K线图
- 财务数据（营收、利润、现金流、资产负债）
- F10 资料库（公司信息、股东、高管）
- 研报中心
- 机构调研记录

**数据时效性**:
- 行情: 实时
- 财报: 季度更新（财报季后2-3周）
- F10: 月度更新

**优点**:
- 数据全面，覆盖A股所有股票
- F10资料库详细
- 机构调研记录有价值

**缺点**:
- 需要付费才能获取历史数据
- API 不对外开放

### 2. 东方财富 (eastmoney.com)

**优先级**: 2
**类型**: 综合
**覆盖内容**:
- 实时行情
- 财务数据（三表）
- 股东研究（股东户数、持股比例）
- 机构持仓（基金、QFII、社保）
- 资金流向数据
- 龙虎榜

**数据时效性**:
- 行情: 实时
- 财报: 季度更新
- 股东研究: 季度更新

**优点**:
- 股东研究功能强大
- 资金流向数据准确
- 龙虎榜数据完整

**缺点**:
- 部分高级数据需付费

### 3. 新浪财经 (sina.com.cn)

**优先级**: 3
**类型**: 行情
**覆盖内容**:
- 基础行情
- 财务摘要
- 新闻资讯

**数据时效性**:
- 行情: 实时

**优点**:
- 免费开放

**缺点**:

### 4. 交易所官网

**优先级**: 10 (官方)
**类型**: 官方

## 美股 数据源

### 1. Yahoo Finance

**优先级**: 1
**类型**: 综合
**URL**: https://finance.yahoo.com
**覆盖内容**:
- 实时行情
- 历史价格
- 财务数据（三表）
- 估值倍数（P/E, P/S, P/B, EV/EBITDA）
- 分析师评级和目标价
- 关键统计数据
- 股息信息

**数据时效性**:
- 行情: 实时（15分钟延迟免费）
- 财务: 季度更新
- 分析师: 实时更新

**API**: `yfinance` (Python库)

**优点**:
- 免费且数据全面
- API 友好
- 覆盖全球市场

**缺点**:
- 部分数据可能有延迟
- 高频请求可能被限制

### 2. SEC EDGAR

**优先级**: 1 (官方)
**类型**: 官方
**URL**: https://www.sec.gov/edgar
**覆盖内容**:
- 10-K (年报)
- 10-Q (季报)
- 8-K (当期报告)
- 10-C (年报更正)
- DEF 14A (委托声明书)
- 4 (内部人交易)
- 13F (机构持仓)
- 20-F (外国公司年报)

**数据时效性**:
- 文件: 实时披露
- 财务: 季度/年度披露

**API**: SEC EDGAR API

**优点**:
- 数据最权威
- 文件格式统一（XBRL）
- 包含所有公开披露

**缺点**:
- 只提供原始文件，需要解析
- 13F 有1.5个月滞后

## 数据验证规则

### 1. 交叉验证
- 同一数据点，从多个源验证
- 发现差异时，选择官方源

### 2. 时效性检查
- 检查数据更新时间
- 超时数据标记警告

### 3. 合理性检查
- 异常值需要额外验证
- 大幅变化需要确认

### 4. 来源标注
- 每个数据点必须标注来源
- 格式：`[数值] 来源: [来源], 日期: [日期]`

## API 使用建议

### 美股
- `yfinance` (Python) - 免费且功能全面
- `alpha_vantage` - 免费额度有限
- `quandl` - 部分免费

### A股
- `Tushare` - 需要积分
- `AkShare` - 免费但需维护
- `Baostock` - 免费但数据不全

### 港股
- `yfinance` - 支持港股代码
- 港交所 API - 需要申请
