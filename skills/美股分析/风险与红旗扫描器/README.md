# 风险与红旗扫描器

## 概述

风险与红旗扫描器提供**尽职调查级别风险分析**能力，系统识别公司潜在风险。

## 核心特性

- ✅ **财务健康风险**：债务、现金流、利润率、现金续航
- ✅ **内部人与机构**：内部人交易、高管离职、机构变化、做空比例
- ✅ **业务集中度**：收入/客户/地域集中度
- ✅ **竞争威胁**：竞争对手、颠覆性威胁、市场状态
- ✅ **监管法律**：诉讼、调查、合规历史
- ✅ **会计质量**：GAAP差距、审计意见、财报重述
- ✅ **宏观敏感度**：利率、衰退、汇率

## 数据源

| 数据源 | 用途 |
|-------|------|
| SEC EDGAR | Form 4、13F、10-K/10-Q |
| 公司官网 | 公告、高管变动 |
| Bloomberg/Reuters | 监管新闻 |
| Yahoo Finance | 做空数据 |
| IDC/Gartner | 竞争数据 |

## 风险证据要求

- 每个风险必须有数据/文件/报道支持
- 无证据标注"暂无当前风险 — 持续监控"
- 标注格式：来源 + 日期

## 注意事项

1. 证据驱动分析
2. 不臆测风险
3. 巴菲特原则：不要亏钱
4. 不构成投资建议
