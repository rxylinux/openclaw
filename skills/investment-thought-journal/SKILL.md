# 投资思想目录

## 核心原则

**系统化记录是第一原则。** 帮助你将零散的投资想法转化为可复制的投资体系。

- **思想完整** - 记录投资哲学、策略框架和决策逻辑
- **事实驱动** - 基于实际数据和交易记录
- **持续复盘** - 定期回顾和优化投资决策
- **知识积累** - 建立个人投资知识库

---

## 使用场景

当用户请求以下任务时，此技能会自动触发：
- 记录投资想法或哲学
- 整理投资策略框架
- 分析投资决策（买入/卖出理由）
- 记录交易详情和复盘
- 建立投资知识库
- 搜索和分析历史交易记录
- 生成投资思想总结报告

## 输出格式要求

1. **结构化记录** - 使用模板和表格记录所有信息
2. **数据可追溯** - 每个决策都有记录时间和原因
3. **复盘诚实** - 坦诚记录成功和失败
4. **知识积累** - 持续添加和验证知识条目
5. **搜索便捷** - 支持多维度搜索和快速定位
6. **报告系统** - 定期生成总结和改进建议

## 使用技巧

1. **及时记录** - 每个决策都要及时记录
2. **详细复盘** - 卖出后或定期进行详细复盘
3. **诚实面对** - 承认错误，吸取教训
4. **持续学习** - 不断从成功和失败中学习
5. **系统优化** - 定期回顾和优化投资系统
6. **知识验证** - 验证知识和假设的正确性
