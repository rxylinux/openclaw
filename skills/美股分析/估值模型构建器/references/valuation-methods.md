# 估值方法参考

## 概述

估值模型构建器采用**5种估值方法**，系统评估公司内在价值。

## 5个估值维度

### 第1步：DCF模型
- 现金流预测
- WACC计算
- 终值计算
- 敏感性分析

### 第2步：可比公司法
- 选择5家可比公司
- 对比估值倍数
- 计算合理价格

### 第3步：历史估值
- 5年P/E历史
- 高点/低点分析
- 估值位置判断

### 第4步：分析师目标价
- 华尔街目标价汇总
- 最高/最低/中位数
- 近期更新频率

### 第5步：情景分析
- 乐观情景
- 基准情景
- 悲观情景
- 概率加权

## DCF关键参数

### WACC组成
```
WACC = Ke × E/(E+D) + Kd × D/(E+D) × (1-T)

Ke = Rf + β × (Rm - Rf)
Kd = 债务利率 × (1 - T)
```

### 关键输入
- Rf（无风险利率）：10年期美债
- β（Beta）：股票波动率
- Rm - Rf（股权风险溢价）：6-7%
- T（税率）：有效税率

## 常用倍数

| 倍数 | 适用场景 | 计算方式 |
|------|---------|---------|
| P/E | 盈利公司 | 股价/EPS |
| P/S | 亏损/高增长 | 股价/每股营收 |
| EV/EBITDA | 资本密集型 | EV/EBITDA |
| P/B | 金融/周期型 | 股价/BPS |

## 假设来源优先级

1. **公司指引**（最权威）
2. **分析师预期**（市场共识）
3. **历史趋势**（数据支撑）
4. **行业数据**（外部验证）
5. **[ASSUMPTION]**（明确标注）
