# 商业理解提示指南

## 核心原则

用**大白话**讲清楚这家公司的生意，让小学生都能听懂。

## 必须回答的三个问题

### 1. 这家公司解决什么问题？

**错误示例**:
- ❌ "公司提供云计算解决方案和企业级SaaS服务"
- ❌ "专注于人工智能算法优化和数据挖掘"

**正确示例**:
- ✅ "帮老板管仓库，用摄像头数货，不用人拿着本子抄"
- ✅ "让医生看病更快，系统自动帮你分析片子，不用等专家"
- ✅ "帮电商老板盯着库存，卖完了自动补货，不压货也不缺货"

### 2. 谁为此付费？

**错误示例**:
- ❌ "To B企业客户，包括制造业、零售业、物流业"
- ❌ "目标市场为大型企业和政府机构"

**正确示例**:
- ✅ "开超市的、管仓库的、做电商的老板"
- ✅ "大工厂厂长、物流公司经理、快递站老板"
- ✅ "想省钱的小店老板、大公司的采购经理"

### 3. 为什么客户选择它而不是替代品？

**错误示例**:
- ❌ "凭借技术壁垒和规模效应，公司保持竞争优势"
- ❌ "差异化战略和成本领先优势明显"

**正确示例**:
- ✅ "比人管便宜一半，而且24小时盯着不睡觉"
- ✅ "用过的都说比原来快3倍，出错了还能自动修"
- ✅ "别人家要培训半个月才能上手，这家3天就能用"
- ✅ "别家坏了要等一周，这家4小时就有人上门"

## 语言风格指南

### ❌ 避免的术语

| 禁用词 | 替换为 |
|------|--------|
| 营收/收入 | 每年卖多少 |
| 净利润 | 赚了多少钱 |
| 毛利率 | 每卖100块能赚多少 |
| 市盈率 | 几年赚回本 |
| 资产负债率 | 借的钱占总资产的几成 |
| ROE | 投进去100块每年能赚回多少 |
| 周转率 | 东西转手有多快 |
| CAGR | 平均每年涨多少 |
| To B/To C | 卖给公司/卖给个人 |
| SaaS | 租来用的软件 |
| 解决方案 | 帮你办这个事 |
| 痛点 | 烦人的地方 |
| 护城河 | 别人抄不来的本事 |

### ✅ 推荐的表达方式

**描述产品/服务**:
- "这是个软件，装上就能用，不用自己买服务器"
- "这东西像个智能管家，自动干这干那，不用人盯着"
- "这是门生意，客户按月付钱，你给他服务"

**描述客户选择原因**:
- "便宜：比原来省一半钱"
- "省事：不用招人，也不用培训"
- "放心：坏了有人管，出了问题能找着人"
- "好用：傻瓜式操作，老人小孩都会用"

**描述商业模式**:
- "卖产品：卖一个赚一个的钱"
- "收租金：客户按月付钱，你一直提供服务"
- "抽成：每帮他做成一笔生意，你分一杯羹"

## 行业举例模板

### 软件/SaaS类

**原始信息**:
- "云计算PaaS平台，支持多租户架构，服务于企业数字化转型"

**商业理解**:
```
这家公司给大老板们卖个"云账本"，不用自己建机房、买服务器，
按月交租金就能用。相当于把办公室电脑都搬到了云端，
数据安全、扩容方便、成本比自己搞省一半。

客户主要是大公司的IT部门，不想管服务器硬件、
不想招人维护、不想担心数据丢了，就租他们家的。
为什么不选别的？他家做的早、客户多、用得放心，
出了问题24小时有人管，小公司可没这本事。
```

### 制造/硬件类

**原始信息**:
- "新能源汽车热管理系统供应商，一体化压铸技术领先"

**商业理解**:
```
帮电车做"空调"，电池太热会坏，太冷也不行。
他们家的东西能把热量管得刚刚好，夏天不趴窝，冬天续航长。

客户主要是造电动车的厂，每卖一辆车都要装这个系统。
为什么选他们家？技术牛，别人压铸的件有毛边、容易裂，
他们家的又轻又结实，还比别人便宜20%。
造电动车的都想省成本、保证质量，所以都愿意买他们的。
```

### 医药/生物类

**原始信息**:
- "创新药研发企业，专注于肿瘤靶向治疗领域"

**商业理解**:
```
帮癌症病人做"新药"，传统化疗好坏细胞一起杀，
他们家的药能精准找到癌细胞，只打坏人，不伤好人。

客户主要是大医院和医保局，病人需要，他们就得买。
为什么买他们的？药比别人家有效，副作用小，
而且已经做了很多年临床试验，医生敢开，病人也信。
新药开发很难，别家想抄也没那么快抄出来。
```

### 零售/消费类

**原始信息**:
- "连锁休闲食品品牌，主打高端零食市场"

**商业理解**:
```
给想吃点好的年轻人卖零食，不是超市那种便宜货，
是包装精美、味道独特、能在朋友圈晒的那种。

客户主要是爱追新潮的年轻人，舍得花钱买点好的。
为什么买他们家的？味道确实不一样，包装好看能拍照发圈，
而且到处都有店，饿了馋了随时能买到，网购也方便。
别家也想做，但味道和品牌调性没那么容易复制。
```

## 快速检查清单

在输出商业理解前，问自己：

- [ ] 能不能用"赚钱/省事/放心/好用"这种词描述？
- [ ] 能不能用具体例子（"大老板"、"工厂厂长"）？
- [ ] 能不能让小学生听懂？
- [ ] 有没有用"解决方案/SaaS/护城河"这种术语？
- [ ] 能不能用一句话讲清楚"谁、为什么"？

## 常见错误

### 错误1：用词太专业
❌ "公司提供端到端供应链协同解决方案"
✅ "帮工厂管进货和发货，自动协调，不用人打电话催"

### 错误2：只讲不说价值
❌ "公司主要收入来源是SaaS订阅服务"
✅ "软件按月收租金，客户一直用，他们就一直收钱，生意很稳"

### 错误3：不讲竞争理由
❌ "公司在行业内具有竞争优势"
✅ "别家东西便宜但不稳定，他们家虽然贵点但好用，客户都买贵不买贱"

### 错误4：没有场景感
❌ "服务于B端企业客户"
✅ "开饭馆的、管商场的、开便利店的老板"
