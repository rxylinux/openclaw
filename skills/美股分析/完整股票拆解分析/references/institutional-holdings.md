## 数据来源

### SEC 文件（最权威）

- **13F-HR**：季度机构持仓报告
  - 大型机构投资者（管理资产>1亿美元）必须提交
  - 每季度提交（45天内）
  - SEC EDGAR 数据库

- **13G/G**：5%以上大股东披露

### 数据平台

- **WhaleWisdom**：专门追踪13F数据
- **SEC EDGAR**：官方来源
- **Bloomberg Terminal**
- **FactSet**
- **Nasdaq.com**

### 免费来源

- Nasdaq.com（Institutional Holdings）
- Yahoo Finance（Major Holders）
- Finviz.com（Ownership）
- SEC EDGAR 数据库

## 数据获取方法

### SEC EDGAR API

```python
import requests

# 获取13F文件
def get_13f_filing(cik):
    url = f"https://www.sec.gov/files/edgar/data/{cik}.txt"
    response = requests.get(url)
    return response.text
```

## 重要注意事项

1. **数据滞后**：
   - 13F报告有45天提交期
   - 数据可能滞后1-2个月
   - 需标注"数据可能已过期"

2. **披露门槛**：
   - 仅管理资产>1亿美元的机构需披露
   - 小型机构动向可能不可见

3. **投资风格差异**：
   - 指数基金：被动跟踪
   - 主动基金：主动选择
   - 对冲基金：策略多样

4. **季度变动解读**：
   - 增持≠看好（可能是指数基金被动增仓）
   - 减持≠看空（可能是获利了结）
   - 需结合具体机构类型分析

## 数据时效性标注

- **13F数据**：标注具体季度和提交日期
- **季度变动**：对比前后两个季度
- **超期警告**：数据超过90天需标注"数据可能已过期"
