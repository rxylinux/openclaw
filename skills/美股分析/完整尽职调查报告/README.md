# 完整尽职调查报告

顶级投行级别的股票首次覆盖正式报告生成工具。

## 概述

本技能按照 Goldman Sachs、Morgan Stanley、JPMorgan Chase 等顶级投行的标准，生成专业级的投资研究报告。

## 核心特性

- **8个完整部分**：覆盖从执行摘要到最终结论的完整报告结构
- **严格数据标注**：每个财务指标都标注来源和日期
- **三情景分析**：Bull/Base/Bear情景及概率加权期望值
- **专业估值方法**：DCF、相对估值、历史估值区间
- **全面风险评估**：前5大实质性风险及监测指标
- **催化剂时间表**：未来12个月关键事件日历

## 报告结构

1. **执行摘要** - 三句话投资逻辑、评级、目标价
2. **业务概览** - 商业模式、竞争壁垒、收入拆解
3. **财务深度分析** - 关键指标、资产负债表、现金流、资本配置
4. **增长分析** - TAM、市场份额、增长驱动因素
5. **估值分析** - DCF、可比公司、历史估值、情景分析
6. **风险分析** - 实质性风险、做空比例、会计质量
7. **催化剂时间表** - 近期事件、宏观催化剂
8. **最终结论** - 三情景汇总、概率加权、最终评级

## 使用场景

- 首次覆盖报告
- 投资决策支持
- 尽职调查
- 投资者教育
- 研究报告模板
