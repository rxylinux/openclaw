|-----------|----------------|-----------|---------|
| 经营活动现金流（OCF） | $XXX | XX.X% | +X.X% |
| 投资活动现金流（ICF） | -$XXX | -XX.X% | +X.X% |
| 筹资活动现金流（FCF） | -$XXX | -XX.X% | +X.X% |
| **自由现金流（FCF）** | **$XXX** | **X.X%** | **+X.X%** |

*数据来源：现金流量表，报告日期：YYYY-MM-DD*

### 计算公式

**经营现金流（OCF）**：
```
从现金流量表直接获取
```

**资本支出（Capex）**：
```
资本支出 = 投资活动现金流中的资本支出（通常为负数）
```

**自由现金流（FCF）**：
```
自由现金流 = 经营现金流 - 资本支出
FCF利润率 = 自由现金流 / 营收 × 100%
```

*数据来源：现金流量表和利润表，报告日期：YYYY-MM-DD*

### 质量评估

| OCF/净利润比率 | 评估 |
|--------------|------|
| > 1.2 | 优秀 - 盈利质量高 ✅ |
| 1.0 - 1.2 | 良好 - 盈利质量正常 ✅ |
| 0.8 - 1.0 | 一般 - 需关注 ⚠️ |
| < 0.8 | 警告 - 盈利质量差 ⚠️⚠️ |

**解释**：
- OCF > 净利润：通常健康，说明利润有现金支撑
- OCF < 净利润：可能存在问题，如应收账款增加、存货积压

|---------|---------|-----------|-----------|
| Q1 | $XXX | X.X% | XXX% |

| Q3 | $XXX | X.X% | XXX% |
| Q4 | $XXX | X.X% | XXX% |

*数据来源：现金流量表，报告日期：YYYY-MM-DD*

### Capex评估

| 占营收比例 | 评估 |
|-----------|------|
| > 10% | 高资本支出 - 扩张期 |
| 5-10% | 中等资本支出 - 正常投资 |
| 3-5% | 低资本支出 - 维护性投资 |
| < 3% | 极低资本支出 - 可能投资不足 |

**Capex vs 折旧**：
- **Capex > 折旧**：扩张投资
- **Capex ≈ 折旧**：维护性投资
- **Capex < 折旧**：投资不足或资产老化

### 资本配置评估

**股东友好型**：
- 回购 + 分红 > 50% OCF
- 债务下降
- FCF稳定或增长

**投资扩张型**：
- 并购 + Capex > 50% OCF
- 债务可能增加
- 短期FCF可能为负

**保守稳健型**：
- 现金储备增加
- 债务下降
- 回购分红适中

## 现金流趋势判断

### 同比对比

| 指标 | 今年TTM | 去年TTM | 变化 | 趋势 |
|------|---------|---------|------|------|
| 经营现金流 | $XXX | $XXX | +X.X% | ↗️/→/↘️ |
| 资本支出 | $XXX | $XXX | +X.X% | ↗️/→/↘️ |
| 自由现金流 | $XXX | $XXX | +X.X% | ↗️/→/↘️ |

*数据来源：现金流量表，报告日期：YYYY-MM-DD*

### 趋势解读

**经营现金流趋势**：
- ↗️ 增长：核心业务产生现金能力增强 ✅
- → 稳定：业务成熟，现金流稳定 ✅
- ↘️ 下降：核心业务可能面临压力 ⚠️

**自由现金流趋势**：
- ↗️ 增长：现金生成能力提升，股东回报潜力增加 ✅
- → 稳定：业务稳定，可预测现金流 ✅
- ↘️ 下降：需要关注，可能影响股东回报 ⚠️

## 数据来源

### 主要来源

- **现金流量表**（Statement of Cash Flows）
- 10-K/10-Q
- 季度财报

### 关键项目

**经营活动现金流**：
- 净利润调整
- 折旧与摊销
- 营运资本变动

**投资活动现金流**：
- 资本支出
- 并购支出
- 资产处置

**筹资活动现金流**：
- 债务发行与偿还
- 股票发行与回购
- 股息支付
