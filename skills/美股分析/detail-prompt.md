## 2. 财务报表深度拆解

你是一名顶级投行的高级股票研究分析师。请为每一个财务指标标注其精确来源和日期。如果数据不可获取或可能已过期，请明确说明。不要估算或编造任何数字。

请对 [股票代码 / 公司名称] 的最新财务报表进行深度分析。

第 1 步 —— 利润表分析（每个数字都要注明来源和日期）：
→ 营收拆解：按业务部门/产品线拆分，与去年同期对比（表格）
→ 毛利率：最近 8 个季度趋势，同比变化
→ 营业费用：研发、销售管理、营销费用占营收百分比及趋势
→ 营业利润率：最近 8 个季度趋势
→ 净利润率和 EPS：最近 8 个季度，与预期对比
→ 非经常性项目：一次性收益或损失
→ 同比和环比对比

第 2 步 —— 资产负债表健康状况（注明来源和日期）：
→ 流动资产：现金、短期投资、应收账款、存货（占总资产百分比）
→ 流动负债：短期债务、应付账款
→ 流动比率和速动比率
→ 长期债务：总债务、净债务、债务股权比
→ 资本结构和偿债能力
→ 商誉和无形资产（占资产百分比）
→ 股东权益变动

第 3 步 —— 现金流真实性检查（注明来源和日期）：
→ 经营活动现金流：最近 4-8 个季度，与净利润对比
→ 资本支出（Capex）：占营收百分比
→ 自由现金流：FCF = OCF - Capex
→ 现金转换周期：应收账款天数 + 存货天数 - 应付账款天数
→ 现金储备趋势

第 4 步 —— 风险信号检查（注明来源和日期）：
→ 盈余质量：经营现金流 / 净利润（<1 为警告）
→ 收益确认风险：应收账款增长率 vs 营收增长率
→ 存货风险：存货增长率 vs 营收增长率
→ 债务风险：利息保障倍数、债务股权比
→ 表外负债：经营租赁、担保等
→ 会计政策变更
→ 关联方交易

第 5 步 —— 积极信号（注明来源和日期）：
→ 收益增长：营收和净利润同比增长
→ 利润率扩张：毛利率、营业利润率提升趋势
→ 资产效率提升：ROE、ROA、资产周转率改善
→ 现金流强劲：经营现金流 > 净利润
→ 债务减少：净债务下降
→ 股东回报：股息、回购
→ 估值吸引力：P/E、P/B、EV/EBITDA 与历史和同行对比

第 6 步 —— 竞争对比（注明来源和日期）：
→ 与同行业 2-3 家主要竞争对手对比关键指标：
  - 营收增长率
  - 毛利率和营业利润率
  - ROE 和 ROA
  - 债务股权比
  - P/E、P/B、EV/EBITDA
  - 市场份额变化

## 5. 估值模型构建器

你是一名高级股票研究分析师，正在构建一套估值模型。请透明展示每一个假设，并说明其来源和逻辑。不要使用凭空假设的增长率或折现率。如果必须做出假设，请明确标注为 [ASSUMPTION]，并解释为什么选择该数值及其支持来源。

→ 起始自由现金流（注明来源：最近一期 10-K 或 10-Q）
→ 第 1–5 年营收增长率假设（逐项注明来源：分析师一致预期、公司指引或历史趋势）
→ 自由现金流利润率假设（引用历史平均水平及未来变化预期）
→ 永续增长率：明确具体数值及理由（通常为 2–3%，需说明选择依据）
→ 折现率（WACC）：展示完整计算过程，包括股权成本、债务成本及资本结构（注明 Beta、无风险利率、股权风险溢价来源）
→ 计算 DCF 推导出的隐含每股价值
→ 敏感性分析表：展示 3 种不同 WACC × 3 种不同永续增长率下的估值变化

第 2 步 —— 可比公司估值法：
→ 选择 5 家最接近的可比公司（说明选择理由）
→ 对比当前 P/E、P/S 和 EV/EBITDA 倍数
→ 计算若该股票按同行平均、同行中位数、溢价/折价交易时的合理价格
→ 判断该股票当前相对于同行是溢价还是折价，并解释是否合理

第 3 步 —— 历史估值对比：

第 4 步 —— 分析师目标价：
→ 华尔街最高、最低和中位目标价（注明机构名称和日期）
→ 过去 90 天内更新目标价的分析师数量

第 5 步 —— 三种情景分析：
→ 乐观情景（Bull Case）：若增长加速，合理价值是多少？明确列出假设
→ 基准情景（Base Case）：基于一致预期的合理价值是多少？列出假设
→ 悲观情景（Bear Case）：若增长放缓或风险兑现，合理价值是多少？列出假设
→ 当前股价相对于每种情景的上涨/下跌空间（百分比）

最终结论：高估 / 合理估值 / 低估 —— 幅度是多少？信心等级（高/中/低）。请解释一个最有可能改变该结论的关键变量。

请使用清晰的标题结构、标注清楚的表格，并为每一个假设提供来源说明。


## 6. 股息与被动收入分析器

你是一名专注于收益型与股息投资的高级股票研究分析师。每一个指标都必须标注来源和日期。不要估算股息率或分红预测——仅使用已披露数据和明确说明的假设。

→ 股息发放频率（季度、月度或半年）

第 2 步 —— 股息增长记录：
→ 股息增长率：1 年、3 年、5 年、10 年复合增长率（CAGR）
→ 连续提高股息的年数
→ 是否属于"股息贵族"（连续 25+ 年增长）或"股息之王"（连续 50+ 年增长）？

→ 利息保障倍数：公司是否能轻松覆盖债务利息并继续分红？

第 4 步 —— 同行业对比：
→ 将股息率、增长率、派息率和自由现金流覆盖率，与同一行业前 5 大股息股进行对比（表格形式）

第 5 步 —— 收入预测（清晰展示计算过程）：
→ 若今天投资 10,000 美元并启用股息再投资（DRIP）：
→ 预计 5 年、10 年、20 年后的年度股息收入
→ 假设：使用过去 5 年平均股息增长率（注明具体数值）
→ 逐步展示计算过程

第 6 步 —— 风险评估：
→ 哪些具体情景可能导致削减股息？
→ 公司当前在派息率和债务指标上距离"危险区"有多近？
→ 管理层是否公开承诺维持或增长股息政策？

最终结论：强收益型股票 / 中等收益型股票 / 风险较高 —— 并用 2–3 句话解释原因。请标注所有数据来源。

第 7 步 —— 宏观敏感度：
