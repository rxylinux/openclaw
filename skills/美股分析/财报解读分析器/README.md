# 财报解读分析器

## 概述

财报解读分析器提供**6维度财报分析**能力，深入分析最新财报数据、管理层指引、市场反应等。

## 核心特性

- ✅ **核心数据分析**：营收/EPS vs 预期、一次性项目
- ✅ **前瞻指引**：指引调整、管理层措辞分析
- ✅ **业务拆解**：各板块表现、驱动因素
- ✅ **管理层评论**：CEO/CFO发言、语气评估
- ✅ **市场反应**：股价变动、分析师评级变化
- ✅ **最终结论**：关键数字、季度质量评估

## 数据源

| 数据源 | 用途 |
|-------|------|
| SEC EDGAR | 10-Q/10-K财报 |
| 公司官网IR | 财报新闻稿 |
| Seeking Alpha | 会议记录 |
| Yahoo Finance | 股价、预期 |
| Bloomberg | 分析师评级 |

## 注意事项

1. 每个数字标注来源
2. 区分确认数据与预测
3. 不编造引用或财务指标
4. 如会议纪要未发布，明确标注
