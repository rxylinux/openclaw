# 投资随想复盘系统

## 📋 概述

系统化记录和复盘投资决策，帮助形成稳定的投资体系和持续的改进机制。

---

## 🎯 核心目标

1. **决策记录** - 捕捉每次投资决策的思考过程
2. **事后复盘** - 评估决策的正确性和偏差
3. **认知提升** - 发现思维模式，改进投资系统
4. **情绪管理** - 记录情绪波动对决策的影响

---

## 📁 目录结构

```
investment-thought-journal/
├── README.md                 # 本文件
├── template.md              # 每周复盘模板
├── weekly/                  # 每周复盘记录
│   └── YYYY-WXX.md          # 按周编号
├── insights/                # 投资洞察总结
│   ├── market-insights.md   # 市场认知
│   ├── self-insights.md     # 自我认知
│   └── strategy-insights.md # 策略洞察
└── decisions/               # 重要决策记录
    ├── buy-decisions.md     # 买入决策
    └── sell-decisions.md    # 卖出决策
```

## 🔄 使用流程

### 每日记录（可选）

使用 `daily-YYYY-MM-DD.md` 快速记录当日重要思考：
- 市场观察
- 新的认知
- 情绪变化
- 决策冲动

### 每周复盘（推荐）

每周日晚上使用 `template.md` 进行系统性复盘：

1. **本周交易回顾**
   - 买入/卖出操作
   - 持仓变动
   - 收益统计

2. **决策质量评估**
   - 每次决策的理由是否充分
   - 是否有冲动交易
   - 情绪状态如何

3. **市场认知更新**
   - 新的行业/公司认知
   - 宏观环境变化
   - 资金流向观察

4. **自我反思**
   - 本周做得好的地方
   - 需要改进的地方
   - 下周重点关注

5. **策略调整**
   - 策略是否需要微调
   - 新的风险识别
   - 下周计划

## 📊 复盘框架

### 四步复盘法

参考 [AI投资复盘系统](https://github.com/AIPMAndy/ai-invest-agent) 的方法论：

#### 1. 宏观扫描
- 利率环境
- 流动性状况
- 政策变化
- 风险偏好

#### 2. 板块分析
- 热点板块轮动
- 资金流向
- 估值水位
- 政策催化

#### 3. 温度计评估
- 主要指数PE/PB分位
- 行业估值对比
- 恐慌贪婪指数
- 市场情绪

#### 4. 标的决策
- 个股基本面
- 买入/卖出时机
- 仓位管理
- 止盈止损计划

---

## 💡 使用建议

1. **诚实记录** - 不美化失败，不忽略侥幸
2. **数据驱动** - 用数字说话，避免主观臆断
3. **定期回顾** - 每月回顾洞察，每季度评估策略
4. **持续优化** - 根据复盘结果调整策略

## 🔧 自动化

系统会自动：
- 每周日提醒进行复盘
- 生成复盘报告摘要
- 识别重复错误模式

## 📈 成长指标

**认知成长**：
- 认知深度（从表面到本质）
- 认知广度（从单点到系统）
- 认知速度（从慢速到快速）

**决策质量**：
- 决策准确性（成功率）
- 决策一致性（偏离度）
- 决策及时性（反应速度）

**情绪控制**：
- 恐慌频率
- 贪婪频率
- 恢复速度
