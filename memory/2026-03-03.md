### AI 投资复盘系统

**链接**: https://github.com/AIPMAndy/ai-invest-agent

**简介**: AI 驱动的投资复盘系统，从"拍脑袋"到"有体系"

**核心功能**:
- 🌡️ 温度计量化估值系统（PE历史分位 × 100）
- 📊 四步复盘法（宏观 → 板块 → 温度计 → 标的）
- 🌏 跨市场覆盖（A股20个 + 港股8个 + 美股5个指数）
- 📈 10维度持仓深度评估
- 📄 多格式输出（MD/DOCX/XLSX）

**温度计操作建议**:
- 0-30℃ 🟢 低估 → 买入区间
- 30-50℃ 🟡 合理 → 持有观望
- 50-100℃ 🔴 高估 → 逐步卖出

**使用场景**:
- 周末复盘：系统性回顾本周行情
- 每日快检：5分钟掌握市场状态
- 买入决策：温度计判断估值位置
- 持仓管理：10维度深度评估

**技术特点**:
- 零代码上手，加载 Prompt 即用
- Prompt 驱动，支持 Claude/ChatGPT/Kimi
- Apache 2.0 许可（个人免费，企业可商用）
