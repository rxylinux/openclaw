# 全市场金融分析 Agent - 快速开始

## 简介

全市场金融分析 Agent 是一个顶级投行级别的智能金融分析系统，支持 **A股、美股、港股** 三大市场的完整分析。

## 投资评级标准

| 评级 | 定义 | 适用条件 | 目标涨幅 |
|------|------|----------|----------|
| **Strong Buy 强烈买入** | 极具吸引力 | 潜在涨幅 > 20%，风险可控 | >20% |
| **Buy 买入** | 具有吸引力 | 潜在涨幅 10%-20% | 10%-20% |
| **Hold 持有** | 观望为主 | 潜在涨幅 ±10% | ±10% |
| **Sell 卖出** | 减持/规避 | 潜在跌幅 > 10% | <-10% |

## 报告结构

### 单股分析报告

1. **基本信息**
   - 股票代码、当前价格、市场、行业

2. **投资评级**
   - Strong Buy / Buy / Hold / Sell
   - 评级理由

3. **目标价**
   - 12个月目标价
   - 上涨/下跌空间
   - 估值方法

4. **操作建议**
   - 建仓价格区间
   - 止损位
   - 目标价分阶段

5. **关键亮点**
   - 3个核心优势

6. **关键风险**
   - 3个主要风险

7. **详细分析**
   - 公司概览
   - 关键财务数据
   - 股价表现
   - 华尔街预期
   - 机构动向

8. **风险扫描**
   - 7维度风险分析

9. **数据来源**
   - 所有数据源和日期

## 数据标注规则

### 每个数据点必须标注来源和日期

**格式：**
```
[数值] 来源: [来源], 日期: [日期]
```

**示例：**
```
营收 $123.4B 来源: 10-K, 日期: 2024-12-31
市盈率 25.3 来源: Yahoo Finance, 日期: 2024-03-01
```

### 时效性标记

- 超过30天：`⚠️`
- 超过90天：`🚨`

### 假设标注

必须标注为 `[ASSUMPTION]` 并说明依据

**示例：**
```
长期增长率 3% [ASSUMPTION] 基于行业平均水平
```

## 常见问题

### Q1: 支持哪些市场？

**A:** A股、美股、港股 三大市场全支持。

### Q2: 数据从哪里来？

**A:** 多个权威数据源交叉验证，包括：
- 官方披露（财报、公告）
- 第三方权威（Bloomberg、FactSet）
- 市场数据（Yahoo Finance）

### Q3: 投资建议可靠吗？

**A:** 所有建议基于公开数据分析，不构成投资建议。投资有风险，决策需谨慎。

### Q4: 可以分析多少只股票？

**A:** 单次分析：
- 单股：无限制
- 对比：2-5只
- 投资组合：建议不超过20只

### Q5: 数据时效性如何？

**A:**
- 股价、估值倍数：1天内
- 财报数据：90天内
- 年报数据：365天内
- 超时数据会标记 ⚠️
