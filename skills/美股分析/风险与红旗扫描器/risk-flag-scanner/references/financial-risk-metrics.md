# 财务风险指标说明

## 债务风险指标

### 债务增长率 vs 营收增长率

**定义：** 比较债务增长速度与业务增长速度，评估财务健康度。

**计算：**
```
债务增长率 = (本期债务 - 上期债务) / 上期债务 × 100%
营收增长率 = (本期营收 - 上期营收) / 上期营收 × 100%
增长差值 = 债务增长率 - 营收增长率
```

**风险评估：**
- 增长差值 > 10%：🚨 高风险 — 债务增速远超营收增速
- 增长差值 5%-10%：⚠️ 中等风险
- 增长差值 < 5%：✅ 相对健康

### 债务到期结构

**定义：** 未来各时间段需要偿还的债务金额。

**风险阈值：**
- 未来12个月到期 > 总债务20%：⚠️ 再融资压力
- 未来24个月到期 > 总债务40%：🚨 高再融资风险

### 债务/EBITDA

**定义：** 衡量公司偿还债务能力的指标。

**计算：**
```
债务/EBITDA = 总债务 / EBITDA
```

**风险评估：**
- < 3.0：✅ 健康
- 3.0 - 5.0：⚠️ 中等风险
- > 5.0：🚨 高风险

### 利息保障倍数

**定义：** 公司支付利息的能力。

**计算：**
```
利息保障倍数 = EBITDA / 利息支出
```

**风险评估：**
- > 5.0：✅ 强
- 3.0 - 5.0：⚠️ 中等
- 1.5 - 3.0：🟡 偏弱
- < 1.5：🚨 危险

## 现金流风险指标

### 自由现金流（FCF）

**定义：** 经营活动产生的现金减去资本支出后的净现金。

**计算：**
```
自由现金流 = 经营活动现金流 - 资本支出
```

**趋势分析：**
- 连续3年下降：⚠️ 警告信号
- 连续2年负值：🚨 红旗

### 现金燃烧率（Burn Rate）

**定义：** 负自由现金流公司每月消耗现金的速度。

**计算：**
```
现金燃烧率 = |负自由现金流| / 12
```

### 现金续航（Runway）

**定义：** 按当前消耗速度，现金能维持的时间。

**计算：**
```
续航月数 = 现金及现金等价物 / 月度燃烧率
```

**风险评估：**
- > 24个月：✅ 充足
- 12-24个月：⚠️ 适中
- 6-12个月：🟡 紧张
- < 6个月：🚨 危险

## 利润率风险指标

### 毛利率压缩

**定义：** 毛利率连续下降表明定价能力减弱或成本上升。

**计算：**
```
毛利率 = (营收 - 销货成本) / 营收 × 100%
```

**红旗信号：**
- 连续4个季度下降
- 下降幅度 > 500个基点（5%）

### 营业利润率

**定义：** 反映核心业务盈利能力。

**计算：**
```
营业利润率 = 营业利润 / 营收 × 100%
```

### 净利率

**定义：** 最终盈利能力。

**红旗信号：**
- 从正转负
- 连续大幅下降

## 资产质量指标

### 应收账款周转天数

**定义：** 收回账款的平均天数。

**计算：**
```
应收账款周转天数 = (应收账款 / 营收) × 365
```

**风险评估：**
- 天数上升：⚠️ 回款变慢
- 比行业平均高30%以上：🚨 可能存在坏账风险

### 存货周转天数

**定义：** 销售存货的平均天数。

**计算：**
```
存货周转天数 = (存货 / 销货成本) × 365
```

**红旗信号：**
- 天数大幅上升：⚠️ 可能存在库存积压
- 周转天数 > 行业平均1.5倍：🚨 库存风险

---

## 盈利质量指标

### GAAP 与非 GAAP 差距

**定义：** 调整后盈利与官方盈利的差距。

**计算：**
```
差距金额 = 调整后净利润 - GAAP净利润
差距比例 = 差距金额 / |GAAP净利润| × 100%
```

**红旗信号：**
- 差距 > 20%：⚠️ 关注
- 差距 > 50%：🚨 盈利质量存疑

### 经常性 vs 非经常性项目

**红旗信号：**
- 频繁出售资产/业务以提振利润
- 一次性项目占利润比例 > 30%

## 财务比率风险阈值

| 比率 | 安全 | 警告 | 危险 |
|------|------|------|------|
| 流动比率 | > 2.0 | 1.5-2.0 | < 1.5 |
| 速动比率 | > 1.0 | 0.8-1.0 | < 0.8 |
| 债务/股权 | < 1.0 | 1.0-2.0 | > 2.0 |
| 债务/EBITDA | < 3.0 | 3.0-5.0 | > 5.0 |
| 利息保障倍数 | > 5.0 | 3.0-5.0 | < 3.0 |
