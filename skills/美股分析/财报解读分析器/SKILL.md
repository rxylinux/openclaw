# 财报解读分析器

## 概述

本技能提供美股公司**财报深度解读分析**能力，包括：
- **第1步 —— 核心数据**：营收、EPS vs 预期，一次性项目
- **第2步 —— 前瞻指引**：管理层指引调整、措辞分析
- **第3步 —— 业务板块拆解**：各业务表现、驱动因素
- **第4步 —— 管理层评论**：CEO/CFO发言、语气评估
- **第5步 —— 市场反应**：股价变动、分析师评级变化
- **第6步 —— 最终结论**：关键数字、季度评估、下季关注点

**核心原则**：
- ✅ 每个数字标注来源
- ✅ 区分确认数据与前瞻性预测
- ✅ 不编造引用或财务指标
- ✅ 引用真实会议纪要并标注来源
- ✅ 如会议纪要未发布，明确标注说明

## 快速开始

### 解读最新财报
当用户询问"解读苹果最新财报"时：

1. 获取最新财报数据和预期对比
2. 分析管理层指引变化
3. 拆解业务板块表现
4. 提取管理层评论
5. 分析市场反应
6. 给出最终结论

## 核心能力

### 第1步 —— 核心数据

**核心目标**：
- 对比实际与预期
- 识别超预期/不及预期
- 分析一次性项目影响

**必须包含的内容**：

→ **营收分析**：
- 市场预期营收
- 实际营收
- 差额（美元和百分比）
- 超预期/不及预期

→ **EPS分析**：
- 预期EPS
- 实际EPS
- 差额
- 超预期/不及预期

→ **一次性项目**：
- 是否存在一次性项目
- 调整后数据
- GAAP数据
- 差异分析

**输出模板**：


## 数据获取方式

### 主要数据源

1. **SEC EDGAR**：10-Q/10-K财报（官方数据）
2. **公司官网IR**：财报新闻稿、业绩材料
3. **Seeking Alpha**：财报会议文字记录
4. **Yahoo Finance**：股价数据、分析师预期
5. **Bloomberg**：分析师评级变化

### 获取顺序

1. 先获取SEC 10-Q/10-K（确认数据）
2. 再获取会议记录（管理层观点）
3. 最后获取市场反应（股价、评级）

### 如会议纪要未发布

如财报会议纪要尚未发布：
- 明确标注："⚠️ 财报会议纪要尚未发布"
- 使用财报新闻稿替代
- 使用分析师报告替代
- 建议稍后更新

## 注意事项

1. **来源标注**：每个数字必须标注来源和日期
2. **区分数据类型**：明确区分确认数据与预测
3. **不编造**：不编造引用或财务指标
4. **引用准确**：引用管理层原话并标注时间戳
5. **合规要求**：不构成投资建议，仅作分析
