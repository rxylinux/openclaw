# 8个必备股票网站配置

## 网站详细信息

### 1. 财联社
- **域名：** caifinance.com
- **类型：** 官方金融新闻平台
- **功能：** 24小时实时新闻推送、公司公告、政策解读
- **特色：** 消息快到离谱，盘中就能接到弹窗

### 2. 开盘啦
- **域名：** kaipanla.com
- **类型：** 市场情绪可视化工具
- **功能：** 板块热度、个股异动、隔夜挂单
- **特色：** 直观传递市场情绪起伏，提前预判风险

### 3. 淘股吧
- **域名：** taoguba.com.cn
- **类型：** 股民交流社区
- **功能：** 股票讨论、实战经验分享、游资大佬发言
- **特色：** "股市里的黄埔军校"，很多游资大佬从这里走出来

### 4. 雪球网
- **域名：** xueqiu.com
- **类型：** 高端投资者智慧平台
- **功能：** 游资大佬专栏、深度研报、机构调研纪要
- **特色：** 国内顶级游资聚集地，"抄作业"天堂

### 5. 韭研公社
- **域名：** jiucaigongshe.com
- **类型：** 逻辑派投资者聚集地
- **功能：** 个股题材挖掘、炒作路径、事件日历
- **特色：** 提前捕捉风口，比别人早一步布局

### 6. 萝卜投研
- **域名：** luobotou.com
- **类型：** 顶级研报和数据平台
- **功能：** 整合各大券商研究报告、深度数据推演
- **特色：** 提供深度数据推演和逻辑支撑

### 7. 巨潮资讯
- **域名：** jucho.com
- **类型：** 官方信息第一出口
- **功能：** 所有公告、政策、内幕消息
- **特色：** 官方信息第一出口，信息差来源

### 8. 选股通
- **域名：** xuangutong.com
- **类型：** 热点题材拆解
- **功能：** 热点板块排名、涨停家数统计、深度解析
- **特色：** 直接锁定核心标的，节省大量时间

## 使用方法

```bash
# 在所有8个股票网站中搜索
python3 skills/baidu-search/scripts/search.py '{"query":"中芯国际","search_sites":"all"}'

# 在指定网站中搜索（编号1-8）
python3 skills/baidu-search/scripts/search.py '{"query":"中芯国际","search_sites":"1,2,3"}'

# 在财联社和巨潮资讯中搜索
python3 skills/baidu-search/scripts/search.py '{"query":"中芯国际","search_sites":"1,7"}'
```
