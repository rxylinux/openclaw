# 美股分析框架

## 概述

美股分析框架采用**5维度投行级别分析**方法，每个维度都有明确的分析标准、输出模板和检查清单。

## 5个分析维度

### 第1步 —— 公司概览

**核心目标**：
- 用通俗易懂的语言解释公司业务
- 说明业务模式和所有收入来源
- 按总收入百分比拆分收入结构
- 用一句话总结核心竞争优势

**必须包含的内容**：
→ 公司业务描述（大白话）
→ 业务模式与收入来源（百分比拆分）
→ 核心竞争优势（一句话）

**输出模板**：
```
### 第1步 —— 公司概览

**公司业务**：
[用大白话解释公司做什么]

**业务模式与收入来源**：
- 业务A（XX%）：[说明]
- 业务B（XX%）：[说明]

**核心竞争优势**：
[一句话总结]
```

### 第2步 —— 关键财务数据

**核心目标**：
- 获取最新财务数据（TTM和最近季度）
- 每个数字标注来源和日期
- 计算同比变化
- 评估财务健康度

**必须包含的指标**：
→ 营收数据（TTM、最近季度、同比）
→ 利润数据（净利润、EPS）
→ 估值指标（P/E、Forward P/E、P/S、PEG）
→ 财务健康指标（资产负债率、总债务、自由现金流）

**数据来源要求**：
- 每个指标后标注：来源 + 日期
- 示例：`营收：$3833亿（来源：Yahoo Finance，日期：2025-02-20）`
- 数据超过30天时标注：⚠️ 数据超过30天，可能已过期

### 第3步 —— 股价表现

**核心目标**：
- 获取各时间段价格变动数据
- 计算精确百分比变化
- 与标普500同期对比
- 识别相对强弱

**必须包含的内容**：
→ 价格变动（1个月、3个月、6个月、1年、YTD）
→ 价格区间（52周最高价、最低价）
→ 与标普500对比（各时间段跑赢/跑输）

### 第4步 —— 华尔街一致预期

**核心目标**：
- 获取分析师评级分布
- 获取目标价数据
- 识别最新评级调整
- 判断市场情绪

**必须包含的内容**：
→ 分析师覆盖（数量、买入/持有/卖出分布）
→ 目标价数据（平均、最高、最低）
→ 最新评级调整（上调、下调）

### 第5步 —— 机构资金动向

**核心目标**：
- 获取前5大机构持仓信息
- 识别持仓变化
- 发现对冲基金动向
- 判断聪明钱流向

**必须包含的内容**：
→ 前5大机构持仓（表格形式）
→ 对冲基金动向（新建仓、清仓、大幅加减仓）
→ 资金流向总结

## 数据源

### 主要数据源

1. **Yahoo Finance**：股价、财务数据、估值指标
2. **SEC EDGAR**：公司财报、13F机构持仓文件
3. **TipRanks/Bloomberg**：分析师评级、目标价
4. **公司官网**：最新财报、投资者关系资料

### 数据获取方式

- 使用 `mcp__web-search-prime__webSearchPrime` 搜索最新财务数据和新闻
- 使用 `mcp__web-reader__webReader` 获取SEC文件和公司财报详细信息
- 优先使用最近30天内的数据
- 数据超过30天时标注⚠️提示

## 产出格式

完整的5步分析报告结构：

```
# [公司名称]（[股票代码]）完整拆解分析

## 第1步 —— 公司概览
## 第2步 —— 关键财务数据
## 第3步 —— 股价表现
## 第4步 —— 华尔街一致预期
## 第5步 —— 机构资金动向

## 投资总结
```

## 核心原则

1. **数据来源标注**：每个指标后必须标注来源和日期
2. **不编造数据**：数据不可获取时明确说明，不估算或编造
3. **时效性提醒**：数据超过30天时标注⚠️提示
4. **客观中立**：避免强烈买入/卖出建议，提供分析框架
5. **合规要求**：不构成投资建议，仅作信息整理和分析
