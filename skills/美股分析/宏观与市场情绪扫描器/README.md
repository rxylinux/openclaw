# 宏观与市场情绪扫描器

顶级投行晨会简报级别的宏观与市场情绪分析工具。

## 概述

本技能提供7维度宏观环境扫描，帮助投资者快速理解当前市场状态并制定相应策略。

## 分析维度

1. **美联储与利率政策** - 当前利率、降息预期、官员言论
2. **通胀数据** - CPI、PCE及其趋势
3. **经济健康状况** - GDP、就业、PMI、衰退概率
4. **市场结构与情绪** - 指数表现、VIX、Put/Call比率、资金流
5. **板块轮动分析** - 各板块表现对比、资金流向
6. **地缘政治与重大事件** - 风险事件日历、黑天鹅监控
7. **综合判断与策略建议** - Risk-On/Off状态、资产配置建议

## 核心特性

- **数据源追踪**：每个数据点标注来源和时间戳
- **预期vs实际**：清晰区分确认数据与市场预期
- **状态判断**：明确给出Risk-On/Risk-Off/中性状态
- **策略建议**：提供进攻/防御/中性三种策略

## 使用场景

- 每周市场复盘
- FOMC会议前评估
- 重大数据发布后解读
- 资产配置决策参考
- 风险事件评估
