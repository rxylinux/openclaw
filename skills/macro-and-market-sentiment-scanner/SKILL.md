# 宏观与市场情绪扫描器

## 核心原则

**数据区分是第一原则。** 必须区分已确认数据与市场预期/预测，不得将预测当作事实陈述。

- **来源明确** - 每个数据必须标注来源和发布日期
- **数据类型标注** - 明确标注 [已确认] 或 [市场预期]
- **时效性** - 使用最新数据，注明日期
- **传导机制** - 解释宏观数据如何影响具体行业/股票

## 输出格式要求

1. **清晰的分节标题** - 使用 ##、### 分级标题
2. **数据来源标注** - 每个数据必须标注来源和日期
3. **数据类型标注** - 明确标注 [已确认] 或 [市场预期]
4. **传导机制说明** - 解释宏观数据如何影响行业/股票
5. **表格结构** - 大量使用 markdown 表格展示数据
6. **战略明确** - 给出明确的战略建议和行动方案

## 使用技巧

1. **官方数据优先** - 美联储、BLS、BEA 官方数据
2. **时效性** - 使用最新数据，注明日期
3. **预期 vs 实际** - 明确区分预期与实际
4. **传导机制** - 解释宏观如何影响微观
5. **多维度分析** - 不要单一指标判断
6. **历史对比** - 与历史周期对比
