# 宏观经济指标说明

## 美联储与利率指标

### 联邦基金利率（Federal Funds Rate）

**定义：** 银行间隔夜拆借利率，是美国最重要的基准利率。

**制定机构：** 美联储（FOMC 决议）

**更新频率：** FOMC 会议后（通常每年 8 次）

**数据来源：** federalreserve.gov

### 有效联邦基金利率（EFFR）

**定义：** 实际交易利率的加权平均值。

**发布机构：** 纽约联储

**更新频率：** 每日

**数据来源：** newyorkfed.org

### FOMC 会议日程

**常规会议：** 每年 8 次，间隔约 6 周

**会议结构：**
- 第 1 天：审议（如需要）
- 第 2 天：决策 + 记者会

**重要性：** 每次会议都可能影响市场

## 通胀指标

### CPI（消费者价格指数）

**发布机构：** BLS（劳工统计局）

**更新频率：** 每月（通常月中发布上月数据）

**数据类型：**

| 指标 | 说明 |
|------|------|
| 总体 CPI（同比） | 与去年同期相比 |
| 总体 CPI（环比） | 与上月相比 |
| 核心 CPI（同比） | 剔除食品和能源 |
| 核心 CPI（环比） | 剔除食品和能源 |

**市场关注重点：**
- 核心 CPI 更受关注（剔除波动性大的食品能源）
- 同比数据反映长期趋势
- 环比数据反映短期变动

**数据来源：** bls.gov

### PCE（个人消费支出价格指数）

**发布机构：** BEA（经济分析局）

**更新频率：** 每月（通常月末发布上月数据）

**重要性：**
- ⭐ 美联储偏好的通胀指标
- 与 CPI 相比，PCE 通常较低 0.3-0.5 个百分点

**差异原因：**
- 权重不同（PCE 基于更广泛的消费数据）
- 公式计算不同（PCE 允许替代效应）

**数据来源：** bea.gov

## 经济增长指标

### GDP（国内生产总值）

**发布机构：** BEA

**更新频率：** 每季度（首估、修正、终值）

**数据类型：**

| 指标 | 说明 |
|------|------|
| 实际 GDP 环比年化 | 季度环比，折算成年率 |
| 实际 GDP 同比 | 与去年同期相比 |
| 名义 GDP | 未调整通胀 |

**美国潜在增长率：** 约 1.8% - 2.0%

**解读：**
- 高于 2%：稳健扩张
- 1%-2%：温和增长
- 0%-1%：接近停滞
- 负值：衰退

**数据来源：** bea.gov

## 就业指标

### 失业率

**发布机构：** BLS

**更新频率：** 每月（第一个周五）

**定义：** 失业人口占劳动力的百分比

**自然失业率：** 约 4.0% - 4.5%

**解读：**
- < 4%：充分就业，可能引发通胀
- 4%-5%：健康就业市场
- > 6%：就业市场疲软
- > 8%：严重失业

### 非农就业（Non-Farm Payrolls）

**发布机构：** BLS

**更新频率：** 每月（第一个周五）

**定义：** 非农业部门新增就业人数

**正常增长：** 每月约 10万-20万人
**强劲增长：** 每月 > 20万人

**重要性：** 最受关注的就业数据

### 劳动参与率

**定义：** 劳动力占成年人口的百分比

**当前水平：** 约 62%-63%

**趋势：** 长期下降（人口老龄化）

### 平均时薪

**更新频率：** 每月

**解读：**
- 同比增长 > 4%：工资增长强劲
- 同比增长 3%-4%：温和增长
- 同比增长 < 3%：工资增长疲软

**通胀关联：** 工资增长 → 通胀压力

## 消费者信心指标

### 密歇根消费者信心指数

**发布机构：** 密歇根大学

**更新频率：** 每月（两次：初值和终值）

**数值范围：**
- > 100：极度乐观
- 80-100：乐观
- 50-80：中性偏乐观
- < 50：悲观

### Conference Board 消费者信心指数

**发布机构：** The Conference Board

**更新频率：** 每月

**基数：** 1985 = 100

**解读：**
- > 100：乐观
- < 100：悲观

## 衰退预警指标

### 收益率曲线倒挂

**定义：** 短期利率 > 长期利率

**常用指标：** 10年期国债收益率 - 2年期国债收益率

**预警阈值：** < 0%（倒挂）

**准确性：**
- 倒挂后 6-24 个月通常发生衰退
- 1950 年以来几乎每次衰退前都有倒挂

**数据来源：** FRED（fred.stlouisfed.org）

### LEI（领先经济指数）

**发布机构：** Conference Board

**更新频率：** 每月

**组成部分（10 项）：**
1. 制造业工时平均周
2. 平均每周初请失业金人数
3. 制造商新订单（消费品）
4. ISM 指数中的新订单指数
5. 制造商新订单（非国防资本品）
6. 建筑许可（新私人住宅）
7. 股票价格（标普 500）
8. 领先信贷指数
9. 利率差（10年期国债减联邦基金利率）
10. 消费者对商业环境的平均预期

**预警信号：**
- 6 个月连续下降 → 衰退预警

### PMI（采购经理人指数）

**制造业 PMI（ISM 制造业）**
- 发布机构：ISM（供应管理协会）
- 更新频率：每月
- 阈值：50（扩张/收缩分界线）
  - > 50：扩张
  - < 50：收缩
  - < 45：严重收缩

**服务业 PMI（ISM 服务业）**
- 更重要（服务业占美国经济 80%）
- 阈值：50

## 其他重要指标

### 初请失业金人数

**发布机构：** BLS

**更新频率：** 每周

**预警信号：**
- 持续上升 → 就业市场恶化
- > 30万 → 关注
- > 35万 → 警告

### 零售销售

**发布机构：** 人口普查局

**更新频率：** 每月

**重要性：**
- 消费占美国 GDP 约 70%
- 零售销售反映消费健康度

### 住房市场指标

| 指标 | 发布机构 | 重要性 |
|------|----------|--------|
| 新屋开工 | 人口普查局 | 领先指标 |
| 成屋销售 | NAR | 当前活动 |
| 房价指数（Case-Shiller） | S&P | 财富效应 |

## 注意事项

1. **数据修订：** 许多经济数据会后续修订
2. **季节性调整：** 大部分数据已季节性调整
3. **预期 vs 实际：** 市场对预期和实际值的差异反应
4. **趋势重要：** 单月数据可能波动，趋势更重要
5. **数据延迟：** 大部分数据有 1 个月延迟
