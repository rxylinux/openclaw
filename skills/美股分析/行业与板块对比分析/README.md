# 行业与板块对比分析

## 概述

行业与板块对比分析提供**多公司竞争格局对比**能力，系统评估行业地位和投资价值。

## 核心特性

- ✅ **综合对比表格**：市值、营收、利润率、估值等
- ✅ **竞争定位**：壁垒分析、市场份额
- ✅ **风险对比**：最大风险、债务风险
- ✅ **排名结论**：价值、增长、安全性
- ✅ **不孤立分析**：永远在竞争格局中评估

1. 永远在竞争格局中分析
2. 每个指标标注来源
3. 缺失数据标注"N/A"
4. 数据超30天需标记
