# 核心数据分析方法

## 营收对比分析

### 营收对比表

| 指标 | 数值 | 来源 |
|------|------|------|
| 市场预期 | $X,XXX | Bloomberg Consensus |
| 实际结果 | $X,XXX | 财报新闻稿 |
| 差额（美元） | ±$XXX | 计算值 |
| 差额（百分比） | ±X.X% | 计算值 |

*发布日期：YYYY-MM-DD*

### 计算方法

**差额（美元）**：
```
差额 = 实际结果 - 市场预期
```

**差额（百分比）**：
```
差额% = (实际结果 - 市场预期) / 市场预期 × 100%
```

### 评估标准

| 差额% | 评估 |
|-------|------|
| > +5% | 大幅超预期 ✅ |
| +2% ~ +5% | 温和超预期 ✅ |
| -2% ~ +2% | 符合预期 → |
| -5% ~ -2% | 温和不及预期 ❌ |
| < -5% | 大幅不及预期 ❌ |

## 一次性项目分析

### GAAP vs 调整后利润

| 项目 | GAAP净利润 | 调整后净利润 | 差异 |
|------|-----------|------------|------|
| 金额 | $XXX | $XXX | $XXX |
| EPS | $X.XX | $X.XX | $X.XX |

*来源：财报新闻稿，发布日期：YYYY-MM-DD*

### 常见一次性项目

**正向一次性项目**：
- 资产处置收益
- 投资收益
- 汇兑收益
- 诉讼和解收入

**负向一次性项目**：
- 重组费用
- 资产减值
- 诉讼费用
- 并购相关费用

### 分析方法

1. **识别一次性项目**：
   - 查看财报新闻稿中的"Non-GAAP"或"调整后"部分
   - 查看GAAP与调整后数据对调表

2. **评估影响**：
   ```
   一次性项目影响 = |GAAP - 调整后| / GAAP × 100%
   ```

3. **判断标准**：
   - **影响 < 5%**：影响较小 ✅
   - **影响 5-10%**：需要关注 ⚠️
   - **影响 > 10%**：影响显著 ⚠️⚠️

## 数据来源

### 财报新闻稿（Earnings Press Release）

**内容**：
- 实际营收和EPS
- 调整后数据
- 一次性项目说明
- 管理层引用

**发布时间**：
- 通常在美股收盘后（约4:30 PM ET）或盘前（约7:00 AM ET）

**获取来源**：
- 公司投资者关系网站
- PR Newswire
- Business Wire

### 分析师预期数据

**主要来源**：
- Bloomberg Consensus Estimates
- IBES（Institutional Brokers' Estimate System）
- FactSet Estimates
- Yahoo Finance Analyst Estimates

**预期类型**：
- **营收预期**：Consensus Revenue Estimate
- **EPS预期**：Consensus EPS Estimate
- **预期范围**：High/Low Estimates

### 注意事项

1. **预期数据时效性**：
   - 预期数据在财报发布前可能变化
   - 使用最新可获得的一致预期

2. **财报重述**：
   - 注意公司是否重述历史财报
   - 检查是否有会计政策变更

3. **财年差异**：
   - 确认公司财年与自然年是否一致
   - 标注财年/财季（如FY2024 Q3）
