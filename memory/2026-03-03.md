### AI 投资复盘系统

**链接**: https://github.com/AIPMAndy/ai-invest-agent

**简介**: AI 驱动的投资复盘系统，从"拍脑袋"到"有体系"

**核心功能**:
- 🌡️ 温度计量化估值系统（PE历史分位 × 100）
- 📊 四步复盘法（宏观 → 板块 → 温度计 → 标的）
- 🌏 跨市场覆盖（A股20个 + 港股8个 + 美股5个指数）
- 📈 10维度持仓深度评估
- 📄 多格式输出（MD/DOCX/XLSX）

**温度计操作建议**:
- 0-30℃ 🟢 低估 → 买入区间
- 30-50℃ 🟡 合理 → 持有观望
- 50-100℃ 🔴 高估 → 逐步卖出

**使用场景**:
- 周末复盘：系统性回顾本周行情
- 每日快检：5分钟掌握市场状态
- 买入决策：温度计判断估值位置
- 持仓管理：10维度深度评估

**技术特点**:
- 零代码上手，加载 Prompt 即用
- Prompt 驱动，支持 Claude/ChatGPT/Kimi
- Apache 2.0 许可（个人免费，企业可商用）

## 🚀 全市场金融分析 Agent 已创建

**位置**: `skills/full-market-financial-analyst/`

**核心能力**:
- 🌏 支持A股、美股、港股三大市场
- 📊 整合10大专业分析模块
  - 完整股票分析
  - 完整尽职调查
  - 宏观市场扫描
  - 风险红旗扫描
  - 财报深度拆解
  - 财报解读分析
  - 行业板块对比
  - 股息收入分析
  - ETF组合分析
  - 估值模型构建

**8种分析模式**:
1. 单股深度分析 - 快速了解公司
2. 完整尽职调查 - 深度投资研究
3. 多股对比分析 - 行业竞争格局
4. 投资组合分析 - 持仓优化
5. 宏观环境扫描 - 市场时机判断
6. 风险红旗扫描 - 风险评估
7. 股息收入分析 - 收益型投资
8. 估值模型构建 - DCF+可比公司

**投资评级系统**:
- Strong Buy 强烈买入（>20%涨幅）
- Buy 买入（10-20%涨幅）
- Hold 持有（±10%）
- Sell 卖出（<-10%跌幅）

**数据源**:
- A股: 同花顺、东方财富、交易所官网
- 美股: Yahoo Finance、SEC EDGAR、Bloomberg
- 港股: 港交所披露易、AAStocks、Yahoo Finance HK

**核心原则**:
- 每个数据点标注来源和日期
- 绝不编造或估算数据
- 区分已确认数据与预期
- 数据超时标记 ⚠️ 或 🚨
