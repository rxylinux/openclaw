# 压力测试方法

## 历史压力测试

### 原则

**⚠️ 重要警告：** 历史表现不保证未来结果。压力测试仅用于了解组合在历史压力时期的相对表现。

### 主要历史危机时期

#### 1. 2008 年全球金融危机

**时间：** 2007年10月 - 2009年3月

**触发原因：**
- 次贷危机
- 雷曼兄弟破产
- 全球金融系统崩溃

**市场表现（标普 500）：**
- 峰值：2007年10月9日，1,565点
- 谷底：2009年3月9日，676点
- 跌幅：-56.8%
- 恢复时间：约4年（2012年恢复峰值）

**受影响最严重的板块：**
- 金融：-80%+
- 房地产：-70%+
- 消费服务：-60%+

**相对抗跌板块：**
- 消费必需品：-30%
- 公用事业：-35%
- 医疗健康：-40%

#### 2. 2020 年 COVID-19 疫情暴跌

**时间：** 2020年2月19日 - 2020年3月23日

**触发原因：**
- COVID-19 全球大流行
- 经济封锁
- 不确定性急剧上升

**市场表现（标普 500）：**
- 峰值：2020年2月19日，3,386点
- 谷底：2020年3月23日，2,237点
- 跌幅：-33.9%
- 恢复时间：约6个月（2020年8月恢复）

**受影响最严重的板块：**
- 能源：-50%+
- 金融：-40%+
- 工业：-35%+

**快速恢复板块：**
- 科技：-25%，快速恢复
- 成长股：V型反转
- 数字经济相关

#### 3. 2022 年熊市

**时间：** 2022年1月 - 2022年10月

**触发原因：**
- 美联储激进加息（0% → 4.5%）
- 通胀飙升（40年高点）
- 地缘政治（俄乌战争）

**市场表现（标普 500）：**
- 峰值：2022年1月3日，4,796点
- 谷底：2022年10月12日，3,577点
- 跌幅：-25.4%
- 恢复时间：约1年（2023年恢复）

**受影响最严重的板块：**
- 科技/成长股：P/E压缩
- 科技：-30%+
- 消费服务：-25%+
- 房地产：-30%+

**相对抗跌板块：**
- 能源：大涨（俄乌战争）
- 价值股：表现优于成长
- 短期债券：利率上升受益

## 压力测试计算方法

### 回测数据获取

**数据来源：**
1. **Yahoo Finance：** 历史价格数据
2. **ETF 发行人网站：** 历史 NAV 数据
3. **Portfolio Visualizer：** 回测工具
4. **Morningstar：** 历史表现数据

### 关键指标计算

#### 期间跌幅

```
期间跌幅 = (期末价格 - 期初价格) / 期初价格 × 100%
```

#### 最大回撤

```
最大回撤 = max[(峰值价格 - 谷底价格) / 峰值价格]
```

**计算步骤：**
1. 识别期间内所有峰值
2. 计算每个峰值后的最大跌幅
3. 取最大值

#### 恢复时间

```
恢复时间 = 从谷底恢复到峰值价格的时间
```

**计算步骤：**
1. 找到谷底日期
2. 找到价格恢复到峰值水平的日期
3. 计算月份数

### 数据表格

| 危机 | 开始日期 | 结束日期 | 组合跌幅 | 标普500跌幅 | 相对表现 | 恢复时间（月） |
|------|----------|----------|----------|-------------|----------|----------------|
| 2008 金融危机 | 2007-10-09 | 2009-03-09 | % | -56.8% | [更差/更好] | |
| 2020 疫情 | 2020-02-19 | 2020-03-23 | % | -33.9% | [更差/更好] | |
| 2022 熊市 | 2022-01-03 | 2022-10-12 | % | -25.4% | [更差/更好] | |

### 相对表现评估

**评估标准：**
- 组合跌幅 < 市场跌幅 -5%：✅ **防御性强**
- 组合跌幅 ≈ 市场跌幅 ±5%：🟡 **与市场同步**
- 组合跌幅 > 市场跌幅 +5%：🚨 **防御性弱**

### 恢复速度评估

**评估标准：**
- < 6个月：✅ **快速恢复**
- 6-12个月：🟡 **适中恢复**
- > 12个月：⚠️ **缓慢恢复**
- > 24个月：🚨 **极慢恢复**

## 蒙特卡洛模拟

### 基本原理

蒙特卡洛模拟通过生成大量随机情景来评估投资组合的风险。

**步骤：**
1. 设定收益分布假设（均值、标准差）
2. 生成大量随机情景（如 1000 次）
3. 计算每个情景的最终收益
4. 统计分析

**关键输出：**
- 概率分布
- VaR（风险价值）
- 期望损失
- 最坏情况情景

### 简化示例

**假设：**
- 年化收益率：8%
- 年化波动率：18%
- 模拟次数：1000
- 投资期限：5年

**输出：**
- 中位数收益：+45%
- 10% 最坏情况：-15%
- 90% 最好情况：+120%

## 压力测试局限性

### 主要局限

1. **历史不重复：** 每次危机都不同
2. **相关性变化：** 危机中相关性可能趋向1
3. **流动性风险：** 历史数据可能无法反映极端流动性风险
4. **黑天鹅事件：** 未预见的事件无法预测
5. **政策干预：** 政府政策可能改变结果

### 最佳实践

1. **多场景测试：** 测试多个不同情景
2. **保守假设：** 考虑比历史更坏的情况
3. **动态调整：** 定期更新压力测试
4. **定性评估：** 结合定性分析
5. **风险预算：** 为最坏情况做准备
