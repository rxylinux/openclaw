# 投资组合指标详解

## Beta 系数

### 定义

Beta = 衡量投资组合相对于市场（通常是标普 500）的波动性

### 计算公式

```
Beta = Cov(投资组合收益, 市场收益) / Var(市场收益)
```

### Beta 含义

| Beta 值 | 波动性 | 说明 |
|---------|--------|------|
| < 0.5 | 低波动 | 防御性强 |
| 0.5-0.8 | 中低波动 | 相对保守 |
| 0.8-1.2 | 中等波动 | 与市场相近 |
| 1.2-1.5 | 中高波动 | 相对激进 |
| > 1.5 | 高波动 | 非常激进 |

### 应用

- **资产配置**：根据风险偏好调整 Beta
- **风险控制**：控制整体投资组合 Beta
- **绩效评估**：评估基金经理的主动管理能力

## 波动率（Volatility）

### 定义

波动率 = 投资组合收益率的标准差，衡量价格波动程度

### 年化波动率计算

```
年化波动率 = 日波动率 × √252
或
年化波动率 = 月波动率 × √12
```

### 波动率评估

| 年化波动率 | 风险水平 | 说明 |
|-----------|---------|------|
| < 15% | 低波动 | 防御型组合 |
| 15-20% | 中低波动 | 保守型组合 |
| 20-25% | 中等波动 | 平衡型组合 |
| 25-35% | 中高波动 | 增长型组合 |
| > 35% | 高波动 | 激进型组合 |

### 应用

- **风险管理**：评估组合风险
- **压力测试**：模拟不同市场环境
- **资产配置**：根据波动率调整配置

---

## 夏普比率（Sharpe Ratio）

### 定义

夏普比率 = 风险调整后收益，衡量单位风险获得的超额收益

### 计算公式

```
夏普比率 = (投资组合收益率 - 无风险利率) / 投资组合标准差
```

### 夏普比率评估

| 夏普比率 | 评级 | 说明 |
|---------|------|------|
| > 1.5 | 优秀 | 风险调整后收益优秀 |
| 1.0-1.5 | 良好 | 风险调整后收益良好 |
| 0.5-1.0 | 一般 | 风险调整后收益一般 |
| 0-0.5 | 较差 | 风险调整后收益较差 |
| < 0 | 差 | 风险调整后收益为负 |

### 应用

- **绩效评估**：评估基金经理能力
- **投资选择**：选择风险调整后收益高的投资
- **组合优化**：优化夏普比率

---

## 最大回撤（Maximum Drawdown）

### 定义

最大回撤 = 从峰值到谷值的最大跌幅，衡量最坏情况下的损失

### 计算方法

```
最大回撤 = (峰值 - 谷值) / 峰值
```

### 最大回撤评估

| 最大回撤 | 风险水平 | 说明 |
|---------|---------|------|
| < 20% | 低风险 | 防御性强 |
| 20-30% | 中低风险 | 保守型 |
| 30-40% | 中等风险 | 平衡型 |
| 40-50% | 中高风险 | 增长型 |
| > 50% | 高风险 | 激进型 |

### 应用

- **风险承受**：评估投资者能承受的最大损失
- **产品选择**：选择符合风险承受度的产品
- **风险控制**：设定止损点

---

## 特雷诺比率（Treynor Ratio）

### 定义

特雷诺比率 = 基于 Beta 的风险调整后收益

### 计算公式

```
特雷诺比率 = (投资组合收益率 - 无风险利率) / Beta
```

### 与夏普比率的区别

- **夏普比率**：使用总风险（标准差）
- **特雷诺比率**：使用系统性风险（Beta）

---

## 信息比率（Information Ratio）

### 定义

信息比率 = 超额收益的稳定性，衡量主动管理能力

### 计算公式

```
信息比率 = 超额收益 / 跟踪误差
```

### 信息比率评估

| 信息比率 | 评级 | 说明 |
|---------|------|------|
| > 1.0 | 优秀 | 主动管理能力优秀 |
| 0.5-1.0 | 良好 | 主动管理能力良好 |
| 0-0.5 | 一般 | 主动管理能力一般 |
| < 0 | 差 | 主动管理能力差 |

---

## 相关性（Correlation）

### 定义

相关性 = 两个资产收益率的线性关系，范围 -1 到 1

### 相关系数含义

| 相关系数 | 关系 | 说明 |
|---------|------|------|
| 1.0 | 完全正相关 | 同涨同跌，无分散效果 |
| 0.7-0.9 | 高度正相关 | 趋势一致，分散效果弱 |
| 0.3-0.7 | 中等相关 | 部分同步，有分散效果 |
| 0-0.3 | 低相关 | 较少同步，分散效果良好 |
| < 0 | 负相关 | 反向波动，分散效果最佳 |

### 应用

- **分散化**：选择低相关资产
- **风险控制**：降低组合波动率
- **压力测试**：评估组合分散化效果

---

## 费用率（Expense Ratio）

### 定义

费用率 = 基金年度运营费用占资产净值的比例

### 费用率评估

| 费用率 | 评级 | 说明 |
|---------|------|------|
| < 0.10% | 优秀 | 非常低费用 |
| 0.10-0.30% | 良好 | 低费用 |
| 0.30-0.70% | 一般 | 中等费用 |
| 0.70-1.00% | 较高 | 高费用 |
| > 1.00% | 高 | 非常高费用 |

### 长期影响

```
假设：
- 初始投资：$10,000
- 年化收益率：7%
- 投资期限：10 年

费用率 0.10%：
10 年后：$19,539

费用率 0.50%：
10 年后：$19,227

费用率 1.00%：
10 年后：$18,834

差异：$705（3.6%）
```

## 股息率（Dividend Yield）

### 定义

股息率 = 年度股息 / 当前股价

### 计算公式

```
股息率 = 年度股息 / 当前股价 × 100%
```

### 股息率评估

| 股息率 | 类型 | 说明 |
|---------|------|------|
| < 1% | 低收益 | 成长型投资 |
| 1-2.5% | 中等收益 | 平衡型投资 |
| 2.5-4% | 中高收益 | 收益型投资 |
| 4-6% | 高收益 | 高收益投资 |
| > 6% | 极高收益 | 需警惕可持续性 |

---

## 跟踪误差（Tracking Error）

### 定义

跟踪误差 = 投资组合收益与基准收益差异的标准差

### 计算公式

```
跟踪误差 = √[Σ(投资组合收益 - 基准收益)² / (n - 1)]
```

### 跟踪误差评估

| 跟踪误差 | 评级 | 说明 |
|---------|------|------|
| < 0.5% | 优秀 | 紧密跟踪 |
| 0.5-1.0% | 良好 | 良好跟踪 |
| 1.0-2.0% | 一般 | 中等跟踪 |
| 2.0-3.0% | 较差 | 跟踪偏差大 |
| > 3.0% | 差 | 严重偏离基准 |

---

## 阿尔法（Alpha）

### 定义

阿尔法 = 超越基准的收益，衡量主动管理能力

### 计算公式（CAPM）

```
Alpha = 投资组合收益 - [无风险利率 + Beta × (市场收益 - 无风险利率)]
```

### 阿尔法评估

| 阿尔法 | 评级 | 说明 |
|---------|------|------|
| > 5% | 优秀 | 显著超越基准 |
| 2-5% | 良好 | 超越基准 |
| 0-2% | 一般 | 略超越基准 |
| 0% | 中性 | 等于基准 |
| < 0% | 差 | 不如基准 |

## 注意事项

### 指标局限性

1. **历史数据**：过去不代表未来
2. **基准选择**：不同基准产生不同结果
3. **时间窗口**：不同时间窗口产生不同结果
4. **假设条件**：某些指标基于假设（如无风险利率）

### 综合评估

- 不要单一指标判断
- 多个指标综合评估
- 结合实际情况分析
- 定期更新和调整
