# 财报解读分析框架

## 概述

财报解读分析采用**6维度方法**，系统评估财报质量、指引变化和市场反应。

## 6个分析维度

### 第1步：核心数据
- 营收 vs 预期
- EPS vs 预期
- 一次性项目影响

### 第2步：前瞻指引
- 指引调整
- 下季度/全年指引
- 管理层措辞

### 第3步：业务板块拆解
- 各板块表现
- 增长/下滑分析
- 驱动因素

### 第4步：管理层评论
- CEO发言提取
- CFO发言提取
- 语气评估

### 第5步：市场反应
- 股价变动
- 分析师评级变化
- 问答环节主题

### 第6步：最终结论
- 关键数字
- 季度质量评估
- 下季关注点

## 数据优先级

1. **SEC 10-Q/10-K**（最权威）
2. **公司新闻稿**（官方解读）
3. **会议记录**（管理层观点）
4. **分析师报告**（第三方观点）
