# 现金流折现模型（DCF）理论基础

## DCF 核心公式

```
企业价值 = Σ [自由现金流t / (1 + WACC)^t] + [终值 / (1 + WACC)^n]

其中：
- 自由现金流t = 第 t 年的自由现金流
- WACC = 加权平均资本成本
- 终值 = 永续期价值
- n = 预测期年数
```

## 自由现金流计算

### 方法 1：从净利润推导

```
自由现金流 = 净利润 + 折旧摊销 - 资本支出 - 营运资本变化
```

### 方法 2：从息税前利润（EBIT）推导

```
自由现金流 = EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本变化
```

### 营运资本变化

```
营运资本变化 = (流动资产 - 流动负债)期末 - (流动资产 - 流动负债)期初

正向变化 = 资金占用（减少自由现金流）
负向变化 = 资金释放（增加自由现金流）
```

## 终值计算方法

### 方法 1：永续增长模型（Gordon Growth）

```
终值 = 第 (n+1) 年自由现金流 / (WACC - g)

其中：
- g = 永续增长率
- 第 (n+1) 年自由现金流 = 第 n 年自由现金流 × (1 + g)
```

**永续增长率选择原则：**
- 理论范围：2-3%（接近 GDP 增长率）
- 保守选择：取 2-3% 的下限
- 不宜超过 5%（长期可持续增长限制）

### 方法 2：退出倍数法

```
终值 = 第 n 年 EBITDA × 行业平均 EV/EBITDA 倍数
```

**适用场景：**
- 可比公司数据丰富
- 行业倍数相对稳定
- 公司预期接近行业平均水平

## WACC 计算详解

### 股权成本（Ke）- CAPM 模型

```
Ke = Rf + β × (Rm - Rf) + 特定风险溢价

其中：
- Rf = 无风险利率（通常用 10 年期国债收益率）
- β = Beta 系数（衡量股票相对于市场的波动性）
- Rm - Rf = 市场风险溢价（股权风险溢价）
- 特定风险溢价 = 公司特有风险（可选）
```

#### 无风险利率（Rf）

**选择原则：**
- 使用 10 年期国债收益率
- 与估值货币匹配（人民币估值用中国国债，美元估值用美国国债）
- 数据来源：央行官网、财政部网站

**示例数据：**
- 中国 10 年期国债：~2.5-3.0%
- 美国 10 年期国债：~4.0-4.5%

#### Beta 系数

**选择原则：**
- 首选：Bloomberg、Wind 等金融数据平台
- 次选：财经网站（Yahoo Finance、东方财富）
- 调整：通常使用调整后 Beta（去除短期波动）

**Beta 范围：**
- < 0.5：低波动性（公用事业、消费必需品）
- 0.5-1.0：中等波动性（大盘蓝筹）
- > 1.0：高波动性（成长股、科技股）

#### 市场风险溢价（Rm - Rf）

**常用数据来源：**
- Damodaran 数据（纽约大学教授，权威来源）
- 本地市场历史数据（如：中国市场的历史股权风险溢价）

**典型数值：**
- 美国：5.0-6.0%
- 中国：7.0-8.0%（新兴市场风险溢价更高）

### 债务成本（Kd）

```
Kd = 税前债务成本 × (1 - 企业所得税率)
```

**税前债务成本估算：**
- 有债券发行：使用债券收益率
- 有银行贷款：使用贷款利率
- 无公开数据：使用同评级公司债券利率 + 公司特定风险溢价

**企业所得税率：**
- 使用公司实际税率（来自财报）
- 中国标准企业所得税率：25%
- 高新技术企业：15%

### 资本结构

```
权益占比 = 权益市值 / (权益市值 + 净债务市值)
债务占比 = 净债务市值 / (权益市值 + 净债务市值)
```

**净债务计算：**
```
净债务 = 短期借款 + 长期借款 - 现金及现金等价物
```

## DCF 敏感性分析

### 需要测试的关键变量

1. **营收增长率**
   - 测试范围：基准 ±3-5%
   - 影响：直接影响自由现金流规模

2. **利润率**
   - 测试范围：基准 ±2-5%
   - 影响：影响自由现金流质量

3. **WACC**
   - 测试范围：基准 ±1-2%
   - 影响：影响折现率，对终值影响较大

4. **永续增长率**
   - 测试范围：2.0%-3.0%（通常不超出此范围）
   - 影响：对终值影响显著

### 敏感性矩阵示例

```
          |  增长率 -2%  |  增长率 基准  |  增长率 +2%
----------------------------------------------------
WACC -1%  |   XXX 元    |   XXX 元     |   XXX 元
WACC 基准 |   XXX 元    |   XXX 元     |   XXX 元
WACC +1%  |   XXX 元    |   XXX 元     |   XXX 元
```

## DCF 模型的局限性

### 主要局限

1. **预测的不确定性**
   - 长期预测（5 年以上）准确性低
   - 假设的轻微变化可能导致估值大幅波动

2. **终值占比过大**
   - 终值通常占企业价值的 60-80%
   - 终值估算的误差对整体估值影响巨大

3. **对折现率敏感**
   - WACC 的 1% 变化可能导致估值 10-20% 的变化
   - Beta、市场风险溢价等参数估算存在主观性

4. **不适用于某些类型公司**
   - 负现金流公司（如：早期科技公司）
   - 周期性强的公司（如：大宗商品）
   - 资产重组中的公司

### 改进方法

1. **多情景分析**
   - 乐观、基准、悲观三种情景
   - 赋予不同权重计算加权价值

2. **蒙特卡洛模拟**
   - 对关键变量设置概率分布
   - 进行多次模拟获得估值分布

3. **与其他方法交叉验证**
   - 可比公司估值
   - 资产基础估值
   - 期权定价模型（对于某些特殊公司）

## 数据来源建议

### 财务数据

- **财报**：SEC 10-K/10-Q、港交所披露易、上交所/深交所公告
- **数据库**：Wind、Bloomberg、Choice、CSMAR
- **财经网站**：Yahoo Finance、东方财富、同花顺

### 市场数据

- **Beta**：Bloomberg、Wind、Choice
- **无风险利率**：央行官网、财政部网站
- **市场风险溢价**：Damodaran 网站、券商研究报告

### 分析师数据

- **目标价**：FactSet、Bloomberg、券商研报
- **一致预期**：IBES、Choice、东方财富

## 计算检查清单

在进行 DCF 估值前，检查：

- [ ] 自由现金流计算方法是否正确
- [ ] 历史自由现金流是否稳定（排除异常年份）
- [ ] 预测期增长率是否合理（对比历史和行业）
- [ ] WACC 计算是否有完整的推导过程
- [ ] Beta、无风险利率、市场风险溢价是否有明确来源
- [ ] 永续增长率是否在 2-3% 范围内
- [ ] 终值计算方法是否合理
- [ ] 敏感性分析是否覆盖关键变量
- [ ] 单位是否一致（全部用人民币或全部用美元）
- [ ] 是否进行了合理的四舍五入（保留 2 位小数）
