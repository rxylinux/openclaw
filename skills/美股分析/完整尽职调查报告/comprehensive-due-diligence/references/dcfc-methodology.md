# DCF 估值方法论

## DCF 基本原理

### 什么是 DCF

**定义：** 现金流折现模型（Discounted Cash Flow）是一种通过预测未来现金流并折现到现值来评估公司价值的估值方法。

**核心思想：** 公司的价值等于其未来产生的所有自由现金流的现值之和。

**公式：**
```
企业价值 = Σ(FCFt / (1+WACC)^t) + 终值
股权价值 = 企业价值 - 净债务
每股价值 = 股权价值 / 稀释股数
```

### 适用场景

**✅ 适合使用 DCF 的情况：**
- 现金流稳定、可预测
- 成熟行业
- 资本密集型行业（如公用事业、能源）
- 有长期经营历史

**❌ 不适合使用 DCF 的情况：**
- 早期亏损公司
- 高增长但不确定性高的公司
- 周期性极强的行业
- 现金流波动大的公司

## DCF 关键参数

### WACC（加权平均资本成本）

**定义：** 公司资本结构中股权和债务的加权平均成本。

**计算公式：**
```
WACC = (E/V × Re) + (D/V × Rd × (1-T))

其中：
E = 股权市值
D = 债务市值
V = E + D
Re = 股权成本
Rd = 债务成本
T = 税率
```

#### 股权成本（Re）- CAPM 模型

**公式：**
```
Re = Rf + β × (Rm - Rf)

其中：
Rf = 无风险利率（通常用10年期国债收益率）
β = 贝塔系数（衡量股票相对于市场的波动性）
Rm = 市场预期回报（通常假设 8%-10%）
Rm - Rf = 股权风险溢价
```

**典型数值：**
- Rf：3%-5%（取决于利率环境）
- β：0.5-2.0（取决于行业和公司）
- Rm - Rf：5%-7%（历史平均）

#### 债务成本（Rd）

**定义：** 公司借款的利率。

**来源：**
- 公司债券收益率
- 银行贷款利率
- 信用评级对应的利率

**税盾效应：** 利息支出可以抵税，因此债务成本要乘以 (1-T)

**典型 WACC 范围：**
- 稳定行业（如公用事业）：7%-9%
- 一般行业：8%-11%
- 高风险行业：12%-15%

---

### 自由现金流预测

#### 自由现金流（FCF）定义

**公式：**
```
FCF = 经营现金流 - 资本支出
或
FCF = EBIT × (1-T) + 折旧摊销 - 资本支出 - 营运资本变化
```

#### 预测期（Explicit Forecast Period）

**长度：** 通常 5-10 年

**选择原则：**
- 业务稳定后
- 增长率趋于长期增长率
- 通常 5 年为标准

#### 收入增长率预测

**方法：**
1. 基于历史增长率
2. 分析师一致预期
3. 管理层指引
4. 行业增长率
5. 公司具体驱动因素

**合理性检验：**
- 长期增长率不应超过名义 GDP 增长率太多
- 通常假设最终降至 2%-4%

#### 利润率预测

**考虑因素：**
- 历史利润率趋势
- 规模效应
- 竞争格局
- 定价能力
- 成本结构

**警告：** 避免假设利润率无限制扩张

#### 营运资本变动

**组成：**
- 应收账款
- 存货
- 应付账款

**预测方法：**
- 占收入百分比
- 历史周转天数

#### 资本支出（CapEx）

**组成：**
- 维护性 CapEx：维持现有产能
- 增长性 CapEx：扩张产能

**预测方法：**
- 历史占收入比例
- 折旧占收入比例
- 管理层资本支出计划

---

### 终值（Terminal Value）

终值是预测期之后的持续价值，通常占 DCF 价值的 50%-70%。

#### 方法一：永续增长模型（Gordon Growth）

**公式：**
```
终值 = (FCFn × (1+g)) / (WACC - g)

其中：
FCFn = 预测期最后一年的自由现金流
g = 长期增长率
WACC = 加权平均资本成本
```

**长期增长率（g）选择：**
- 通常假设 2%-4%（接近长期 GDP 增长率）
- 不应超过名义 GDP 增长率
- 发达市场通常 2%-3%
- 新兴市场可能 3%-5%

**限制条件：** 必须 g < WACC

#### 方法二：终值倍数法（Exit Multiple）

**公式：**
```
终值 = 指标（EBITDA 或 EBIT 或 FCF） × 终值倍数
```

**常用倍数：**
- EV/EBITDA：8-15倍（取决于行业）
- P/E：15-25倍
- FCF 倍数：10-20倍

**来源：**
- 当前交易倍数
- 历史平均倍数
- 同业倍数

#### 混合方法（推荐）

**方法：** 同时使用两种方法，取平均值或赋予权重

**优点：** 降低单一方法的偏差

## DCF 实操步骤

### 第一步：收集历史数据

**需要的数据：**
- 过去 3-5 年财务报表
- 收入、利润率、现金流、资本支出
- 债务结构和利率
- 股票价格和 Beta

### 第二步：设定关键假设

**假设清单：**
- [ ] WACC（股权成本、债务成本、资本结构）
- [ ] 预测期年数
- [ ] 收入增长率
- [ ] 利润率
- [ ] 营运资本/收入比
- [ ] 资本支出/收入比
- [ ] 长期增长率
- [ ] 终值倍数（如使用）

**关键原则：**
- 所有假设必须有依据
- 参考历史数据
- 参考同业
- 参考管理层指引

### 第三步：构建预测模型

**表格格式：**

| 年份 | 第1年 | 第2年 | 第3年 | 第4年 | 第5年 |
|------|-------|-------|-------|-------|-------|
| 收入增长率 | % | % | % | % | % |
| 收入（$M） | | | | | |
| EBITDA 率 | % | % | % | % | % |
| EBITDA（$M） | | | | | |
| 折旧摊销（$M） | | | | | |
| EBIT（$M） | | | | | |
| 税率 | % | % | % | % | % |
| NOPAT（$M） | | | | | |
| (+) 折旧摊销 | | | | | |
| (-) 资本支出 | | | | | |
| (-) 营运资本变动 | | | | | |
| (=) FCF（$M） | | | | | |

### 第四步：折现到现值

**计算：**

| 年份 | FCF（$M） | 折现因子 | PV FCF（$M） |
|------|-----------|----------|--------------|
| 第1年 | $ | 1/(1+WACC)^1 | $ |
| 第2年 | $ | 1/(1+WACC)^2 | $ |
| 第3年 | $ | 1/(1+WACC)^3 | $ |
| 第4年 | $ | 1/(1+WACC)^4 | $ |
| 第5年 | $ | 1/(1+WACC)^5 | $ |
| **终值** | $ | 1/(1+WACC)^5 | $ |
| **企业价值** | | | **$** |

### 第五步：计算股权价值和每股价值

**计算：**
```
企业价值 = PV(预测期 FCF) + PV(终值)
股权价值 = 企业价值 - 净债务 + 现金
每股价值 = 股权价值 / 稀释股数
```

## 敏感性分析

### 关键假设敏感性

**测试变量：**
- WACC
- 长期增长率
- 收入增长率
- 利润率

**敏感性矩阵示例（WACC vs 长期增长率）：**

| g \ WACC | 8% | 9% | 10% | 11% |
|----------|-----|-----|------|------|
| 2% | $50 | $45 | $40 | $36 |
| 3% | $55 | $48 | $42 | $38 |
| 4% | $62 | $53 | $45 | $40 |

**目的：** 展示不同假设下的目标价范围

## DCF 常见错误

### 假设过于乐观

**表现：**
- 长期增长率过高（> 5%）
- 利润率无限扩张
- 收入增长率远高于历史和行业

### 资本支出低估

**表现：**
- 假设资本支出持续低于折旧
- 忽略维护性资本支出
- 忽略增长性资本支出

### 营运资本忽略

**表现：**
- 假设营运资本为零变动
- 忽略业务增长需要的营运资本

### 终值占比过高

**表现：**
- 终值占企业价值 > 80%
- 表明预测期太短或假设问题

### WACC 错误

**表现：**
- Beta 选择不当
- 无风险利率使用错误
- 资本结构假设不合理

## 注意事项

1. **[ASSUMPTION] 标注：** 所有前瞻性假设必须标注
2. **敏感性分析：** 必须展示不同情景下的目标价
3. **合理性检查：** 假设必须在合理范围内
4. **数据来源：** 所有输入数据必须有来源
5. **透明度：** 计算过程必须透明可追溯
