### 1. 修复科技新闻推送脚本bug ✓

**问题**：
- `push-tech-news.sh` 中的变量 `i` 在 Python 单引号字符串中无法解析
- 导致推送失败：`NameError: name 'i' is not defined`
- Cron 任务运行失败，日志显示报错

**解决方案**：
```bash
# 修改前（错误）:
python3 -c "
content = '''$CONTENT'''
result = subprocess.run([...], ...)
# 变量 i 无法在单引号字符串中解析
"

# 修改后（正确）:
python3 -c "
content = sys.argv[1]
part_num = $i
total_parts = $TOTAL_PARTS
" "$CONTENT"
```

**测试结果**：
- ✅ 成功发送 3 条消息到飞书

## 🎓 学习要点

1. **不要执着于单一方案**
   - 微信公众号不是唯一的内容源
   - 多平台 RSS 覆盖更全面
   - 有时候替代方案更优

2. **免费方案可行**
   - 公开 RSS 源质量高
   - 无需付费 API
   - 完全自动化

3. **稳定性优先**
   - 选择成熟、稳定的协议（RSS）
   - 避免依赖需要授权的服务
   - 简单即是美

4. **bash 脚本中的变量传递**
   - Python 单引号字符串中不能解析 shell 变量
   - 使用 `sys.argv` 传递参数更可靠
   - 避免在 shell 中嵌入复杂 Python 代码

### 核心理念：职责分离

**传统 AI 网页能力的问题**：
- 靠搜索引擎拼概率 → 结果不全、过时
- 硬啃原始 HTML → 大规模数据时会幻觉

> "At 10 pages, you won't notice. At 100 pages, your agent will start making decisions based on data that's wrong in ways you can't even detect."
>
> —— 10页时你不会注意到，到了100页，Agent会开始根据那些你甚至都无法察觉其错误之处的数据来做决定。

**正确架构**：职责彻底分离
- **Apify**: 确定性抓取（20年经验，海量稳定 Actor）
- **LLM**: 智能分析、决策、输出洞见

---

### 技术方案

**工具组合**：
1. **Apify** - 20年网页抓取经验，积累海量 Actor（Serverless 云程序）
2. **Apify Agent Skills** - 12个预构建技能包
3. **Claude Code/Cursor** - 通过自然语言调用 Apify 技能

---

### 安装步骤

**1. 安装 Agent Skills**
```bash
npm install -g apify-agent-skills
```
安装时全选12个技能：
- lead generation
- competitor analysis
- ecommerce
- ultimate scraper
- actor development
- 等

**2. 获取 Apify API Token**
- 访问: https://console.apify.com/account/integrations
- 创建免费账号
- 复制 API Token

**3. 配置项目**
在项目目录创建 `.env` 文件：
```bash
APIFY_TOKEN=你的token
```

**4. 在 Claude Code 中使用自然语言**

列出所有技能：
```
list all the agent skills you have access to
```

执行抓取：
```
run lead generation skill for AI startups in San Francisco
```

链式提取：
```
extract emails from the previous results
```
