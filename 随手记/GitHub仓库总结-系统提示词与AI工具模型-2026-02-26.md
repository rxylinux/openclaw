## 🚀 如何使用

### 1. 查看系统提示词
```bash
# 下载仓库
git clone https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools.git

# 查看系统提示词
cd system-prompts-and-models-of-ai-tools
ls -la prompts/system/
```

### 2. 优化AI Agent
```bash
# 选择合适的系统提示词
cp prompts/system/investment-agent.md ~/.agent-config/

# 集成内部工具
cd tools/code
python3 optimize_code.py
```

### 3. 选择AI模型
```bash
# 查看模型选择指南
ls -la models/selection/

# 查看优化建议
cat models/optimization/cost_control.md
```
