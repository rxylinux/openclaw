# 估值模型构建器

## 核心原则

**透明性是第一原则。** 每一个数值假设都必须标注来源，不允许使用凭空捏造的数据。

- **[ASSUMPTION]** - 标注假设性数值，必须说明选择理由和支持来源
- **数据来源** - 明确标注：公司财报、分析师一致预期、历史数据、行业标准等
- **计算过程** - 展示关键计算的完整步骤，特别是 WACC 和折现率

## 估值分析工作流

当用户请求估值分析时，按以下顺序执行：

### 0. 数据收集前置步骤

在开始估值之前，必须获取以下关键数据：

1. **公司基本信息**
   - 公司名称 / 股票代码
   - 最新股价（注明日期）
   - 市值

2. **财务数据来源优先级**
   - 首选：最新 10-K（年度）和 10-Q（季度）财报
   - 次选：财经网站（如 Yahoo Finance、东方财富、同花顺）
   - 再次：公司官网投资者关系页面

3. **分析师数据**
   - 分析师一致预期（营收增长、利润率）
   - 目标价（最高、最低、中位）
   - 更新时间（过去 90 天内更新数量）

```

- 税前债务成本：X%（来源：公司债券收益率）
- 税率：X%（来源：公司实际税率）

资本结构：
- 权益占比：X%
- 债务占比：Y%

WACC = Ke × 权益占比 + Kd × 债务占比
     = X% × X% + X% × X%
     = X%
```

## 输出格式要求

1. **清晰的标题结构** - 使用 ##、### 分级标题
2. **标注清楚的表格** - 使用 markdown 表格展示数据
3. **假设来源标注** - 每个假设必须标注 [ASSUMPTION] 并说明理由
4. **数据来源标注** - 关键数据必须标注来源和日期
5. **数字精确性** - 货币单位保持一致（如：全部用人民币/元）

## 使用技巧

1. **数据优先** - 在开始估值前，确保所有必要数据已收集
2. **假设透明** - 每个假设都必须明确标注并解释
3. **交叉验证** - 多种估值方法的结果应相互印证
4. **风险提示** - 明确列出关键风险和不确定性
5. **定期更新** - 估值模型应随新财报和市场变化更新
