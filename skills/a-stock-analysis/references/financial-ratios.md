# 财务指标速查手册

## 盈利能力指标

### ROE (净资产收益率)
**定义**: 净利润 / 平均净资产 × 100%
**含义**: 股东投入资本能带来多少回报
**标准**:
- >20%: 优秀（贵州茅台、海天味业级别）
- 15-20%: 良好（大多数优质白马）
- 10-15%: 一般
- <10%: 较差
**注意**: 高杠杆会虚高ROE，需结合负债率看

### 毛利率
**定义**: (营收 - 营业成本) / 营收 × 100%
**含义**: 产品定价能力和成本控制水平
**行业差异**:
- 软件/SaaS: 60-80%
- 医药生物: 70-85%
- 消费品牌: 50-70%
- 制造业: 20-35%
- 零售贸易: 10-20%

### 净利率
**定义**: 净利润 / 营收 × 100%
**含义**: 扣除所有费用后的最终盈利能力
**标准**:
- >15%: 优秀（高端消费、科技龙头）
- 10-15%: 良好
- 5-10%: 一般
- <5%: 较差（竞争激烈行业）

## 成长性指标

### 营收增长率
**标准**:
- >30%: 高速成长（成长股）
- 15-30%: 稳健增长
- 5-15%: 缓慢增长
- <5%: 成熟期或衰退期

### 净利润增长率
**注意**: 剔除非经常性损益（扣非净利润）
**标准**:
- >30%: 高速
- 15-30%: 稳健
- 5-15%: 缓慢

### CAGR (复合年增长率)
**公式**: (期末值 / 期初值)^(1/n) - 1
**含义**: 过去N年的平均年化增速
**应用**:
- 3年CAGR: 中期趋势判断
- 5年CAGR: 长期成长能力

## 估值指标

### PE (市盈率)
**定义**: 股价 / 每股收益（EPS）
**含义**: 回本所需年数
**行业PE参考**:
- 科技/成长股: 30-60倍
- 消费/医药: 25-40倍
- 制造/周期股: 10-25倍
- 银行/公用: 5-10倍

### PB (市净率)
**定义**: 股价 / 每股净资产
**含义**: 相对账面值的溢价程度
**适用**: 重资产行业（银行、地产、制造）
**注意**: 轻资产公司（SaaS、互联网）PB参考价值低

### PEG (市盈增长比)
**定义**: PE / 净利润增长率
**含义**: 估值与成长的匹配度
**标准**:
- <0.8: 低估
- 0.8-1.2: 合理
- 1.2-2.0: 略高
- >2.0: 高估（成长溢价过高）

### PS (市销率)
**定义**: 市值 / 营收
**适用**: 亏损或低利润率公司（SaaS、互联网）
**行业参考**:
- SaaS: 10-20倍
- 互联网: 5-15倍
- 零售: 1-3倍

## 财务健康指标

### 资产负债率
**定义**: 总负债 / 总资产 × 100%
**标准**:
- <40%: 非常健康
- 40-60%: 健康
- 60-70%: 需关注
- >70%: 风险较高

### 流动比率
**定义**: 流动资产 / 流动负债
**含义**: 短期偿债能力
**标准**:
- >2: 安全
- 1.5-2: 正常
- <1.5: 警惕

### 现金比率
**定义**: (现金+现金等价物) / 流动负债
**含义**: 最严格偿债能力（无依赖存货和应收款）
**标准**:
- >0.5: 非常健康
- 0.2-0.5: 正常
- <0.2: 现金压力

### 存货周转天数
**定义**: 365 / (营业成本 / 平均存货)
**含义**: 存货变现速度
**行业差异**:
- 快消品: 30-60天
- 耐用品: 60-120天
- 周期品: 90-180天
- 异常高: 滞销风险

### 应收账款周转天数
**定义**: 365 / (营收 / 平均应收账款)
**含义**: 回款速度、客户质量
**标准**:
- <30天: 优秀（强势议价）
- 30-60天: 正常
- 60-90天: 需关注
- >90天: 风险（大客户依赖）

## 经营质量指标

### 扣非净利润占比
**定义**: 扣非净利润 / 净利润 × 100%
**含义**: 盈利可持续性
**标准**:
- >90%: 可靠（主营业务为主）
- 70-90%: 一般（部分非经常收益）
- <70%: 需剔除（不可持续）

### 经营现金流/净利润
**定义**: 经营现金流 / 净利润
**含义**: 利润含金量（有无虚构）
**标准**:
- >1.2: 优秀（现金奶牛）
- 0.8-1.2: 正常
- 0.5-0.8: 需关注（大量应收账款）
- <0.5: 警惕（纸面利润）

### 研发费用占比
**定义**: 研发费用 / 营收 × 100%
**含义**: 创新投入、技术储备
**行业参考**:
- 高科技: 10-20%
- 医药生物: 8-15%
- 智能制造: 5-10%
- 传统制造: 2-5%

## 常见陷阱

1. **ROE虚高**: 高杠杆公司ROE高但风险大
   → 看ROIC（投入资本回报率）更准确

2. **PE失真**: 净利润大增或大降时PE失真
   → 看PE-TTM（滚动12个月）

3. **成长股用PE**: 高成长公司PE通常很高
   → 用PEG更合理

4. **周期股用PE**: 周期顶部时PE很低（业绩高）
   → 看PB或市净率更准确

5. **扣非忽略**: 非经常收益（政府补助、卖资产）不可持续
   → 必须看扣非净利润
