# 收入分解提示指南

## 核心目标

把公司的收入拆开来看，找出：
- 哪块业务在赚钱？哪块在拖后腿？
- 客户是不是太集中？丢一个客户会不会慌？
- 产品是不是太单一？一个产品不行会不会全垮？

## 分析三问

### 1. 哪些部门在增长？哪些在放缓？

**要看的数据**:
- 各业务板块收入占比
- 各板块同比增长率
- 各板块毛利率

**分析框架**:

| 业务板块 | 收入占比 | 增速 | 评价 |
|---------|---------|-------|------|
| 板块A | 40% | +30% | ✅ 核心引擎，增速健康 |
| 板块B | 30% | +5% | ⚠️ 增速放缓，需关注 |
| 板块C | 20% | -10% | ❌ 拖后腿，可能需转型 |
| 其他 | 10% | +50% | 📈 基数小但爆发，观察持续性 |

**输出要求**:
- 用"增长引擎"、"拖后腿"、"转型中"等直观词汇
- 标注哪个是主业，哪个是新兴业务
- 分析业务结构是否健康（鸡蛋是否放一个篮子）

### 2. 对顶级客户依赖程度如何？

**关键指标**:
- 前五大客户收入占比
- 最大单一客户占比
- 客户集中度同比变化

**判断标准**:

| 占比 | 风险级别 | 解释 |
|------|----------|------|
| 最大客户 <10% | 🟢 低风险 | 丢一个客户不疼不痒 |
| 最大客户 10-30% | 🟡 中等风险 | 丢大客户会有影响但不致命 |
| 最大客户 >50% | 🔴 高风险 | 大客户一走，业绩腰斩 |
| 前五大客户 >70% | 🔴 极高风险 | 被客户拿捏，议价权弱 |

**输出要求**:
- 明确写出"前五大客户占X%，最大客户占Y%"
- 说明客户构成（政府/企业/个人）
- 分析客户议价能力（强势还是弱势）

### 3. 对顶级产品依赖程度如何？

**关键指标**:
- 前五大产品收入占比
- 单一产品收入占比
- 产品收入增速对比

**判断标准**:

| 占比 | 风险级别 | 解释 |
|------|----------|------|
| 单一产品 <20% | 🟢 低风险 | 产品多元化，不靠单品吃饭 |
| 单一产品 20-40% | 🟡 中等风险 | 主打产品明显，但有一定储备 |
| 单一产品 >60% | 🔴 高风险 | 单品依赖，产品不行就完了 |

**输出要求**:
- 列出前三大产品及收入占比
- 说明产品生命周期（爆发期/成熟期/衰退期）
- 分析是否有新品接力

## 收入结构健康度评分

### 综合评分表

| 维度 | 得分 | 评分依据 |
|------|------|----------|
| **业务多元化** | _/10 | 业务板块数量及占比分布 |
| **增长均衡性** | _/10 | 是否存在单一板块拖累 |
| **客户集中度** | _/10 | 前五大客户占比，越低越好 |
| **产品集中度** | _/10 | 前五大产品占比，越低越好 |
| **客户质量** | _/10 | 客户行业地位和议价能力 |
| **总收入** | _/50 | 综合评价 |

### 评分标准

**40-50分**: 🟢 健康多元化
- 多业务并进，客户分散，产品丰富
- 丢了谁都不怕，转型也有路

**30-39分**: 🟡 结构尚可
- 主业明确但有一定支撑
- 客户或产品略显集中但不致命

**20-29分**: 🟠 需关注
- 单一业务或产品依赖明显
- 大客户或大产品风险较高

**0-19分**: 🔴 结构高危
- 单一客户或产品收入占比>60%
- 随时可能被客户/市场卡脖子

## 行业对比视角

### 收入结构横向对比

| 公司 | 前五大客户占比 | 单一产品占比 | 业务板块数 |
|------|---------------|-------------|----------|
| 公司A | 15% | 20% | 5个 |
| 公司B | 60% | 70% | 2个 |
| 公司C | 40% | 30% | 3个 |

**分析维度**:
- 谁的客户更分散？
- 谁的产品更丰富？
- 谁的业务结构更抗风险？

## 快速检查清单

在输出收入分解前，问自己：

- [ ] 能不能用"赚钱/拖后腿/转型中"这种词描述增速？
- [ ] 能不能列出前三大业务及占比？
- [ ] 能不能说出前五大客户占比？
- [ ] 能不能判断客户/产品依赖是高/中/低风险？
- [ ] 能不能给收入结构打个总分（0-50分）？
- [ ] 能不用"主营业务收入/产品矩阵/客户结构"这种术语？

## 常见输出模板

### 模板1：多业务平衡型

```
### 💰 收入怎么来的

**业务板块**:
- 板块A（40%）：赚了X亿，增长30%，是核心引擎 ✅
- 板块B（30%）：赚了X亿，增长5%，比较平稳 ⚠️
- 板块C（20%）：赚了X亿，下滑10%，在拖后腿 ❌
- 其他（10%）：基数小但增速快，观察中 📈

**客户分布**:
- 前五大客户占35%，风险中等 🟡
- 最大客户占12%，丢了也能撑住

**产品依赖**:
- 前三大产品占45%，有点集中但还能抗 🟡
- 没有单一产品占超30%，不是靠单品吃饭

**结构健康度**: 35/50分 - 结构尚可，主业明确但略显集中
```

### 模板2：单业务依赖型

```
### 💰 收入怎么来的

**业务板块**:
- 板块A（85%）：几乎全靠这个赚钱，增长20%
- 其他（15%）：零头业务，没啥存在感

**客户分布**:
- 前五大客户占70%，风险很高 🔴
- 最大客户占40%，大客户一走业绩腰斩

**产品依赖**:
- 产品X（65%）：六成多收入靠这一个，产品不行就完了 🔴
- 产品Y（15%）：主打产品的配角

**结构健康度**: 18/50分 - 结构高危，单一客户+产品双依赖
风险: 客户拿捏议价权，产品迭代慢会出大事
```

### 模板3：多元化均衡型

```
### 💰 收入怎么来的

**业务板块**:
- 板块A（35%）：主力业务，增长25%
- 板块B（25%）：第二引擎，增长20%
- 板块C（20%）：第三增长点，增长15%
- 板块D（20%）：新兴业务，增长60% 🚀

**客户分布**:
- 前五大客户占20%，很分散 🟢
- 最大客户占6%，丢了不疼不痒

**产品依赖**:
- 前五大产品占30%，产品线丰富 🟢
- 没有单一产品占超15%，鸡蛋没放一个篮子

**结构健康度**: 42/50分 - 健康多元化
优势: 丢了谁都不怕，多条腿走路
```
