# 估值方法论

## DCF（现金流折现）模型

### 核心公式

```
企业价值 = Σ [自由现金流t / (1 + WACC)^t] + [终值 / (1 + WACC)^n]

其中：
- 自由现金流t = 第 t 年的自由现金流
- WACC = 加权平均资本成本
- 终值 = 永续期价值
- n = 预测期年数
```

### 自由现金流计算

```
自由现金流 = EBIT × (1 - 税率) + 折旧摊销 - 资本支出 - 营运资本变化

或

自由现金流 = 净利润 + 折旧摊销 - 资本支出 - 营运资本变化
```

### WACC 计算详细步骤

```
股权成本（Ke）= Rf + β × (Rm - Rf)
- Rf = 无风险利率（10 年期国债收益率）
- β = Beta 系数
- Rm - Rf = 市场风险溢价

债务成本（Kd）= 税前债务成本 × (1 - 税率)

WACC = Ke × (权益 / 总资本) + Kd × (债务 / 总资本)
```

### 终值计算方法

**方法 1：永续增长模型**
```
终值 = 第 6 年自由现金流 / (WACC - g)
- g = 永续增长率（通常 2-3%）
```

**方法 2：退出倍数法**
```
终值 = 第 5 年 EBITDA × 行业平均 EV/EBITDA 倍数
```

## 可比公司估值

### 关键估值倍数

**P/E（市盈率）**
```
P/E = 当前股价 / 每股收益（EPS）

或

P/E = 总市值 / 净利润
```

**P/S（市销率）**
```
P/S = 当前股价 / 每股销售额

或

P/S = 总市值 / 营收
```

**EV/EBITDA**
```
企业价值（EV）= 市值 + 净债务

EV/EBITDA = 企业价值 / 息税折旧摊销前利润
```

### 可比公司选择标准

1. **行业相似** - 同一 GICS 行业
2. **业务模式** - 产品/服务相似
3. **规模相近** - 市值在同一数量级
4. **增长阶段** - 成长期/成熟期
5. **地理市场** - 相似的市场环境

## 情景分析

### 三种情景框架

**Bull 情景（乐观）**
- 营收增长率：高于指引 3-5%
- 利润率：高于当前 2-3%
- 估值倍数：高于同行 10-20%
- 概率：20-30%

**Base 情景（基准）**
- 营收增长率：符合指引
- 利润率：维持当前
- 估值倍数：同行平均
- 概率：40-50%

**Bear 情景（悲观）**
- 营收增长率：低于指引 3-5%
- 利润率：低于当前 2-3%
- 估值倍数：低于同行 10-20%
- 概率：20-30%

### 概率加权期望值

```
期望值 = Σ(目标价 × 概率)

示例：
- Bull：$150 × 30% = $45
- Base：$120 × 50% = $60
- Bear：$90 × 20% = $18
- 期望值 = $45 + $60 + $18 = $123
```
