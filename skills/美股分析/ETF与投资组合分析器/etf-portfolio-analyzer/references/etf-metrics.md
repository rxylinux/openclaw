# ETF 分析指标说明

## 基础指标

### 费用率（Expense Ratio）

**定义：** ETF 每年收取的管理费用占基金资产净值（NAV）的百分比。

**计算：**
```
费用率 = 年度总费用 / 基金资产净值
```

**解读：**
- < 0.10%：极低成本（如 VTI, VOO）
- 0.10% - 0.30%：低成本
- 0.30% - 0.75%：中等成本
- > 0.75%：高成本

**影响：**
- $10,000 投资，0.05% vs 0.50% 费用率，10 年差异约 $450

### 资产管理规模（AUM）

**定义：** ETF 管理的总资产价值。

**风险阈值：**
- AUM < $50M：⚠️ 清盘风险较高
- AUM $50M-$200M：🟡 中等风险
- AUM > $200M：✅ 相对安全

### 日均交易量（ADV）

**定义：** ETF 每日平均交易股数。

**流动性评估：**
- ADV < 10万股：⚠️ 流动性较差，买卖价差可能较大
- ADV 10万-100万股：🟡 中等流动性
- ADV > 100万股：✅ 流动性良好

### 买卖价差（Bid-Ask Spread）

**定义：** 买入价与卖出价的差额。

**评估：**
- 价差 < 0.10%：✅ 交易成本低
- 价差 0.10%-0.30%：🟡 可接受
- 价差 > 0.30%：⚠️ 交易成本高

## 风险指标

### Beta（贝塔系数）

**定义：** 衡量 ETF 相对于基准指数（通常为标普 500）的波动性。

**计算：**
```
Beta = Cov(ETF收益, 基准收益) / Var(基准收益)
```

**解读：**
| Beta 值 | 含义 | 风险级别 |
|---------|------|----------|
| 1.0 | 与市场同步 | 中等 |
| > 1.0 | 比市场波动更大 | 高 |
| < 1.0 | 比市场波动更小 | 低 |
| < 0 | 与市场反向 | 对冲/套利 |

### 标准差（波动率）

**定义：** ETF 收益率偏离平均值的程度，衡量波动性。

**年化波动率计算：**
```
年化波动率 = 日波动率 × √252
或
年化波动率 = 月波动率 × √12
```

**评估：**
- < 15%：低波动率（如债券 ETF）
- 15% - 25%：中等波动率（如大盘股 ETF）
- > 25%：高波动率（如小盘股、行业 ETF）

### 最大回撤（Maximum Drawdown）

**定义：** 从峰值到谷值的最大跌幅。

**计算：**
```
最大回撤 = (峰值 - 谷值) / 峰值 × 100%
```

**评估：**
- < 20%：风险可控
- 20% - 40%：⚠️ 中等风险
- > 40%：🚨 高风险

### 夏普比率（Sharpe Ratio）

**定义：** 风险调整后的收益衡量指标。

**计算：**
```
夏普比率 = (ETF收益率 - 无风险利率) / ETF波动率
```

**解读：**
- < 1.0：较差的风险调整后收益
- 1.0 - 2.0：良好
- > 2.0：优秀
- < 0：风险调整后收益为负

### 信息比率（Information Ratio）

**定义：** 相对于基准的超额收益与跟踪误差的比值。

**计算：**
```
信息比率 = (ETF收益 - 基准收益) / 跟踪误差
```

**解读：**
- > 0.5：良好的主动管理
- 0 - 0.5：中等
- < 0：跑输基准

## 收益指标

### 总收益率（Total Return）

**定义：** 包含价格变动和股息再投资的总体回报。

**计算：**
```
总收益率 = (期末净值 - 期初净值 + 股息) / 期初净值
```

### 股息率（Dividend Yield）

**定义：** 年度股息占当前价格的比例。

**计算：**
```
股息率 = 年度股息 / 当前价格 × 100%
```

### 股息增长率

**定义：** 股息年度增长百分比。

**计算：**
```
股息增长率 = (本年股息 - 去年股息) / 去年股息 × 100%
```

---

## 跟踪误差（Tracking Error）

**定义：** ETF 收益与基准收益偏离的标准差。

**计算：**
```
跟踪误差 = Std(ETF收益 - 基准收益)
```

**解读：**
- < 0.10%：优秀跟踪
- 0.10% - 0.50%：良好跟踪
- > 0.50%：跟踪误差较大

---

## 持仓集中度指标

### 前 10 大持仓占比

**定义：** 前 10 大持仓占基金净资产的比例。

**评估：**
- < 30%：高度分散
- 30% - 60%：适中集中
- > 60%：高度集中

### 权重上限

**定义：** 单一持仓的最大权重限制。

**常见限制：**
- 广基指数 ETF：通常 < 5%
- 行业 ETF：可能 > 10%

---

## 风险价值（VaR）

**定义：** 在给定置信水平下，特定时期内的最大可能损失。

**示例：**
- 95% VaR, 1天 = 3%：表示有 95% 的概率，单日损失不超过 3%

---

## 相关系数矩阵

**用途：** 评估多个 ETF 之间的相关性，判断分散效果。

**计算：**
```
相关系数 = Cov(A,B) / (StdA × StdB)
```

**解读：**
- 相关系数 > 0.7：高度相关，分散效果差
- 相关系数 0.4 - 0.7：中等相关
- 相关系数 < 0.4：低相关，分散效果好
