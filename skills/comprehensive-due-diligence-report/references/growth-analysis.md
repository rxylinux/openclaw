# 增长分析方法

## TAM（总可触达市场）分析

### TAM 计算方法

**方法 1：自上而下**
```
TAM = 行业总收入

示例：
- 行业总收入：$100 十亿
- 公司 TAM：$100 十亿
```

**方法 2：自下而上**
```
TAM = 目标客户数 × 每客户平均收入

示例：
- 目标客户数：10 亿
- 每客户平均收入：$10
- TAM：$100 十亿
```

## 市场份额分析

### 市场份额计算

```
市场份额 = 公司收入 / 市场规模 × 100%
```

### 市场份额趋势

```
趋势分析：

上升 → 竞争优势强化
稳定 → 维持现状
下降 → 竞争劣势或行业萎缩
```

### 竞争格局

```
市场结构：

寡头垄断：前 3 家占 > 60%
垄断竞争：前 3 家占 40-60%
竞争市场：前 3 家占 20-40%
完全竞争：前 3 家占 < 20%
```

## 增长驱动因素

### 内生增长驱动

**驱动因素类型：**

1. **产品创新**
   - 新产品推出
   - 产品升级
   - 功能扩展

2. **市场扩张**
   - 进入新市场
   - 区域扩张
   - 客户群扩张

3. **价格上涨**
   - 产品提价
   - 溢价能力

4. **效率提升**
   - 成本降低
   - 运营效率
   - 利润率提升

### 外延增长驱动

**驱动因素类型：**

1. **并购**
   - 横向并购（同行）
   - 纵向并购（上下游）
   - 跨界并购

2. **合资**
   - 战略联盟
   - 合作开发
   - 资源共享

3. **投资**
   - 少数股权投资
   - 战略投资
   - 平台投资

## 增长方式分析

### 内生增长计算

```
内生增长率 = (当年营收 - 去年营收 - 并购贡献) / 去年营收

示例：
- 当年营收：$1,100 百万
- 去年营收：$1,000 百万
- 并购贡献：$50 百万
- 内生增长：(1100 - 1000 - 50) / 1000 = 5.0%
```

### 外延增长计算

```
外延增长率 = 并购贡献 / 去年营收

示例：
- 并购贡献：$50 百万
- 去年营收：$1,000 百万
- 外延增长：50 / 1000 = 5.0%
```

### 增长方式评估

```
增长方式判断：

内生占比 > 70%：内生驱动
内生占比 40-70%：混合驱动
内生占比 < 40%：外延驱动

外延增长风险评估：
- 频繁并购：高风险
- 整合能力：关键因素
- 溢价支付：降低股东回报
```
