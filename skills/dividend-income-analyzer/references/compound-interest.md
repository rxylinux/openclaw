# 复利计算与 DRIP

## 复利基础

### 复利公式

```
终值 = 本金 × (1 + 利率)^时间

其中：
- 本金：初始投资金额
- 利率：收益率（或股息增长率）
- 时间：投资年数
```

### 简单利息 vs 复利

| 类型 | 公式 | 特点 |
|------|------|------|
| 简单利息 | 本金 × (1 + 利率 × 时间) | 利息不产生利息 |
| 复利 | 本金 × (1 + 利率)^时间 | 利息产生利息 |

**复利优势：**
- 长期效应显著
- 时间越长，差异越大
- 股息再投资的倍增器

---

## 股息复利计算

### 基本公式

**方法 1：年度股息计算**

```
第 n 年股息 = 初始股息 × (1 + 增长率)^n
```

**方法 2：年度收入计算**

```
第 n 年收入 = 初始投资金额 × (1 + 股息率) × (1 + 增长率)^n
```

**方法 3：逐步计算（更准确）**

```
第 1 年：
初始股数 = 初始投资金额 / 初始股价
年度股息收入 = 初始股数 × 每股股息
再投资股数 = 年度股息收入 / 当前股价
年末总股数 = 初始股数 + 再投资股数

第 2 年：
年度股息 = 上年股息 × (1 + 增长率)
年度股息收入 = 年末总股数 × 年度股息
再投资股数 = 年度股息收入 / 当前股价
年末总股数 = 上年总股数 + 再投资股数

... 重复至目标年份
```

## DRIP 详细计算步骤

### 步骤 1：初始设置

```
初始投资金额（P）= $10,000
初始股价（S₀）= $100.00
初始每股股息（D₀）= $3.00
股息率（Y₀）= D₀ / S₀ = 3.00 / 100.00 = 3.0%
股息增长率（g）= 8%（假设过去 5 年平均）

初始股数（N₀）= P / S₀ = 10,000 / 100 = 100 股
```

### 步骤 2：第 1 年计算

```
第 1 年每股股息（D₁）= D₀ × (1 + g) = 3.00 × 1.08 = $3.24

年度股息收入（I₁）= N₀ × D₁ = 100 × 3.24 = $324

再投资股数（R₁）= I₁ / S₁

假设股价不变（S₁ = S₀ = $100）：
R₁ = 324 / 100 = 3.24 股

年末总股数（N₁）= N₀ + R₁ = 100 + 3.24 = 103.24 股
```

### 步骤 3：第 2 年计算

```
第 2 年每股股息（D₂）= D₁ × (1 + g) = 3.24 × 1.08 = $3.50

年度股息收入（I₂）= N₁ × D₂ = 103.24 × 3.50 = $361.34

再投资股数（R₂）= I₂ / S₂

假设股价不变：
R₂ = 361.34 / 100 = 3.61 股

年末总股数（N₂）= N₁ + R₂ = 103.24 + 3.61 = 106.85 股
```

### 步骤 4：第 5 年计算

```
第 5 年每股股息（D₅）= D₀ × (1 + g)^5 = 3.00 × 1.08^5 = $4.41

年度股息收入（I₅）= N₄ × D₅

假设年末股数（N₄）≈ 117.16 股：
I₅ = 117.16 × 4.41 = $516.68

再投资股数（R₅）= I₅ / S₅ = 516.68 / 100 = 5.17 股

年末总股数（N₅）= N₄ + R₅ = 117.16 + 5.17 = 122.33 股

投资组合价值 = N₅ × S₅ = 122.33 × 100 = $12,233
```

### 步骤 5：第 10 年计算

```
第 10 年每股股息（D₁₀）= D₀ × (1 + g)^10 = 3.00 × 1.08^10 = $6.48

年度股息收入（I₁₀）= N₉ × D₁₀

假设年末股数（N₉）≈ 148.97 股：
I₁₀ = 148.97 × 6.48 = $965.34

再投资股数（R₁₀）= I₁₀ / S₁₀ = 965.34 / 100 = 9.65 股

年末总股数（N₁₀）= N₉ + R₁₀ = 148.97 + 9.65 = 158.62 股

投资组合价值 = N₁₀ × S₁₀ = 158.62 × 100 = $15,862
```

### 步骤 6：第 20 年计算

```
第 20 年每股股息（D₂₀）= D₀ × (1 + g)^20 = 3.00 × 1.08^20 = $13.98

年度股息收入（I₂₀）= N₁₉ × D₂₀

假设年末股数（N₁₉）≈ 254.69 股：
I₂₀ = 254.69 × 13.98 = $3,560.60

再投资股数（R₂₀）= I₂₀ / S₂₀ = 3,560.60 / 100 = 35.61 股

年末总股数（N₂₀）= N₁₉ + R₂₀ = 254.69 + 35.61 = 290.30 股

投资组合价值 = N₂₀ × S₂₀ = 290.30 × 100 = $29,030
```

## 复利增长总结表

基于上述计算：

| 年份 | 每股股息 | 年度股息收入 | 年末股数 | 投资组合价值 | 增长率 |
|------|---------|-------------|----------|-------------|--------|
| 0 | $3.00 | $0 | 100.00 | $10,000 | - |
| 1 | $3.24 | $324 | 103.24 | $10,324 | 3.2% |
| 2 | $3.50 | $361 | 106.85 | $10,685 | 3.5% |
| 3 | $3.78 | $404 | 110.89 | $11,089 | 3.8% |
| 4 | $4.08 | $452 | 115.41 | $11,541 | 4.1% |
| 5 | $4.41 | $517 | 122.33 | $12,233 | 6.0% |
| 10 | $6.48 | $965 | 158.62 | $15,862 | 8.0% |
| 15 | $9.51 | $1,634 | 219.57 | $21,957 | 9.8% |
| 20 | $13.98 | $3,561 | 290.30 | $29,030 | 11.7% |

**关键观察：**
- 20 年后股息收入增长 11 倍（从 $324 到 $3,561）
- 投资组合价值增长 1.9 倍（从 $10,000 到 $29,030）
- 复利效应随时间加速

## 快速估算公式

### 规则 72

**用途：** 估算翻倍所需时间

```
翻倍时间 ≈ 72 / 利率

示例：
- 股息增长率 8%：72 / 8 = 9 年翻倍
- 股息增长率 10%：72 / 10 = 7.2 年翻倍
```

### 简化复利公式

**用途：** 快速估算最终价值

```
最终价值 ≈ 本金 × (1 + 利率 × 时间 / 2)

示例：
- 本金 $10,000，利率 8%，20 年
- ≈ 10,000 × (1 + 0.08 × 10) = $18,000

注意：这是低估，实际更高
```

### 年度增长率公式

**用途：** 快速计算股息增长

```
最终股息 = 初始股息 × (1 + 增长率)^年数

示例：
- 初始股息 $3.00，增长率 8%，10 年
- = 3.00 × 1.08^10 = $6.48
```

## 不同股息增长率的影响

假设初始投资 $10,000，股息率 3%，股价不变：

| 股息增长率 | 5 年股息收入 | 10 年股息收入 | 20 年股息收入 |
|-----------|-------------|--------------|--------------|
| 0% | $300 | $300 | $300 |
| 2% | $330 | $364 | $441 |
| 4% | $365 | $442 | $653 |
| 6% | $401 | $536 | $968 |
| 8% | $441 | $648 | $1,439 |
| 10% | $483 | $785 | $2,141 |

**关键结论：**
- 增长率差异长期影响巨大
- 0% vs 10%：20 年后相差 7 倍
- 寻找可持续的高增长公司

## 不同初始股息率的影响

假设初始投资 $10,000，股息增长率 8%，股价不变：

|-----------|-------------|--------------|--------------|

| 2% | $294 | $432 | $960 |

| 5% | $735 | $1,080 | $2,398 |

- 初始股息率影响基础收入

- 平衡股息率和增长率

## 季度 vs 年度股息再投资

### 季度再投资（更精确）

```
季度股息 = 年度股息 / 4
季度增长率 = (1 + 年度增长率)^(1/4) - 1

每季度计算一次复利
```

**示例：**
- 年度增长率：8%
- 季度增长率：(1.08)^(1/4) - 1 ≈ 1.94%

### 年度再投资（简化）

```
每年计算一次复利
```

**差异：**
- 季度再投资收益略高
- 差异约 0.1-0.3%
- 为简化，年度再投资足够

## 股价变化的影响

### 股价上涨

```
假设股价每年上涨 5%：

第 1 年：
- 股价 = $100 × 1.05 = $105
- 再投资股数 = 324 / 105 = 3.09 股（vs 3.24 股）

影响：
- 每次再投资购买的股数减少
- 但每股价值增加
- 最终影响取决于股价增长率
```

### 股价下跌

```
假设股价每年下跌 5%：

第 1 年：
- 股价 = $100 × 0.95 = $95
- 再投资股数 = 324 / 95 = 3.41 股（vs 3.24 股）

影响：
- 每次再投资购买的股数增加
- 但每股价值下降
- 长期可能更受益（低价积累更多股数）
```

### DRIP 最佳策略

**理想情况：**
- 股价稳定或温和增长
- 股息持续增长
- 长期持有（10 年以上）

**风险：**
- 股价大幅下跌：短期损失，长期可能收益
- 股价大幅上涨：再投资效率降低
- 公司削减股息：计划受挫

## DRIP 税务影响

### 税务处理

**美国税制：**
- 每次股息再投资都需要交税
- 即使不收到现金
- 使用再投资股数调整成本基础

**示例：**
```
第 1 年：
- 再投资股息：$324
- 税率（假设 15%）：$48.60
- 实际再投资金额：$324 - $48.60 = $275.40

成本基础调整：
- 初始成本：$10,000
- 第 1 年增加：$324
- 总成本基础：$10,324

第 20 年出售：
- 售价：$29,030
- 成本基础：$20,000（累积）
- 应税收益：$9,030
```

### 退休账户优势

**IRA、401(k)：**
- 股息再投资暂不交税
- 退休时交税（传统 IRA）或免税（Roth IRA）
- 复利效应最大化

## 计算检查清单

在进行 DRIP 计算前，检查：

- [ ] 使用正确的股息增长率（过去 5 年平均）
- [ ] 股息率基于最新股价
- [ ] 考虑发放频率（季度/半年/年度）
- [ ] 假设清晰标注（股价、增长率、时间）
- [ ] 逐步展示计算过程
- [ ] 验证结果合理性（无计算错误）
- [ ] 提供多种情景（不同增长率）
- [ ] 标注风险提示（实际可能不同）
- [ ] 区分实际数据和假设
- [ ] 考虑税务影响（如适用）
