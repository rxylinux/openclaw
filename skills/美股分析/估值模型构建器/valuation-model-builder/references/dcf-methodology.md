# 现金流折现模型 (DCF) 方法详解

## DCF 模型概述

现金流折现模型（Discounted Cash Flow）是一种绝对估值方法，通过预测公司未来自由现金流并将其折现到现值来评估公司价值。

### 核心思想

```
公司价值 = 未来所有自由现金流的现值之和
```

### 优势
- 基于实际现金流，不受会计准则影响
- 理论上最严谨的估值方法
- 适用于产生稳定现金流的公司

### 局限
- 高度依赖增长假设和折现率
- 对假设变化敏感
- 不适用于高增长、波动大或未盈利公司

---

## DCF 计算步骤

### 步骤 1：预测自由现金流

#### 自由现金流定义

```
自由现金流 (FCF) = 经营活动现金流 - 资本支出
```

#### 简化计算方法

当详细现金流数据不可得时：

```
FCF = 税后净营业利润 (NOPAT) + 折旧摊销 - 资本支出 - 营运资本变动
```

其中：
```
NOPAT = EBIT × (1 - 税率)
```

### 步骤 2：确定预测期

**典型预测期：5-10 年**

| 公司类型 | 建议预测期 | 原因 |
|----------|------------|------|
| 成熟公司 | 5 年 | 增长稳定，可预测性强 |
| 成长公司 | 10 年 | 增长期长，需更长预测期 |
| 周期性公司 | 5 年 | 超过 5 年预测不可靠 |

### 步骤 3：计算终值 (Terminal Value)

终值是预测期之后所有现金流的现值。有两种常用方法：

#### 方法 1：永续增长法 (Gordon Growth Model)

```
TV = FCF_n × (1 + g) / (WACC - g)
```

其中：
- `FCF_n` = 预测期最后一年的自由现金流
- `g` = 永续增长率
- `WACC` = 加权平均资本成本

#### 方法 2：终值倍数法

```
TV = EBITDA_n × 终值倍数
```

**推荐：** 使用永续增长法，因为更符合理论

### 步骤 4：计算折现因子

```
折现因子(t) = 1 / (1 + WACC)^t
```

其中 `t` 是年份（1, 2, 3, ...）

### 步骤 5：计算现值

```
现值(PV) = 自由现金流 × 折现因子
```

### 步骤 6：计算企业价值和股权价值

```
企业价值 (EV) = 预测期现值合计 + 终值现值

股权价值 = 企业价值 - 净债务

每股价值 = 股权价值 / 稀释后股数
```

## 关键假设详解

### 永续增长率 (g)

**典型范围：2% - 3%**

| 假设值 | 适用情况 | 理由 |
|--------|----------|------|
| 2% | 成熟行业 | ≈ 长期通胀率 |
| 2.5% | 稳健增长 | 通胀 + 轻微实际增长 |
| 3% | 防御性行业 | 通胀 + 适度实际增长 |
| > 3% | 需强有力支撑 | 长期超过 GDP 增长不现实 |

**理论依据：**
- 长期来看，公司增长不可能无限超过 GDP 增长
- 美国长期 GDP 增长率约为 2-3%
- 美联储长期通胀目标为 2%

**数据来源：**
- 美联储长期经济预测
- IMF 世界经济展望
- 标普 500 长期增长率

### 营收增长率假设

**数据来源优先级：**

1. **公司指引**（最权威）
   - 公司官方财报提供的未来预期
   - 来源：财报新闻稿、电话会议

2. **分析师一致预期**（次优先）
   - 分析师预测的中位数
   - 来源：Bloomberg、FactSet

3. **历史趋势**（参考）
   - 过去 3-5 年平均增长率
   - 适用场景：无明确指引时

**假设原则：**
- 近期（1-3年）：基于公司指引或分析师预期
- 远期（4-5年）：基于历史趋势和行业增长

### FCF 利润率假设

**计算方法：**

```
FCF 利润率 = 自由现金流 / 营收 × 100%
```

**历史参考：**

| 时间区间 | 用途 |
|----------|------|
| 过去 3 年平均 | 近期盈利能力 |
| 过去 5 年平均 | 长期盈利能力趋势 |
| 行业平均 | 横向对比基准 |

**假设原则：**
- 如果有利润率改善计划：可适当高于历史平均
- 如果面临竞争压力：应保守假设
- **[ASSUMPTION]**：偏离历史需解释原因

## WACC（加权平均资本成本）

### WACC 公式

```
WACC = (E/V) × Re + (D/V) × Rd × (1 - t)
```

其中：
- `E` = 权益市值
- `D` = 债务市值
- `V` = 企业价值 (E + D)
- `Re` = 股权成本
- `Rd` = 债务成本
- `t` = 有效税率

### 股权成本 (Re) - CAPM 模型

```
Re = Rf + β × ERP
```

#### 无风险利率 (Rf)

**标准选择：10年期美国国债收益率**

| 数据源 | 可获取性 | 更新频率 |
|--------|----------|----------|
| 美联储 (FRED) | 免费 | 每日 |
| Yahoo Finance | 免费 | 每日 |
| Bloomberg | 付费 | 实时 |

**典型范围：** 3% - 5%（随宏观环境变化）

#### Beta (β)

**定义：** 衡量股票相对市场的波动性

| Beta 值 | 含义 | 典型公司 |
|---------|------|----------|
| < 0.8 | 防御性 | 公用事业、消费必需品 |
| 0.8 - 1.2 | 平均 | 大部分公司 |
| > 1.2 | 周期性/成长 | 科技、生物科技 |

**数据来源：**
- Bloomberg、Yahoo Finance
- 计算方法：通常使用 2-5 年周数据回归

#### 股权风险溢价 (ERP)

**定义：** 投资者要求的超过无风险利率的额外回报

**权威来源：**

| 来源 | ERP 建议 | 更新频率 |
|------|----------|----------|
| Damodaran (NYU) | 4.5% - 5.5% | 年度更新 |
| Morningstar | 5.0% | 季度更新 |
| 历史平均 (1928-) | 约 5.5% | 长期数据 |

**典型假设：** 5% - 6%

### 债务成本 (Rd)

**计算方法：**

```
税后债务成本 = 债务收益率 × (1 - 税率)
```

**债务收益率获取：**

| 方法 | 适用场景 |
|------|----------|
| 公司债券收益率 | 有公开交易债券 |
| 信用利差 + 无风险利率 | 无公开债券，估算信用评级 |
| 银行贷款利率 | 主要债务为银行贷款 |

**典型范围：** 4% - 8%（取决于信用评级）

## 敏感性分析

### 目的

DCF 结果对关键假设高度敏感。敏感性分析展示假设变化对估值的影响。

### 敏感性矩阵

| WACC \ g | 2.0% | 2.5% | 3.0% |
|----------|------|------|------|
| 8% | $XXX | $XXX | $XXX |
| 10% | $XXX | $XXX | $XXX |
| 12% | $XXX | $XXX | $XXX |

### 关键发现

1. **WACC 影响最大**：WACC 变化 1% 可导致估值变化 10-20%
2. **永续增长率影响中等**：g 变化 0.5% 导致估值变化 5-10%
3. **早期增长率最关键**：第 1-3 年假设对现值影响最大

## DCF 最佳实践

### 假设设定原则

1. **保守性原则**
   - 宁可保守，不过度乐观
   - 对高增长公司尤其重要

2. **数据驱动**
   - 每个假设都要有数据来源
   - 不使用"凭感觉"的数字

3. **一致性**
   - 增长假设应与公司指引一致
   - 利润率假设应与历史趋势相符

4. **透明性**
   - 明确标注 [ASSUMPTION]
   - 解释每个假设的选择理由

### 常见错误

| 错误 | 后果 | 避免 |
|------|------|------|
| 过度乐观的增长率 | 估值虚高 | 使用保守假设，参考历史 |
| 过低的 WACC | 估值虚高 | 使用标准 CAPM 计算 |
| 过高的永续增长率 | 不现实 | 限制在 2-3% |
| 忽略敏感性分析 | 假设风险不明确 | 始终提供敏感性表 |

### 适用公司类型

| 适用 | 不适用 |
|------|--------|
| 产生稳定现金流的成熟公司 | 高增长初创公司 |
| 可预测的防御性行业 | 高度周期性行业 |
| 正现金流的盈利公司 | 持续亏损公司 |
| 资本密集型行业（现金流可预测） | 轻资产高波动行业 |

## DCF 与其他方法结合

### 多方法验证

| 估值方法 | 适用场景 | 权重建议 |
|----------|----------|----------|
| DCF | 现金流稳定的公司 | 40-50% |
| 可比公司倍数 | 有可比同行时 | 30-40% |
| 分析师目标价 | 成熟跟踪公司 | 10-20% |

### 方法冲突时

1. **检查假设**：重新审视 DCF 假设是否合理
2. **理解差异**：倍数法反映市场情绪，DCF 反映内在价值
3. **权重判断**：哪种方法更适合目标公司
