# 牛熊情景提示指南

## 核心目标

不预测股价涨跌，而是推演未来3-5年的不同基本面情景，帮助用户理解投资逻辑和风险暴露。

## 分析三问

### 1. 这家公司长期靠什么赚钱？

**判断维度**:

| 盈利驱动 | 典型公司 | 估值适用 |
|----------|----------|----------|
| 销量增长驱动 | 贵州茅台、海天味业 | PE估值 |
| 成本优化驱动 | 福耀玻璃、格力电器 | PE估值 |
| 技术壁垒驱动 | 恒立液压、恒生电子 | PE+PB估值 |
| 政策红利驱动 | 东风汽车、三一重工 | PE估值 |
| 渠道扩张驱动 | 爱尔眼科、爱尔眼科 | PS估值 |

**关键问题**:
- 公司的核心盈利能力是什么？
- 这种能力的持续性如何？
- 是否容易被新技术颠覆？

### 2. 未来3-5年行业环境如何？

**判断维度**:
- 市场需求是扩张还是收缩？
- 行业是在成长期还是成熟期？
- 竞争格局会改善还是恶化？
- 技术变革是利好还是利空？

**数据来源**:
- 行业研报（券商、咨询机构）
- 行业政策文件
- 上市公司年报行业展望
- 新闻追踪

### 3. 公司自身能改善哪些基本面？

**改善维度**:
- 利润率（毛利率、净利率）
- 成本控制能力
- 资本使用效率（ROIC）
- 债务结构优化
- 客户结构优化
- 产品结构优化

## 情景构建框架

### 情景类型

| 情景类型 | 描述 | 基本面假设 |
|----------|------|----------|
| **牛市情景** | 行业高景气+公司超预期 | 需求旺盛，供不应求，价格战放缓 |
| **中性情景** | 行业平稳+公司符合预期 | 需求稳定，格局平衡，价格适中 |
| **熊市情景** | 行业景气下滑+公司低于预期 | 需求萎缩，供过于求，价格战加剧 |

### 三种情景输出模板

#### 模板1：行业高景气牛市

```
### 🐂 牛市情景（未来3-5年）

**情景假设**:
- 行业需求持续旺盛，年均增速15%+
- 供需关系偏紧，价格战放缓
- 公司市场份额持续提升，定价权增强

**基本面预测**:
- 营收增速: 2026-2028年预计12%-18%/年
- 毛利率: 从当前25%提升至30%+
- 净利率: 从当前8%提升至12%+
- ROE: 从当前15%提升至20%+
- 资产负债率: 保持在50%以下
- 市场份额: 从当前25%提升至35%+

**驱动因素**:
- ✅ 行业进入成长期，需求爆发
- ✅ 产能扩张顺利，产能利用率提升
- ✅ 竞争格局优化，主要对手增速放缓
- ✅ 成本控制良好，规模效应显现
- ✅ 新兴业务（机器人/液冷）进入放量期
- ✅ 估值水平: PE从25倍提升至30-35倍合理区间

**风险提示**:
- ⚠️ 行业增速不及预期
- ⚠️ 新进入者打破现有格局
- ⚠️ 技术路线错误，产能扩张错配
- ⚠️ 估值泡沫（PE>40倍）
- ⚠️ 原材料价格大幅上涨

**投资逻辑**:
- 长期持有，分享行业成长红利
- 定期加仓，关注业绩兑现
- 行业景气期坚持持有，不因短期波动下车
```

#### 模板2：行业平稳中性

```
### 🐻 中性情景（未来3-5年）

**情景假设**:
- 行业需求平稳，年均增速5%-10%
- 供需关系平衡，价格适中
- 公司业绩符合市场预期

**基本面预测**:
- 营收增速: 2026-2028年预计8%-12%/年
- 毛利率: 维持在当前25%-28%区间
- 净利率: 维持在当前8%-10%区间
- ROE: 维持在当前15%-18%区间
- 资产负债率: 保持在40%-60%合理区间
- 市场份额: 维持在当前25%-30%

**驱动因素**:
- ✅ 行业进入成熟期，增长放缓但稳定
- ✅ 平台化布局优势持续发挥
- ✅ 成本控制能力强，效率持续改善
- ✅ 新兴业务稳步推进，贡献度提升
- ✅ 现金牛业务提供稳定现金流
- ✅ 估值水平: PE维持在20-30倍合理区间

**风险提示**:
- ⚠️ 行业需求超预期下滑
- ⚠️ 竞争加剧，价格战重演
- ⚠️ 原材料价格大幅波动
- ⚠️ 新兴业务推进不及预期
- ⚠️ 客户流失风险
- ⚠️ 估值中枢下移（PE<20倍）

**投资逻辑**:
- 行业稳健期持有优质龙头
- 关注性价比，逢低布局
- 分散投资，降低单一公司风险
- 新兴业务兑现期高赔率，择机参与
```

#### 模板3：行业低迷熊市

```
### 🐻 熊市情景（未来3-5年）

**情景假设**:
- 行业需求萎缩，年均增速0-5%或负增长
- 供需关系恶化，供过于求，价格战激烈
- 公司市场份额下滑，定价权丧失

**基本面预测**:
- 营收增速: 2026-2028年预计-5%至5%/年或负增长
- 毛利率: 从当前25%下降至15%-20%
- 净利率: 从当前8%下降至3%-6%
- ROE: 从当前15%下降至8%-12%
- 资产负债率: 可能上升至65%以上（现金流吃紧）
- 市场份额: 从当前25%下降至15%-20%

**驱动因素**:
- ❌ 行业进入衰退期，需求结构性下滑
- ❌ 技术颠覆，传统产品被淘汰
- ❌ 产能过剩，行业出清困难
- ❌ 价格战持续，利润率持续被压
- ❌ 新兴业务推进受挫，商业化困难
- ❌ 大客户流失，订单量下滑
- ❌ 估值中枢下移，市场情绪悲观

**风险提示**:
- 🔴 行业需求持续萎缩，可能长期低迷
- 🔴 技术颠覆风险，传统业务可能被淘汰
- 🔴 价格战持续，盈利空间被持续压缩
- 🔴 现金流吃紧，财务风险上升
- 🔴 产能过剩导致巨额减值风险
- 🔴 市场份额持续丢失，竞争地位恶化
- 🔴 估值中枢下移（PE<15倍或PB<1）
- 🔴 分红能力下降，甚至可能暂停

**投资逻辑**:
- 谨慎参与，等待行业出清信号
- 优质龙头可关注，等待拐点
- 短期回避高风险公司，等待行业景气度恢复
- 如有持仓，考虑减仓或清仓止损
- 保留现金，等待更好的投资机会
```

## 情景选择原则

### 选择判断标准

| 判断维度 | 牛市概率 | 中性概率 | 熊市概率 |
|----------|----------|----------|
| 行业需求 | 高增长>15% | 稳定5-15% | 低增长或负<5% |
| 行业周期 | 成长期 | 成熟期 | 衰退期 |
| 供需关系 | 供不应求 | 基本平衡 | 供过于求 |
| 竞争格局 | 优化集中 | 格局稳定 | 恶化分散 |
| 公司地位 | 提升 | 保持 | 下滑 |
| 技术变革 | 利好公司 | 中性 | 利空公司 |
| 客户结构 | 优化 | 稳定 | 恶化 |
| 产品结构 | 优化 | 稳定 | 恶化 |

### 评分方法

- 计算各维度得分（牛市=3分，中性=2分，熊市=1分）
- 综合得分 = 所有维度得分之和
- 概率判断：得分21-30为牛市，得分11-20为中性，得分0-10为熊市

### 概率表述

| 综合得分 | 概率判断 | 表述 |
|----------|----------|----------|
| 21-30分 | 🐂 牛市概率高（60%-80%） | 行业高景气，需求旺盛 |
| 11-20分 | 🐻 中性概率高（60%-80%） | 行业平稳，符合预期 |
| 0-10分 | 🐻 熊市概率高（60%-80%） | 行业低迷，需求萎缩 |

| 得分30+ | 🐂 牛市概率极高（>80%） | 强烈看多 |
| 得分15-19 | 🐻 中性概率高（60%） | 中性偏好 |
| 得分10-14 | 🐻 熊市概率高（60%） | 谨慎看空 |
| 得分0-9 | 🐻 熊市概率极高（>80%） | 强烈看空 |

| 纺织服装 | 外需减弱、库存积压、品牌竞争 | 需求萎缩，去库存艰难 |

## 输出要求

对于每种情景，输出：

1. **情景标题**：🐂 牛市/🐻 中性/🐻 熊市
2. **情景假设**：行业需求、竞争格局、公司地位
3. **基本面预测**：营收、利润率、ROE、估值中枢
4. **驱动因素**：列出关键驱动因素（✅正面、❌负面）
5. **风险提示**：列出3-5个关键风险
6. **投资逻辑**：牛市/中性/熊市分别给出建议
