# 股息可持续性评估

## 评估框架

### 核心原则

**可持续性 = 公司长期支付股息的能力**

评估维度：
1. 盈利能力（净利润）
2. 现金流（自由现金流）
3. 财务健康（债务水平）
4. 增长潜力（业务前景）
5. 管理层承诺（股息政策）

---

## 盈利能力评估

### 派息率分析

#### 健康派息率范围

| 派息率 | 可持续性 | 说明 |
|--------|---------|------|
| 0-30% | 非常高 | 充足增长空间 |
| 30-50% | 高 | 健康平衡 |
| 50-70% | 中等 | 需关注增长 |
| 70-75% | 中低 | 接近危险区 |
| > 75% | 低 | 不可持续风险 |

#### 警示信号

**红色警示：**
- 派息率 > 90%（立即危险）
- 派息率连续 3 年上升 > 70%
- 派息率 > 100%（在消耗现金储备）

**黄色警示：**
- 派息率 75-90%（需密切监控）
- 派息率波动大
- 派息率趋势上升

#### 行业调整

**公用事业：**
- 可承受更高派息率（60-80%）
- 原因：收入稳定，增长缓慢

**REITs：**
- 高派息率（80-90%）
- 法定要求：90% 收益分配
- 注意：可分配现金流是关键

**科技股：**
- 低派息率（0-30%）
- 高成长，需要再投资

---

### 盈利质量

#### 盈利稳定性

```
盈利质量评估：

1. 过去 5 年盈利变化：
   - 稳定增长：优秀
   - 波动大：中等
   - 大幅波动：差

2. 盈利来源：
   - 核心业务：优秀
   - 一次性收益：差

3. 盈利增长：
   - 持续增长：优秀
   - 增长放缓：中等
   - 增长停滞：差
```

#### 盈利增长趋势

**理想趋势：**
- 盈利增长 ≥ 股息增长
- 派息率稳定或下降

**危险趋势：**
- 盈利增长 < 股息增长
- 派息率持续上升

**示例分析：**
```
公司 A（健康）：
年份 | 盈利 | 股息 | 派息率
2020 | $100 | $50 | 50%
2021 | $110 | $55 | 50%
2022 | $120 | $60 | 50%
2023 | $130 | $65 | 50%
评价：派息率稳定，可持续

公司 B（危险）：
年份 | 盈利 | 股息 | 派息率
2020 | $100 | $50 | 50%
2021 | $105 | $55 | 52%
2022 | $108 | $60 | 56%
2023 | $110 | $65 | 59%
评价：派息率上升，风险增加
```

## 现金流评估

### 自由现金流覆盖率

#### 健康覆盖率范围

| 覆盖率 | 可持续性 | 说明 |
|--------|---------|------|
| > 2.0 | 非常高 | 充足缓冲 |
| 1.5-2.0 | 高 | 健康 |
| 1.2-1.5 | 中等 | 基本足够 |
| 1.0-1.2 | 低 | 紧张 |
| < 1.0 | 非常低 | 不足覆盖 |

#### 自由现金流 vs 净利润

**为什么自由现金流更重要？**

```
净利润 vs 自由现金流差异：

公司 A（利润质量高）：
净利润：$100
折旧摊销：$20
资本支出：$15
自由现金流：$100 + $20 - $15 = $105
评价：自由现金流 > 净利润，质量高

公司 B（利润质量低）：
净利润：$100
折旧摊销：$10
资本支出：$50
自由现金流：$100 + $10 - $50 = $60
评价：自由现金流 < 净利润，质量低
```

#### 现金流派息率分析

**健康标准：**
- < 60%：非常安全
- 60-75%：安全
- 75-90%：需关注
- > 90%：危险

**优先级：**
- 自由现金流派息率 > 净利润派息率
- 自由现金流是实际分红能力

## 财务健康评估

### 债务水平

#### 债务/EBITDA

| 债务/EBITDA | 风险等级 | 股息安全 |
|------------|---------|---------|
| < 2.0 | 低风险 | 非常安全 |
| 2.0-3.0 | 低风险 | 安全 |
| 3.0-4.0 | 中等风险 | 需关注 |
| 4.0-5.0 | 高风险 | 危险 |
| > 5.0 | 极高风险 | 不安全 |

#### 债务趋势

**关注点：**
- 债务是否持续上升
- 债务上升是否影响分红
- 债务用途（投资 vs 消耗）

**危险信号：**
- 债务/EBITDA > 4.0 且持续上升
- 同时派息率 > 70%
- 利息保障倍数 < 2.0

---

### 利息保障倍数

#### 健康范围

| 利息保障倍数 | 股息安全 | 说明 |
|-------------|---------|------|
| > 6.0 | 非常安全 | 轻松覆盖利息和股息 |
| 4.0-6.0 | 安全 | 覆盖充分 |
| 2.0-4.0 | 基本安全 | 压力适中 |
| 1.5-2.0 | 危险 | 压力大 |
| < 1.5 | 非常危险 | 可能削减股息 |

#### 债权人优先权

**重要原则：**
- 债权人优先于股东
- 利息必须先支付
- 股息可被削减保利息

**分析框架：**
```
现金流分配顺序：
1. 利息支出（必须支付）
2. 股息支付（可调整）
3. 再投资（可调整）

如果利息保障倍数低：
- 优先保利息
- 股息可能被削减
```

## 增长潜力评估

### 业务前景

#### 行业生命周期

**成长期：**
- 特点：高增长，需求扩张
- 股息：通常低或不分红
- 评估：关注增长潜力，而非股息

**成熟期：**
- 特点：增长放缓，需求稳定
- 股息：稳定分红
- 评估：股息可持续性高

**衰退期：**
- 特点：需求下降，利润减少
- 股息：可能削减
- 评估：高风险

#### 竞争优势

**护城河强度：**
- 强护城河：可口可乐、强生
  - 股息安全，可持续
- 中等护城河：银行、保险
  - 需关注行业趋势
- 弱护城河：零售、航空
  - 高风险

---

### 股息增长潜力

#### 可持续增长率

**计算公式：**
```
可持续增长率 = ROE × (1 - 派息率)

其中：
ROE = 净资产收益率
```

**示例：**
```
公司 A：
ROE = 15%
派息率 = 50%
可持续增长率 = 15% × (1 - 50%) = 7.5%

公司 B：
ROE = 10%
派息率 = 70%
可持续增长率 = 10% × (1 - 70%) = 3.0%

结论：公司 A 更有能力持续增长股息
```

#### 股息增长率评估

| 增长率 | 可持续性 | 说明 |
|--------|---------|------|
| > 15% | 低 | 难以长期维持 |
| 10-15% | 中 | 需强劲业务支撑 |
| 5-10% | 高 | 健康可持续 |
| 0-5% | 非常高 | 非常保守 |

## 管理层承诺评估

### 股息政策

#### 政策明确性

**优秀政策：**
- 明确的派息率目标（如：40-60%）
- 股息增长与盈利增长挂钩
- 公开承诺长期分红

**模糊政策：**
- 无明确目标
- "视情况而定"
- 历史不一致

#### 历史兑现情况

**评估标准：**
- 是否兑现过去承诺
- 危机时期如何处理股息
- 是否有过削减历史

**示例：**
```
公司 A（优秀）：
承诺：股息增长率至少等于盈利增长率
兑现：过去 10 年，股息增长 8%，盈利增长 8%
评级：优秀

公司 B（差）：
承诺：维持股息增长
历史：2008 年削减股息 50%
评级：差
```

## 风险预警系统

### 红色警示（立即危险）

**立即行动：**
- 派息率 > 90%
- 自由现金流 < 股息
- 债务/EBITDA > 5.0
- 利息保障倍数 < 1.5
- 盈利下降 > 30%

**建议：**
- 立即减少或卖出
- 股息削减风险极高

---

### 黄色警示（需密切监控）

**监控指标：**
- 派息率 75-90%
- 自由现金流覆盖率 1.0-1.2
- 债务/EBITDA 4.0-5.0
- 利息保障倍数 1.5-2.0
- 派息率持续上升

**建议：**
- 密切监控财务状况
- 关注季度财报
- 准备应对股息削减

---

### 绿色信号（健康）

**健康指标：**
- 派息率 < 70%
- 自由现金流覆盖率 > 1.5
- 债务/EBITDA < 3.0
- 利息保障倍数 > 4.0
- 派息率稳定或下降

**建议：**
- 继续持有
- 享受股息收入
- 定期评估

## 股息削减预测模型

### 削减概率评估

#### 高概率（> 70%）

**条件（满足 2+）：**
- 派息率 > 90%
- 自由现金流 < 股息
- 债务/EBITDA > 5.0
- 利息保障倍数 < 1.5
- 盈利下降 > 30%

#### 中等概率（30-70%）

**条件（满足 2+）：**
- 派息率 75-90%
- 自由现金流覆盖率 < 1.2
- 债务/EBITDA 4.0-5.0
- 利息保障倍数 1.5-2.0
- 派息率持续上升

#### 低概率（< 30%）

**条件（满足 3+）：**
- 派息率 < 70%
- 自由现金流覆盖率 > 1.5
- 债务/EBITDA < 3.0
- 利息保障倍数 > 4.0
- 连续增长 10 年以上

## 历史案例分析

### 案例 1：通用电气（GE）

**股息削减历史：**
- 2008 年：削减 68%（金融危机）
- 2017 年：削减 50%（业务重组）
- 2018 年：完全暂停股息

**预警信号（回顾）：**
- 派息率持续上升（2000-2008）
- 自由现金流恶化
- 债务水平上升
- 业务转型失败

**教训：**
- 关注派息率趋势
- 自由现金流是关键
- 业务重组期间风险高

---

### 案例 2：AT&T（T）

**股息削减历史：**
- 2022 年：削减 50%（媒体业务出售）

**预警信号：**
- 派息率长期 > 70%
- 自由现金流覆盖率 < 1.0
- 债务/EBITDA > 4.0
- 业务转型风险

**教训：**
- 高债务 + 高派息率 = 危险
- 业务转型期间谨慎
- 自由现金流不足是致命伤

---

### 案例 3：麦当劳（MCD）

**优秀历史：**
- 连续增长 46 年（截至 2024）
- 派息率稳定（50-70%）
- 自由现金流充足
- 股息增长稳健

**成功因素：**
- 强品牌护城河
- 稳定现金流
- 合理派息率
- 健康财务

**启示：**
- 护城河重要性
- 稳定胜于增长
- 财务健康第一

## 常见错误

### 错误 1：只看股息率

**错误：**
- 高股息率 = 优质股息股

**正确：**
- 股息率 + 可持续性 = 真正价值
- 高股息率可能 = 价值陷阱

---

### 错误 2：忽略自由现金流

**错误：**
- 只看净利润派息率

**正确：**
- 自由现金流更重要
- 自由现金流 < 净利润 = 警示

---

### 错误 3：忽视债务

**错误：**
- 高派息率 + 高债务 = 可持续

**正确：**
- 高债务 + 高派息率 = 危险
- 优先偿还债务，后分红

---

### 错误 4：假设过去 = 未来

**错误：**
- 连续增长 20 年 = 永远增长

**正确：**
- 环境可能变化
- 定期评估可持续性
