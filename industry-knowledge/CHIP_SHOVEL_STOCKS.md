# 芯片产业链铲子股图谱

## 📊 产业链全景

```
上游：基础支撑（技术壁垒最高）
    ↓
EDA/IP → 材料 → 设备
    ↓
中游：核心制造（资本+技术密集）
    ↓
设计 → 制造 → 封测
    ↓
下游：应用场景
    ↓
消费电子 → 汽车 → 工业/通信
```

## 💰 铲子股核心逻辑总结

### 铲子股的三个特征

1. **上游位置**：处于产业链上游，为下游提供基础产品/服务
2. **技术壁垒**：技术难度高，竞争对手少
3. **卖铲子思维**：谁在挖金矿（下游应用爆发），就卖铲子给谁

### 芯片产业链铲子股优先级

**第一梯队（技术壁垒最高，国产化替代最迫切）：**
- EDA工具：华大九天、概伦电子
- 光刻机：上海微电子
- 刻蚀机：中微公司
- 检测设备：精测电子、华峰测控

**第二梯队（技术壁垒高，市场空间大）：**
- 硅片：沪硅产业
- 光刻胶：南大光电、彤程新材
- 电子特气：华特气体
- CMP材料：安集科技

**第三梯队（技术壁垒中等，竞争激烈）：**
- 封测材料：长川科技
- 其他材料：江丰电子、鼎龙股份
