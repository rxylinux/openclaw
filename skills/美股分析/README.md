# 美股分析技能集

专业的美股投资分析工具集，提供从个股到宏观的全方位分析能力。

## 技能列表

### 1. 完整股票拆解分析 (5维度)
全面的股票分析框架，覆盖公司概况、财务数据、价格表现、华尔街共识和机构持仓。

**维度**：
- 公司概况与商业模式
- 财务数据与健康度
- 价格表现与估值
- 华尔街分析师共识
- 机构持仓与流向

### 2. 财务报表深度拆解 (6维度)
深度解析财务报表，理解公司真实财务状况。

**维度**：
- 资产负债表分析
- 利润表分析
- 现金流量表分析
- 财务比率计算
- 同比与环比趋势
- 会计质量评估

### 3. 财报解读分析器 (6维度)
专业解读财报季报，提炼关键信息。

**维度**：
- 营收与EPS分析
- 指引更新与展望
- 管理层讨论与分析
- 电话会议要点
- 与预期对比
- 股价反应分析

### 4. 行业与板块对比分析 (4维度)
在行业背景下评估公司竞争力。

**维度**：
- 行业概况与趋势
- 同业公司对比
- 市场份额与定位
- 估值与成长性对比

### 5. 估值模型构建器 (5维度)
专业估值模型构建，判断合理股价区间。

**维度**：
- 现金流折现模型（DCF）
- 相对估值法
- 资产基础法
- 敏感性分析
- 综合估值判断

### 6. 股息与被动收入分析器 (6维度)
专注于股息收入投资者的分析工具。

**维度**：
- 股息历史与稳定性
- 股息安全性分析
- 股息成长率
- 收益率与税收
- 股息贵族与挑战者
- 被动收入策略

### 7. 风险与红旗扫描器 (7维度)
基于巴菲特"不要亏钱"原则的风险分析。

**维度**：
- 财务风险
- 商业模式风险
- 估值风险
- 行业与竞争风险
- ESG与治理风险
- 关联方风险
- 技术分析风险

### 8. ETF与投资组合分析器 (7维度)
系统分析投资组合，识别风险和优化机会。

**维度**：
- 资产配置拆解
- 持仓分析
- 风险指标
- 成本分析
- 收益分析
- 压力测试
- 优化建议

### 9. 宏观与市场情绪扫描器 (7维度)
顶级投行晨会简报级别的宏观分析。

**维度**：
- 美联储与利率政策
- 通胀数据
- 经济健康状况
- 市场结构与情绪
- 板块轮动分析
- 地缘政治与重大事件
- 综合判断与策略建议

### 10. 完整尽职调查报告 (8部分)
顶级投行级别的股票首次覆盖正式报告生成工具。

**部分**：
- SECTION 1：执行摘要
- SECTION 2：业务概览
- SECTION 3：财务深度分析
- SECTION 4：增长分析
- SECTION 5：估值分析
- SECTION 6：风险分析
- SECTION 7：催化剂时间表
- SECTION 8：最终结论

## 核心特性

### 数据可信度
- 每个数据点标注来源
- 不编造历史数据
- 明确区分事实vs预测
- 数据时效性标注

### 专业分析
- 投资级分析框架
- 多维度交叉验证
- 风险阈值警示
- 量化指标支撑

### 可操作性
- 清晰表格展示
- 明确买入/持有/卖出建议
- 具体ETF代码推荐
- 权重配置建议

## 使用场景

### 个股投资
1. 使用"完整股票拆解分析"进行初步筛选
2. 使用"财务报表深度拆解"了解财务状况
3. 使用"财报解读分析器"分析最新财报
4. 使用"行业与板块对比分析"了解竞争格局
5. 使用"估值模型构建器"判断合理价位
6. 使用"风险与红旗扫描器"识别潜在风险

### 股息投资
1. 使用"股息与被动收入分析器"筛选股息股
2. 结合"风险与红旗扫描器"确保安全性
3. 使用"财报解读分析器"跟踪股息支付能力

### 组合管理
1. 使用"ETF与投资组合分析器"分析当前组合
2. 使用"宏观与市场情绪扫描器"判断市场环境
3. 根据宏观环境调整配置策略

### 完整尽职调查
使用"完整尽职调查报告"生成专业级投资研究报告：
- 首次覆盖报告
- 投资决策支持
- 尽职调查文档
- 投资者教育材料
