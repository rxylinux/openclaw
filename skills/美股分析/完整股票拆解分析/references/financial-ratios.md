# 美股财务比率参考

## 概述

本文档提供美股分析中常用的财务比率计算方法和解读标准。

## 估值指标

### 市盈率 (P/E Ratio)

**计算公式**：
```
P/E = 股价 / 每股收益 (EPS)
```

**解读标准**：
| P/E值 | 估值水平 | 说明 |
|-------|---------|------|
| <15 | 低估 | 可能被低估，或公司增长缓慢 |
| 15-25 | 合理 | 正常估值区间 |
| 25-40 | 偏高 | 可能高估，或高增长公司 |
| >40 | 高估 | 可能存在泡沫 |

**注意事项**：
- 亏损公司无P/E比率
- 周期性公司P/E在行业顶峰时可能低（利润高峰），谷底时可能高（利润低谷）
- 高增长公司通常有较高P/E

### 预期市盈率 (Forward P/E)

**计算公式**：
```
Forward P/E = 股价 / 预期每股收益
```

**解读**：
- 使用未来预期收益计算
- 更能反映公司未来估值
- 预期可能不准确，需关注预期调整趋势

### 市销率 (P/S Ratio)

**计算公式**：
```
P/S = 市值 / 营收
或
P/S = 股价 / 每股营收
```

**解读标准**：
| P/S值 | 估值水平 | 说明 |
|-------|---------|------|
| <1 | 低估 | 低于年营收，可能被低估 |
| 1-3 | 合理 | 正常估值区间 |
| 3-5 | 偏高 | 高增长公司常见 |
| >5 | 高估 | 可能存在泡沫 |

**适用场景**：
- 亏损公司（无P/E）
- 高增长科技公司
- 初创企业

### PEG比率

**计算公式**：
```
PEG = P/E / 预期增长率
```

**解读标准**：
| PEG值 | 估值水平 | 说明 |
|-------|---------|------|
| <1 | 低估 | 增长未被充分定价 |
| 1-2 | 合理 | 增长与估值匹配 |
| >2 | 高估 | 估值高于增长率 |

**注意事项**：
- 适用于高增长公司
- 增长率预测可能不准确
- 需考虑增长可持续性

## 盈利能力指标

### 净利润率 (Net Profit Margin)

**计算公式**：
```
净利润率 = 净利润 / 营收 × 100%
```

**解读标准**：
| 净利润率 | 盈利能力 | 典型行业 |
|---------|---------|----------|
| >20% | 优秀 | 软件SaaS、奢侈品 |
| 10-20% | 良好 | 消费品、医疗 |
| 5-10% | 一般 | 零售、制造 |
| <5% | 较低 | 超市、航空 |

### 毛利率 (Gross Margin)

**计算公式**：
```
毛利率 = (营收 - 营业成本) / 营收 × 100%
```

**解读标准**：
| 毛利率 | 盈利能力 | 说明 |
|-------|---------|------|
| >60% | 极强 | 软件SaaS、芯片设计 |
| 40-60% | 强 | 品牌消费、医疗 |
| 20-40% | 一般 | 制造业、零售 |
| <20% | 弱 | 硬件制造、超市 |

### ROE (Return on Equity)

**计算公式**：
```
ROE = 净利润 / 股东权益 × 100%
```

**解读标准**：
| ROE | 盈利能力 | 说明 |
|-----|---------|------|
| >20% | 优秀 | 资本利用效率极高 |
| 15-20% | 良好 | 资本利用效率高 |
| 10-15% | 一般 | 资本利用效率正常 |
| <10% | 较低 | 资本利用效率低 |

**杜邦分析**：
```
ROE = 净利润率 × 资产周转率 × 权益乘数
```

## 财务健康指标

### 资产负债率 (Debt-to-Equity)

**计算公式**：
```
资产负债率 = 总债务 / 股东权益 × 100%
```

**解读标准**：
| 资产负债率 | 财务风险 | 说明 |
|-----------|---------|------|
| <50% | 低风险 | 债务水平健康 |
| 50-100% | 中等风险 | 债务水平适中 |
| 100-200% | 较高风险 | 债务水平较高 |
| >200% | 高风险 | 债务水平过高 |

**特殊情况**：
- 金融公司（银行、保险）资产负债率通常很高
- 需要结合行业特点分析

### 流动比率 (Current Ratio)

**计算公式**：
```
流动比率 = 流动资产 / 流动负债
```

**解读标准**：
| 流动比率 | 偿债能力 | 说明 |
|---------|---------|------|
| >2.0 | 强 | 短期偿债能力强 |
| 1.5-2.0 | 良好 | 短期偿债能力良好 |
| 1.0-1.5 | 一般 | 短期偿债能力一般 |
| <1.0 | 弱 | 短期偿债困难 |

### 自由现金流 (Free Cash Flow)

**计算公式**：
```
自由现金流 = 经营现金流 - 资本开支
```

**解读**：
- 正值：公司有现金可用于分红、回购、还债、投资
- 负值：公司在大量投资，或经营现金流不足

**分析要点**：
- TTM自由现金流与净利润的比值
  - >1.2：现金含金量高
  - 0.8-1.2：正常
  - <0.8：利润质量差

## 增长指标

### 营收增长率 (Revenue Growth)

**计算公式**：
```
营收增长率 = (本期营收 - 上期营收) / 上期营收 × 100%
```

**解读标准**：
| 营收增长率 | 增长水平 | 说明 |
|-----------|---------|------|
| >30% | 高增长 | 成长型公司 |
| 15-30% | 良好增长 | 健康增长 |
| 5-15% | 稳定增长 | 成熟公司 |
| 0-5% | 低增长 | 增长放缓 |
| <0% | 负增长 | 业务萎缩 |

### 净利润增长率 (Net Income Growth)

**计算公式**：
```
净利润增长率 = (本期净利润 - 上期净利润) / 上期净利润 × 100%
```

**解读**：
- 需结合营收增长率分析
- 营收增长 + 利润增长更快：规模效应，利润率提升
- 营收增长 + 利润增长更慢：价格战、成本上升

## 股票回报指标

### 每股收益 (EPS)

**计算公式**：
```
EPS = 净利润 / 加权平均股数
```

**类型**：
- Basic EPS：基于实际股数
- Diluted EPS：考虑所有可转换证券稀释

### 股息收益率 (Dividend Yield)

**计算公式**：
```
股息收益率 = 年度股息 / 股价 × 100%
```

**解读标准**：
| 股息收益率 | 水平 | 说明 |
|-----------|------|------|
| >5% | 高 | 成熟价值股，可能增长缓慢 |
| 3-5% | 中等 | 平衡分红与增长 |
| 1-3% | 较低 | 以增长为主 |
| 0% | 无 | 不分红，再投资 |

### 股息支付率 (Payout Ratio)

**计算公式**：
```
股息支付率 = 年度股息 / 净利润 × 100%
```

**解读标准**：
| 支付率 | 可持续性 | 说明 |
|-------|---------|------|
| <50% | 可持续 | 分红安全，有增长空间 |
| 50-70% | 需关注 | 分红较高，需关注利润稳定性 |
| 70-100% | 风险较高 | 分红可能难持续 |
| >100% | 不可持续 | 分红超过利润，借钱分红 |

## 数据来源

### 美股财务数据源

1. **Yahoo Finance**：免费，覆盖全面
2. **SEC EDGAR**：官方财报，最权威
3. **Morningstar**：专业财务比率
4. **Finviz**：财务筛选器
5. **Macrotrends**：长期财务数据

### 数据时效性

- 季报：每季度更新，滞后45天
- 年报：每年更新，滞后60天
- 股价：实时（交易时间）
- 估值指标：随股价变动

## 注意事项

1. **行业对比**：不同行业标准不同，需同行业对比
2. **趋势分析**：关注3-5年趋势，而非单点数据
3. **数据质量**：优先使用审计后的财报数据
4. **特殊情况**：关注重组、并购等一次性事件影响
