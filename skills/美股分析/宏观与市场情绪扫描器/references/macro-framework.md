# 宏观分析框架

## 概述

宏观与市场情绪扫描采用**7维度方法**，系统评估宏观环境。

## 7个分析维度

### 第1步：美联储与利率政策
- 联邦基金利率区间
- FOMC会议日期
- 市场定价的降息概率（CME FedWatch）
- 关键官员言论
- 实际利率水平

### 第2步：通胀数据
- 整体CPI与核心CPI
- 整体PCE与核心PCE
- 通胀趋势（3个月/6个月/12个月）
- 与2%目标距离

### 第3步：经济健康状况
- GDP增长率
- 就业数据（失业率、非农新增）
- 消费者信心
- 制造业/服务业PMI
- 收益率曲线倒挂
- 经济衰退概率模型

### 第4步：市场结构与情绪
- 主要指数表现（标普500、纳斯达克、道指、罗素2000）
- 市场广度（涨跌比、新高/新低）
- VIX恐慌指数
- Put/Call比率
- 资金流向

### 第5步：板块轮动分析
- 各板块表现对比（科技、金融、医疗等10个板块）
- 资金流方向
- 经济周期定位
- 超配/低配建议

### 第6步：地缘政治与重大事件
- 关键事件日历（FOMC、非农、CPI等）
- 地缘政治风险（乌克兰、中东、中美关系）
- 黑天鹅监控

### 第7步：综合判断与策略建议
- Risk-On/Risk-Off/中性状态
- 进攻性策略（适用于Risk-On）
- 防御性策略（适用于Risk-Off）
- 中性策略（适用于不确定性环境）
- 关键监控指标

## Risk-On / Risk-Off 判别标准

### Risk-On 状态（进攻性环境）
**特征**：
- VIX < 20
- 美债收益率上升（经济乐观）
- 金融、工业、小盘股领涨
- 资金流入股市ETF
- 收益率曲线陡峭化

**策略**：
- 超配成长股、科技股
- 配置小盘股（IWM、Russell 2000）
- 减少防御性资产

### Risk-Off 状态（防御性环境）
**特征**：
- VIX > 25
- 美债收益率下降（避险）
- 公用事业、消费必需品、国债领涨
- 资金流出股市ETF
- 收益率曲线倒挂或平坦

**策略**：
- 超配防御性板块（XLV、XLP、XLU）
- 增加现金和国债配置
- 考虑黄金（GLD）对冲
- 使用反向ETF对冲（SH、SDS）

### 中性状态
**特征**：
- VIX 15-25
- 市场缺乏明确方向
- 数据好坏参半
- 重大事件前观望

**策略**：
- 平衡配置
- 保留灵活现金
- 等待明确信号

## 板块轮动与经济周期

### 经济周期阶段
1. **早期复苏**：金融、工业、消费可选
2. **中期扩张**：科技、工业
3. **晚期过热**：能源、材料
4. **衰退期**：公用事业、消费必需品、医疗

## 地缘政治风险等级

### 高风险事件
- 战争/武装冲突
- 重大制裁/贸易战
- 大选不确定性
- 系统性金融风险

### 中风险事件
- 央行政策转向
- 重大监管变化
- 地区性政治危机

### 低风险事件
- 常规政治辩论
- 非关键经济数据
- 企业层面事件

## 数据时效性要求

- **实时数据**：市场行情、VIX、资金流（需标注具体时间）
- **日数据**：指数收盘、Put/Call比率（需标注日期）
- **周数据**：ETF资金流、初请失业金（需标注周范围）
- **月数据**：CPI、非农、PMI（需标注发布日期）
- **季度数据**：GDP（需标注季度和修正阶段）
