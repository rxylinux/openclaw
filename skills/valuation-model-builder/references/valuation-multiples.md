# 估值倍数详解

## 常用估值倍数

### 1. 市盈率（P/E, Price-to-Earnings）

#### 计算公式

```
P/E = 当前股价 / 每股收益（EPS）

或

P/E = 总市值 / 净利润
```

#### EPS 选择

- **过去 12 个月（TTM）**：最近 4 个季度 EPS 之和，反映实际盈利能力
- **预期 EPS**：未来一年分析师一致预期，反映市场预期
- **当期年度 EPS**：最新年报数据，适合稳定盈利公司

#### 适用场景

**适用：**
- 盈利稳定的成熟公司
- 正常经营的盈利公司
- 可持续盈利的公司

**不适用：**
- 亏损公司
- 业绩波动大的周期性公司
- 一次性收益影响大的公司

#### 合理 P/E 范围

- **低估值**：< 10 倍（被低估或增长前景不佳）
- **正常估值**：10-25 倍（正常范围）
- **高估值**：> 25 倍（高增长预期或泡沫）

**行业差异：**
- 传统行业（银行、公用事业）：5-15 倍
- 消费行业：15-25 倍
- 科技行业：25-50+ 倍（高增长预期）

#### 优缺点

**优点：**
- 计算简单，数据易得
- 直观反映市场对公司盈利的定价

**缺点：**
- 对亏损公司无效
- 易受会计政策影响
- 不考虑未来增长（需配合 PEG 使用）

---

### 2. 市销率（P/S, Price-to-Sales）

#### 计算公式

```
P/S = 当前股价 / 每股销售额

或

P/S = 总市值 / 营业收入
```

#### 适用场景

**适用：**
- 亏损公司（如：早期科技公司）
- 高增长公司（营收增长快，但尚未盈利）
- 周期性公司（利润波动大，营收相对稳定）

**不适用：**
- 低利润率公司（P/S 无法反映盈利能力）
- 收入质量差的公司（如：大量无效营收）

#### 合理 P/S 范围

- **低估值**：< 2 倍
- **正常估值**：2-5 倍
- **高估值**：> 5 倍

**行业差异：**
- 零售行业：0.5-2 倍（低利润率）
- 科技公司：5-10+ 倍（高增长预期）
- 软件行业：8-15+ 倍（SaaS 模式）

#### 优缺点

**优点：**
- 对亏损公司有效
- 营收较难操纵，相对可靠
- 适合早期高增长公司估值

**缺点：**
- 不反映盈利能力
- 对低利润率公司误导性强
- 需配合毛利率、净利率等指标使用

---

### 3. 企业价值/息税折旧摊销前利润（EV/EBITDA）

#### 计算公式

```
企业价值（EV）= 市值 + 净债务 + 优先股 + 少数股东权益

EV/EBITDA = 企业价值 / 息税折旧摊销前利润
```

#### EBITDA 计算

```
EBITDA = 净利润 + 利息 + 税收 + 折旧 + 摊销

或

EBITDA = 营业利润 + 折旧 + 摊销
```

#### 适用场景

**适用：**
- 资本密集型行业（如：制造业、能源、公用事业）
- 负债较多的公司（去除资本结构影响）
- 跨国公司比较（折旧政策差异大）

**不适用：**
- 折旧摊销影响小的行业（如：服务业）
- 轻资产公司

#### 合理 EV/EBITDA 范围

- **低估值**：< 6 倍
- **正常估值**：6-12 倍
- **高估值**：> 12 倍

**行业差异：**
- 制造业：6-10 倍
- 能源业：4-8 倍
- 科技公司：12-20+ 倍

#### 优缺点

**优点：**
- 排除资本结构影响（利于不同公司比较）
- 排除折旧摊销政策影响
- 更接近现金流概念

**缺点：**
- 忽略资本支出（对资本密集型行业误导）
- EBITDA 不是真实现金流
- 对轻资产公司意义不大

---

### 4. 市净率（P/B, Price-to-Book）

#### 计算公式

```
P/B = 当前股价 / 每股净资产

或

P/B = 总市值 / 股东权益
```

#### 适用场景

**适用：**
- 资产密集型行业（如：银行、地产、保险、公用事业）
- 周期性底部（净资产相对稳定）
- 价值投资（寻找"安全边际"）

**不适用：**
- 轻资产公司（如：科技、服务公司）
- 负商誉公司（净资产虚高）
- 资产质量差的公司

#### 合理 P/B 范围

- **低估值**：< 1.0 倍（破净，被低估或资产质量差）
- **正常估值**：1.0-3.0 倍
- **高估值**：> 3.0 倍

**行业差异：**
- 银行业：0.5-1.2 倍
- 地产业：0.8-1.5 倍
- 科技公司：3-10+ 倍

#### 优缺点

**优点：**
- 资产账面价值相对稳定
- 适合价值投资
- 对周期性行业有帮助

**缺点：**
- 资产质量影响大（坏账、减值等）
- 对轻资产公司无效
- 账面价值可能被操纵

---

### 5. PEG 比率

#### 计算公式

```
PEG = P/E / 营收增长率

或

PEG = P/E / 净利润增长率
```

#### 适用场景

**适用：**
- 高增长公司（如：科技、成长股）
- 需要考虑增长的估值分析

**不适用：**
- 低增长或负增长公司（PEG 无意义）

#### 合理 PEG 范围

- **低估值**：< 1.0 倍（增长未被充分定价）
- **正常估值**：1.0-1.5 倍
- **高估值**：> 1.5 倍（增长预期过高）

#### 优缺点

**优点：**
- 同时考虑估值和增长
- 适合成长股分析

**缺点：**
- 增长率预测不确定
- 短期增长波动大时失真

## 可比公司选择标准

### 1. 行业相似性

**原则：**
- 同一细分行业（而非泛泛的行业分类）
- 相似的商业模式（B2B/B2C、产品/服务）
- 相似的产品或服务

**示例：**
- ✅ 可比：茅台 vs 五粮液（同为高端白酒）
- ❌ 不可比：茅台 vs 啤酒公司（虽同为酒类，但产品、客户完全不同）

### 2. 业务模式相似性

**考虑因素：**
- 收入来源（产品销售 vs 订阅服务）
- 成本结构（固定成本 vs 变动成本）
- 盈利模式（一次性收费 vs 持续性收入）
- 客户群体（个人 vs 企业）

**示例：**
- ✅ 可比：Netflix vs 爱奇艺（同为订阅制视频流媒体）
- ❌ 不可比：Netflix vs 传统电视台（商业模式不同）

### 3. 规模相近性

**原则：**
- 市值在同一数量级
- 营收规模相近
- 员工数量相近（可选）

**示例：**
- ✅ 可比：两家市值均为 100-200 亿的公司
- ❌ 不可比：100 亿 vs 1000 亿的公司（规模差异过大）

### 4. 增长阶段相似性

**原则：**
- 同一成长阶段（成长期 vs 成熟期）
- 增长率相近

**示例：**
- ✅ 可比：两家增长率均为 20-30% 的公司
- ❌ 不可比：高增长（30%+） vs 低增长（<5%）公司

### 5. 地理市场重叠

**原则：**
- 主要市场在同一地区
- 面临相似的监管环境
- 受相似宏观经济影响

**示例：**
- ✅ 可比：两家均在中国市场运营的公司
- ❌ 不可比：中国公司 vs 美国公司（市场环境差异大）

## 估值倍数使用技巧

### 1. 多倍数交叉验证

不要依赖单一倍数，使用多个倍数相互印证：

```
估值结论 = 权重1 × P/E 价值 + 权重2 × P/S 价值 + 权重3 × EV/EBITDA 价值
```

**权重分配原则：**
- 盈利稳定公司：P/E 权重高（40-50%）
- 高增长亏损公司：P/S 权重高（40-50%）
- 资本密集型公司：EV/EBITDA 权重高（40-50%）

### 2. 历史倍数对比

- 对比当前倍数 vs 5 年平均值
- 分析偏离历史区间的原因
- 判断偏离是否合理（基本面变化 vs 市场情绪）

### 3. 同业相对定位

- 相对于同行是溢价还是折价
- 溢价/折价是否有合理理由（质量、增长、风险）
- 避免简单的"贵"或"便宜"判断

### 4. 注意倍数失真

**可能导致倍数失真的因素：**
- 一次性收益或损失
- 会计政策变更
- 并购重组
- 周期性高点或低点

**处理方法：**
- 剔除一次性项目
- 使用多周期平均
- 进行情景分析

## 常见错误

### 1. 盲目对标

**错误：** 选择不恰当的可比公司

**正确：** 严格按行业、业务模式、规模、增长阶段筛选

### 2. 忽视基本面差异

**错误：** 简单认为"高于同行 = 高估"

**正确：** 分析溢价/折价的合理性（质量、增长、风险）

### 3. 只看倍数不看增长

**错误：** 用 P/E 评估高增长公司

**正确：** 使用 PEG 或其他适合高增长的倍数

### 4. 忽视历史

**错误：** 只看同行对比，不看自身历史

**正确：** 结合历史倍数判断估值位置

### 5. 倍数失真未调整

**错误：** 直接使用含有一次性影响的倍数

**正确：** 调整异常项目或使用多周期平均

## 数据来源

### 倍数数据

- **实时数据**：Bloomberg、Wind、Yahoo Finance
- **历史数据**：Choice、CSMAR、东方财富
- **同行对比**：券商研究报告、财经网站

### 可比公司筛选

- **行业分类**：Wind 行业分类、申万行业分类
- **基本面数据**：公司财报、数据库

### 历史数据

- **历史倍数**：数据库回测、券商研报
- **历史事件**：公司公告、新闻

## 计算检查清单

- [ ] 可比公司选择是否合理（行业、规模、增长）
- [ ] EPS/EBITDA 等基础数据是否正确
- [ ] 是否使用 TTM 数据（最新 4 个季度）
- [ ] 是否剔除了一次性项目
- [ ] 倍数是否与行业特征匹配
- [ ] 是否进行了历史对比
- [ ] 是否分析了溢价/折价的合理性
- [ ] 是否交叉验证了多个倍数
- [ ] 单位是否一致（全部用人民币或美元）
