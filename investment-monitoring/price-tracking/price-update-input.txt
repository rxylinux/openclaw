# 价格输入模板（方案1）

## 使用说明

每天收盘后，将每只股票的收盘价复制到下面，格式为：`股票名称 价格`

```
双环传动
美的集团
格力电器
兆威机电
拓普集团
歌尔股份
中芯国际
腾讯
NNOX
ABCL
```

## 示例

```
双环传动 12.50
美的集团 68.30
格力电器 32.10
兆威机电 45.60
拓普集团 58.70
歌尔股份 18.90
中芯国际 45.20
腾讯 380.50
NNOX 8.20
ABCL 3.50
```

## 注意

- 汇川技术、速腾聚创、巨子生物暂不监控（如有需要请添加）
- 地平线未上市，暂不监控
- 每天收盘后（15:00左右）提供最新价格即可
- 我会自动对比昨天的价格，计算涨跌幅
- 超过±5%会立即推送预警到飞书
