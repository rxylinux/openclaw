# AetherViz Master 仓库总结

## 📊 项目概况

**仓库地址：** https://github.com/andyhuo520/aetherviz-master
**项目名称：** AetherViz Master
**项目定位：** 互动教育可视化建筑师，将任意教学主题转化为沉浸式3D交互网页
**开源协议：** MIT License
**最新版本：** v5.0 (2026-02-22)
**所有者：** andyhuo520

---

## 🎯 核心价值

### 项目定位

**AetherViz Master** 是一个基于AI的互动教育可视化工具，专注于将抽象的教学概念转化为生动、直观的3D交互式网页。

### 核心能力

| 能力 | 说明 |
|-----|------|
| **一键生成** | 输入主题 → 自动生成3D交互网页 |
| **智能适配** | 自动识别学科领域，匹配最佳配色和可视化方案 |
| **零门槛使用** | 无需编程基础，生成的HTML直接可用 |
| **专业品质** | Three.js + SVG混合渲染，60fps流畅体验 |

---

## ✨ 核心特性

### 1. 3D可视化引擎

**技术基础：**
- 基于Three.js r134的专业级3D场景
- 支持物理模拟、粒子系统、矢量箭头
- 内置OrbitControls，支持鼠标拖拽旋转、滚轮缩放
- 触控设备支持：触摸旋转、双指缩放

**渲染能力：**
- 实时物理模拟
- 粒子系统特效
- 矢量箭头可视化
- 灯光和阴影效果

---

### 2. SVG增强渲染

**功能特点：**
- 可在3D场景上叠加SVG 2D图表
- 支持函数图像、坐标系、流程图
- D3.js数据驱动图表（可选）
- 3D-2D坐标实时同步

**应用场景：**
- 数学函数可视化
- 坐标系标注
- 流程图叠加
- 数据图表展示

---

### 3. 智能自动识别

**识别维度：**

| 识别维度 | 说明 |
|---------|------|
| **学科识别** | 物理/化学/生物/数学/天文/编程，自动切换配色主题 |
| **渲染方案** | 根据关键词自动选择Three.js / SVG / 混合模式 |
| **语言适配** | 自动检测中文/英文，输出对应语言 |

**智能匹配：**
- 运动关键词 → Three.js 3D模式
- 函数关键词 → SVG 2D模式
- 牛顿/波动/能量/电磁 → Three.js + SVG混合模式

---

### 4. 现代化UI设计

**设计风格：**
- 玻璃拟态（Glassmorphism）风格
- 霓虹教育风 + 彩虹强调色
- 响应式布局，适配桌面/平板/手机
- 侧边栏 + 控制面板 + HUD数据展示

**UI组件：**
- 可折叠控制面板
- 悬浮数据展示
- 参数调节滑块
- 学习目标勾选框

---

### 5. 完整教学功能

**学习支持：**
- 学习目标（可勾选追踪）
- KaTeX数学公式实时渲染
- 原理讲解（生动比喻，高中-大学水平）
- 可折叠小测验面板

**播放控制：**
- 播放/暂停
- 单步执行
- 速度控制（慢速/正常/快速）

## 🚀 快速开始

### 环境要求

- 现代浏览器（Chrome/Edge/Firefox/Safari）
- 支持WebGL

### 本地运行

**方法1：HTTP Server**
```bash
# 1. 克隆仓库
git clone https://github.com/andyhuo520/aetherviz-master.git
cd aetherviz-master

# 2. 启动本地服务器
python -m http.server 8080

# 3. 访问
# 浏览器打开 http://localhost:8080
```

**方法2：npx serve**
```bash
npx serve .
```

**方法3：PHP Server**
```bash
php -S localhost:8080
```

### 通过Claude Code使用

```bash
# 1. 启动Claude Code
claude

# 2. 输入主题
/aetherviz-master

# 或直接输入：
牛顿第二定律

# 或：
匀速运动

# 或：
光合作用

# 系统将自动生成完整的HTML文件
```
