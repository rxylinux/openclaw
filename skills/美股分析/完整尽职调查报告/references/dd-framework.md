# 尽职调查报告框架

## 概述

完整尽职调查报告采用**8部分结构**，遵循顶级投行标准，系统评估投资标的。

## 报告结构

### SECTION 1 —— 执行摘要

**目的**：让投资者在3分钟内了解核心投资逻辑

**关键要素**：
- 三句话投资逻辑
- 总体评级（Strong Buy/Buy/Hold/Sell）
- 12个月目标价及计算方法
- 最大投资亮点（3个）
- 最大风险（2个）

**评级定义**：
| 评级 | 12个月预期涨幅 | 信心度 |
|------|---------------|--------|
| Strong Buy | > 20% | 高 |
| Buy | 10-20% | 中等 |
| Hold | ±10% | 中等 |
| Sell | > -10% | 高 |

### SECTION 2 —— 业务概览

**目的**：理解公司是做什么的，如何赚钱

**关键要素**：
- 公司简介（成立时间、总部、员工数）
- 业务板块拆解（收入占比、增长率、利润率）
- 地区分布
- 商业模式（收入模式、关键驱动因素）
- 竞争壁垒（6种护城河类型）

**竞争壁垒评估**：
| 壁垒类型 | 评估要点 |
|---------|---------|
| 网络效应 | 用户越多，价值越高 |
| 转换成本 | 更换供应商的难度和成本 |
| 品牌价值 | 品牌溢价能力 |
| 规模经济 | 产量越大，成本越低 |
| 知识产权 | 专利、技术优势 |
| 监管许可 | 牌照、特许经营权 |

### SECTION 3 —— 财务深度分析

**目的**：评估公司财务健康状况

**关键要素**：
- 最近4个季度及TTM关键指标表格
- 同比增长率分析
- 资产负债表健康度
- 现金流质量（OCF/净利润比率）
- 资本配置（回购、分红、并购、研发）

**关键财务比率阈值**：
| 比率 | 健康 | 警告 | 危险 |
|------|------|------|------|
| 流动比率 | > 2.0 | 1.5-2.0 | < 1.5 |
| 速动比率 | > 1.0 | 0.8-1.0 | < 0.8 |
| 资产负债率 | < 50% | 50-70% | > 70% |
| 债务/股权 | < 1.0 | 1.0-2.0 | > 2.0 |
| 利息保障倍数 | > 5.0 | 3.0-5.0 | < 3.0 |

**现金流质量评估**：
- OCF / 净利润 > 1.0：盈利质量高
- OCF / 净利润 0.8-1.0：正常
- OCF / 净利润 < 0.8：需关注应收账款/存货

### SECTION 4 —— 增长分析

**目的**：判断未来增长可持续性

**关键要素**：
- TAM/SAM/SOM市场分层
- 当前市场份额及趋势
- 未来3-5年增长驱动因素
- 管理层指引 vs 分析师预期
- 内生增长 vs 并购增长

**市场分层定义**：
- TAM (Total Addressable Market)：总可触达市场
- SAM (Serviceable Addressable Market)：可获得市场
- SOM (Serviceable Obtainable Market)：可获得市场份额

**增长质量评估**：
| 内生增长占比 | 评估 |
|------------|------|
| > 80% | 健康 |
| 60-80% | 正常 |
| < 60% | 过度依赖并购 |

### SECTION 5 —— 估值分析

**目的**：判断股票是否被合理定价

**关键要素**：
- DCF估值（完整计算过程）
- 可比公司估值表（至少5家同行）
- 5年历史估值区间
- Bull/Base/Bear三情景目标价
- 概率加权期望值

**DCF关键参数**：
| 参数 | 典型范围 | 数据来源 |
|------|---------|---------|
| WACC | 8-12% | 根据公司风险计算 |
| 终端增长率 | 2-3% | 接近GDP增长率 |
| 预测期 | 5-10年 | 根据行业特点 |
| 永续倍数 | 15-20x | 根据行业平均 |

**相对估值倍数**：
| 倍数 | 适用场景 | 不适用场景 |
|------|---------|-----------|
| P/E | 盈利稳定公司 | 亏损公司、周期性公司 |
| EV/EBITDA | 资本密集型行业 | 轻资产公司 |
| P/S | 亏损公司、高增长公司 | 低利润率公司 |
| P/B | 金融公司、资产型公司 | 轻资产、服务型公司 |
| PEG | 高增长公司 | 低增长、周期性公司 |

### SECTION 6 —— 风险分析

**目的**：识别可能影响投资回报的风险

**关键要素**：
- 前5大实质性风险（按概率×影响排序）
- 每个风险的触发条件、潜在影响、监测指标
- 做空比例与内部人交易
- 会计质量风险

**风险评级矩阵**：
| 影响程度 / 发生概率 | 低 | 中 | 高 |
|-------------------|----|----|----|
| **高** | 中 | 高 | 极高 |
| **中** | 低 | 中 | 高 |
| **低** | 低 | 低 | 中 |

**会计质量红旗**：
- 应收账款增长 > 收入增长
- 存货周转天数增加
- 激进的收入确认
- 频繁的并购重组
- 大量非GAAP调整
- 频繁更换审计师

### SECTION 7 —— 催化剂时间表

**目的**：识别可能影响股价的未来事件

**关键要素**：
- 下一次财报日期
- 即将发布的产品/监管决定/战略事件
- 宏观催化剂
- 未来12个月关键事件日历

**催化剂重要性评级**：
| 重要性 | 股价波动预期 | 示例 |
|--------|-------------|------|
| 高 | ±5-10% | 财报、重大产品发布、监管决定 |
| 中 | ±2-5% | 投资者日、行业会议、竞争对手财报 |
| 低 | ±1-2% | 股票拆分、分红宣布、内部人交易 |

### SECTION 8 —— 最终结论

**目的**：综合所有分析，给出明确投资建议

**关键要素**：
- Bull情景（目标价、必要条件、概率）
- Base情景（目标价、最可能结果、概率）
- Bear情景（目标价、潜在风险、概率）
- 概率加权期望值计算
- 最终评级与信心等级
- 30秒电梯演讲

**概率加权期望值公式**：
```
期望目标价 = (Bull目标价 × Bull概率) + (Base目标价 × Base概率) + (Bear目标价 × Bear概率)
```

**信心等级标准**：
| 等级 | 标准 |
|------|------|
| High | 数据完整度高，催化剂明确，风险可控 |
| Medium | 数据基本完整，催化剂存在不确定性 |
| Low | 关键数据缺失，或高度不确定性 |

## 数据来源清单

### 主要数据源（必须使用）
| 数据类型 | 数据源 | 更新频率 |
|---------|--------|---------|
| 财务报表 | SEC 10-K/10-Q | 季度/年度 |
| 股价数据 | Yahoo Finance/彭博 | 实时 |
| 分析师预期 | IBES/彭博 | 实时更新 |
| 内部人交易 | SEC Form 4 | 及时 |
| 做空比例 | 交易所数据 | 每月/双周 |

### 次要数据源（补充使用）
| 数据类型 | 数据源 | 更新频率 |
|---------|--------|---------|
| 行业数据 | IDC/Gartner/Forrester | 年度/季度 |
| 竞争对手数据 | 公开披露 | 季度/年度 |
| 宏观数据 | 美联储/FRED/BLS | 月度/季度 |

## 报告撰写原则

### 数据标注规则
- 每个数据点必须标注来源
- 必须标注数据日期或期间
- 无法获取的数据写明 "Not publicly available"
- 不得估算或编造数据

### 前瞻性陈述
- 所有预测/假设必须标注 [ASSUMPTION]
- 说明假设的依据或来源
- 区分事实、预期、预测

### 结构化呈现
- 使用Markdown表格展示数据对比
- 使用要点列表列出关键信息
- 使用标题层级清晰组织内容
- 使用加粗突出关键数字

### 客观性原则
- 平衡呈现利好和风险
- 避免过度乐观或悲观
- 基于数据和事实，不凭直觉
- 承认不确定性和局限性
