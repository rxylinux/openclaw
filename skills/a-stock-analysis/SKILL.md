# A股股票分析

## 概述

本技能提供A股上市公司综合分析能力，包括：
- 股票基本信息查询（代码、名称、行业）
- 财务数据分析（营收、净利润、市盈率等）
- 最新新闻和事件追踪
- 基本面分析与投资逻辑解读
- 同行业对比分析

## 快速开始

### 单股分析
当用户询问"帮我看下拓普集团"时：

1. **获取基本信息**：使用百度搜索 `股票代码 公司 主营业务`
2. **财务数据**：搜索 `股票代码 财报 业务结构`
3. **最新新闻**：搜索 `股票代码 新闻 动态`
4. **综合分析**：整合数据生成分析报告

### 行业分析
当用户询问"半导体行业如何"时：

1. 搜索行业关键词（如"芯片半导体 最新动态"）
2. 汇总多家公司信息
3. 生成行业对比分析

## 核心能力

### 1. 股票信息查询

获取股票基本信息、主营业务、客户资源、竞争优势等。

**工具**: 百度搜索
```bash
python3 /root/.openclaw/workspace/skills/baidu-search/scripts/search.py '{
  "query": "<股票代码/名称> 股票信息 主营业务",
  "search_recency_filter": "month",
  "resource_type_filter": [{"type":"web","top_k":8}]
}'
```

### 2. 财务数据分析

查询营收、净利润、市盈率、ROE等关键财务指标，分析业绩趋势。

**搜索关键词**: `<股票代码> 财报 业绩预告 季报年报`
**搜索关键词**: `<股票代码> 市盈率 估值 机构观点`

### 3. 新闻追踪

搜索最新新闻、重大事件、机构调研、政策影响等。

**搜索关键词**: `<股票代码> 最新新闻 动态`
**搜索关键词**: `<股票代码> 机构调研 券商评级`

### 4. 行业对比分析

同一行业多家公司对比，分析产业链位置、竞争优势、市场格局。

**搜索关键词**: `<行业> 龙头 对比 市场份额`

### 5. 商业理解

用简单语言解释公司业务，让非专业人士也能理解这家公司的生意模式。

**关键问题**:
- 这家公司解决什么问题？
- 谁为此付费？
- 为什么客户选择它而不是替代品？

**输出要求**:
- 避免金融术语（如营收、毛利率、护城河等）
- 用大白话表达（如"每年卖多少"、"几年赚回本"）
- 提供具体场景和客户画像

**详细指南**: 见 [references/business-explanation.md](references/business-explanation.md)

### 6. 收入分解

分析公司的收入结构，找出增长引擎和风险点。

**核心问题**:
- 哪些部门在增长？哪些在放缓？
- 公司对顶级客户的依赖程度如何？
- 公司对顶级产品的依赖程度如何？

**输出要求**:
- 列出各业务板块收入占比和增速
- 说明前五大客户及最大客户占比
- 评估单一产品依赖风险
- 给出收入结构健康度评分（0-50分）

**详细指南**: 见 [references/revenue-breakdown.md](references/revenue-breakdown.md)

### 7. 行业背景

解释公司所在行业的环境和趋势。

**核心问题**:
- 市场是在增长、稳定还是萎缩？
- 行业周期位置如何（强周期/弱周期/成长）？
- 什么长期趋势有利或不利？

**输出要求**:
- 用"爆发增长/平稳发展/增长放缓/行业不景气"描述市场状态
- 标注"顺风"（🌬️）或"逆风"（🌬️）
- 列出2-3个关键趋势（利好🌬️或利空🌬️）
- 判断行业处于导入期/成长期/成熟期/衰退期

**详细指南**: 见 [references/industry-background.md](references/industry-background.md)

### 8. 竞争格局

分析行业主要玩家，对比各家公司实力。

**核心问题**:
- 竞争对手都有谁？
- 定价权谁更牛？
- 产品实力谁更强？
- 规模谁更大？
- 竞争壁垒谁更硬？
- 本公司明显胜出或落后的地方？

**输出要求**:
- 列出3-5家主要竞争对手及市场份额
- 对比定价权（毛利率）、产品实力、规模、竞争壁垒
- 用五维评分表给各家公司打分（定价权15%、产品25%、规模20%、壁垒25%、增速15%）
- 明确指出本公司的竞争优势和劣势
- 综合评估竞争地位（领导/强者/中游/追赶/落后）

**详细指南**: 见 [references/competition-pattern.md](references/competition-pattern.md)

### 9. 财务质量

分析近年财务质量，识别财务健康度和风险点。

**核心问题**:
- 收入增长一致性如何？
- 利润率稳不稳定？
- 债务水平安不安全？
- 现金流强不强劲？
- 资本配置合不合理？

**输出要求**:
- 列出近5年营收增速并判断稳定性（稳健/不稳/疲软）
- 分析毛利率/净利率趋势（优质/一般/较差/恶化）
- 判断资产负债率和流动比率（健康/正常/偏高/危险）
- 计算经营现金流/净利润比值，判断现金含金量
- 分析研发投入和分红策略
- 识别财务陷阱（利润虚高/并购增长/高杠杆推ROE等）
- 给出综合评分（0-100分）

**详细指南**: 见 [references/financial-quality.md](references/financial-quality.md)

### 10. 风险与下行提示

识别公司的最大风险点，评估风险等级。

**核心问题**:
- 业务风险是什么？（客户/产品/市场/技术/价格/产能）
- 财务风险在哪里？（债务/现金流/应收/存货/盈利）
- 监管威胁有多大？（政策/合规/贸易）
- 什么因素会永久性伤害业务？（技术颠覆/人口结构/消费升级/渠道变革）

**输出要求**:
- 列出2-4个关键业务风险点，评估严重程度（致命/高危/需关注/一般）
- 识别财务风险指标（如有），说明风险持续时间
- 列出1-3个主要监管风险
- 列出1-3个可能永久伤害业务的因素
- 用四维评分体系给风险打分（业务25%、财务25%、监管25%、永久25%）
- 给出综合风险评分（0-100分）和风险等级（低风险0-30/中等31-50/高风险51-70/高危71-100）
- 明确"硬伤"（致命风险）和"软肋"（拖后腿）

**详细指南**: 见 [references/risk-downside.md](references/risk-downside.md)

### 11. 管理层团队与执行提示

评估管理团队的历史表现和决策质量。

**核心问题**:
- 过去执行情况如何？（战略、重大投资、风险控制、资本效率）
- 他们的决策如何影响长期股东？（投资理性、并购、融资、业务调整）
- 长期业绩表现如何？（股价、市值、营收增长、股东回报）
- 治理结构是否健康？（股权、董事会、高管稳定性、激励机制）
- 薪酬与激励是否合理？（高管薪酬、股权激励、利益一致性）

**输出要求**:
- 评估过去5-10年的战略执行兑现度、投资回报效率
- 分析重大投资决策的理性程度（并购、扩产、研发）
- 判断风险事件应对能力，评估资本配置效率（ROIC）
- 分析3-5年股价/市值相对表现（跑赢/跑输大盘）
- 评估股权结构、董事会独立性、高管团队稳定性
- 分析高管薪酬水平和股权激励方案的合理性
- 计算长期股东回报率（分红+股价增值）
- 用六维评分体系给管理层打分（战略执行20%、决策质量15%、风险控制15%、长期业绩20%、治理结构15%、股东回报15%）
- 给出综合评分（0-100分）和管理质量评价（优秀/良好/一般/较差/差）
- 识别管理层的红旗警示信号（追热点、并购失败、利益输送等）

**详细指南**: 见 [references/management-execution.md](references/management-execution.md)

### 12. 牛熊情景提示

阐述未来3-5年这只股票的现实牛市和熊市情景。重点关注基本面，而非价格预测。

**核心问题**:
- 这家公司长期靠什么赚钱？（销量增长/成本优化/技术壁垒/政策红利）
- 未来3-5年行业环境如何？（需求扩张/平稳/萎缩）
- 公司自身能改善哪些基本面？（利润率/成本控制/ROE/客户结构）

**输出要求**:
- 判断公司的长期盈利驱动类型
- 评估未来3-5年行业环境（需求/供给/竞争/技术变革）
- 识别公司基本面可改善空间
- 提供三种情景推演（牛市、中性、熊市）
- 分别给出牛市、中性、熊市情景下的基本面预测、驱动因素、风险提示和投资逻辑
- 标注情景概率（牛市60%-80%、中性60%、熊市60%-80%）

**详细指南**: 见 [references/bull-bear-scenarios.md](references/bull-bear-scenarios.md)

### 13. 估值思考提示

解释投资者如何评估这家公司。什么假设最重要，什么会合理化更高或更低的估值？

**核心问题**:
- 这家公司适合用什么估值方法？（PE、PB、PS、DCF、PEG等）
- 估值中枢是多少？（2-3种方法加权）
- 什么是最关键的假设？（增长率、WACC、永续增长率）
- 市场当前预期是什么？（机构目标价、一致预期）
- 什么因素会推高或压低估值？（行业景气、业绩超预期、竞争格局变化）
- 估值的安全边际有多大？（内在价值-市价）

**输出要求**:
- 选择并解释主要估值方法（2-3种）及理由
- 计算2-3种方法的估值中枢并给出加权估值（合理价格区间±10%）
- 列出2-4个最关键假设并评估敏感性（±10%对估值的影响）
- 总结市场当前一致预期（机构目标价中位数、预期差）
- 分析3-5个主要推高/压低估值因素
- 计算安全边际（内在价值-市价）/内在价值
- 识别常见估值陷阱（增长/价值/周期/杠杆/故事）
- 给出估值建议（低估/合理/高估）和投资建议（买入/持有/卖出）

**详细指南**: 见 [references/valuation-thinking.md](references/valuation-thinking.md)

### 14. 长期论点提示

帮助我形成长期投资论点。总结为什么这可能是好投资，什么必须成功，什么信号表明我错了。

**核心问题**:
- 为什么这可能是一笔好投资？（投资逻辑分类）
- 这家公司长期靠什么赚钱？（长期盈利驱动）
- 什么必须成功才能兑现投资逻辑？（成功因素排序）
- 什么信号表明投资逻辑可能错了？（危险信号识别）

**输出要求**:
- 确定投资逻辑类型（价值/成长/质量/反转/平台）
- 判断公司的长期盈利驱动类型（销量增长/成本优化/技术壁垒/政策红利）
- 评估未来3-5年行业环境（需求/供给/竞争/技术变革）
- 推演三种情景（牛市/中性/熊市）并分别给出投资逻辑
- 列出3-5个"必须成功"的关键因素并按重要性排序
- 列出2-5个关键危险信号并判断严重程度
- 给出长期持有理由（3年/5年/10年维度）
- 给出止损条件（出现X个危险信号必须减仓或清仓）

**详细指南**: 见 [references/long-term-thesis.md](references/long-term-thesis.md)

## 分析框架

### 基本面分析要素

| 维度 | 关注点 | 数据来源 |
|------|--------|----------|
| **盈利能力** | 营收增速、净利润增速、ROE | 财报搜索 |
| **成长性** | 过去3年CAGR、行业增速 | 财报+行业数据 |
| **估值水平** | PE、PB、PEG、机构目标价 | 机构研报 |
| **财务健康** | 资产负债率、现金流、应收账款 | 财报数据 |
| **竞争优势** | 客户结构、技术壁垒、市场份额 | 公司资料+行业分析 |
| **风险因素** | 原材料价格、政策风险、竞争格局 | 新闻追踪 |

## 工作流示例

### 完整分析流程

```
用户: "分析一下宁德时代"
↓
1. 搜索基本信息: "宁德时代 300750 主营业务 客户"
↓
2. 搜索财务: "宁德时代 财报 业绩 盈利"
↓
3. 搜索新闻: "宁德时代 最新新闻 动态"
↓
4. 整合分析:
   - 提取关键数据
   - 识别投资逻辑
   - 列出风险点
   - 评估估值
   - 推演牛熊情景
   - 构建长期论点
   - 列出止损/加仓条件
   - 检查长度并拆分（如超3000字节）
↓
5. 输出分析报告
```

## 注意事项

1. **数据时效性**: 优先获取最近一周的新闻和最新财报
2. **信息交叉验证**: 多个来源交叉确认关键数据
3. **客观中立**: 避免强烈买入/卖出建议，提供分析框架和风险提示
4. **合规要求**: 不构成投资建议，仅作信息整理和分析
