# 投资组合分析框架

## 概述

ETF与投资组合分析采用**7维度方法**，系统评估投资组合。

## 7个分析维度

### 第1步：资产配置拆解
- 行业配置（>30%集中风险）
- 地理暴露（美国 vs 国际）
- 市值分布（大盘/中盘/小盘）
- 风格暴露（成长/价值/混合）

### 第2步：持仓分析
- 前10大持仓及权重
- 重叠分析（重复股票）
- 个股集中度（>10%风险）

### 第3步：风险指标
- 组合Beta（相对标普500）
- 年化波动率
- 最大回撤（10年）
- 夏普比率
- 持仓相关性

### 第4步：成本分析
- 加权平均费用率
- 规模成本（1万/5万/10万）
- 替代品对比

### 第5步：收益分析
- 综合股息率
- 预计年度收入
- 股息增长率

### 第6步：压力测试
- 2008金融危机表现
- 2020疫情暴跌
- 2022熊市表现
- 恢复时间

### 第7步：优化建议
- 3个具体可执行建议
- 解决的问题
- 代价评估

## 关键风险阈值

| 指标 | 风险阈值 | 评估 |
|------|---------|------|
| 单一行业 | >30% | 过度集中 |
| 单一国家 | >50% | 地缘风险 |
| 单一股票 | >10% | 个股风险 |
| Beta | >1.3 | 高风险 |
| 波动率 | >25% | 高波动 |
| 最大回撤 | >-40% | 高风险 |
| 夏普比率 | <0.5 | 风险调整后收益差 |

## 费用影响

### 费用侵蚀
- 0.03% vs 0.28%：10年差异 = 2.5%
- 复利效应：10万投资，年费$280 vs 年费$30

### 成本优化
1. 选择低费率ETF（被动指数型）
2. 避免频繁交易
3. 批量购买降低佣金
4. 考虑税务效率（ETF vs 共同基金）

## 压力测试要点

### 关键时期
- 2008：金融系统性危机
- 2020：黑天鹅事件
- 2022：加息周期

### 评估指标
- 最大跌幅
- 恢复速度
- 与标普500对比
- 防御能力评估
