# 行业对比分析框架

## 概述

行业对比分析采用**4维度方法**，系统评估行业内竞争格局。

## 4个分析维度

### 第1步：建立对比表格
- 市值、营收、利润率
- 估值指标（P/E、P/S、PEG等）
- 财务健康（债务、现金流）
- 行业关键指标（用户数、销量）

### 第2步：竞争定位
- 竞争壁垒（Moat）
- 市场份额排名
- 份额变化趋势

### 第3步：风险对比
- 最大单一风险
- 债务风险
- 竞争风险

### 第4步：排名与结论
- 最具价值标的
- 增长潜力最高
- 最安全选择
- 综合赢家

## 对比原则

1. **同一时间段**：所有公司数据时间一致
2. **相同准则**：统一会计准则
3. **统一计算**：相同计算方法
4. **明确缺失**：N/A标注

## 关键指标

### 估值指标
- P/E：市盈率
- Forward P/E：预期市盈率
- P/S：市销率
- EV/EBITDA：企业价值倍数
- PEG：增长调整估值

### 财务健康
- 资产负债率
- 净负债
- 自由现金流
- FCF收益率

### 行业特定
- 科技：活跃用户、订阅用户
- 零售：同店销售、客流量
- 制造：产能、销量
- SaaS：ARR、流失率
