## 🎯 方案对比

### 方案 1：微信官方接口（服务号）

**限制**：
- 需要认证服务号（300 元/年）
- 需要模板消息权限
- 每天 1 次推送
- 严格的内容审核

**优势**：
- 官方稳定
- 到达率高
- 不容易被封号

**劣势**：
- 成本高（认证费）
- 限制多（频率、内容）
- 申请流程复杂

### 方案 2：企业微信（WeCom）

**限制**：
- 需要企业认证（300 元/年）
- 可以主动推送
- 支持富媒体

**优势**：
- 推送限制少
- 功能强大
- 可以内部使用

**劣势**：
- 需要企业资质
- 成本较高

### 方案 3：群机器人（微信机器人 API）

**技术**：
- 使用微信机器人接口
- 自动回复和主动推送
- 需要开发者账号

**优势**：
- 门槛低（个人可注册）
- 支持消息推送
- API 相对开放

**劣势**：
- 机器人功能受限
- 不支持公众号内容
- 推送有频率限制

### 方案 4：第三方平台

**候选平台**：
1. **智齿** - 客服系统，支持多渠道
2. **容联七陌** - 多渠道消息平台
3. **阿里云消息服务** - 短信、邮件、推送
4. **腾讯云消息** - 短信、邮件、推送

**优势**：
- API 统一
- 接入简单
- 稳定可靠

**劣势**：
- 需要额外费用
- 依赖第三方

### 代码示例：企业微信 API

```python
import requests
import json

# 企业微信 API 配置
CORP_ID = "your_corp_id"
CORP_SECRET = "your_corp_secret"
AGENT_ID = "your_agent_id"
ACCESS_TOKEN = "get_access_token()"

# 发送消息
def send_wechat_message(user_id, content):
    url = "https://qyapi.weixin.qq.com/cgi-bin/message/send"
    data = {
        "touser": user_id,
        "msgtype": "text",
        "text": {
            "content": content
        },
        "agentid": AGENT_ID,
        "safe": 0
    }
    params = {
        "access_token": ACCESS_TOKEN,
        "debug": 1
    }
    
    response = requests.get(url, params=params, json=data)
    return response.json()

# 获取 Access Token
def get_access_token():
    url = "https://qyapi.weixin.qq.com/cgi-bin/gettoken"
    params = {
        "corpid": CORP_ID,
        "corpsecret": CORP_SECRET
    }
    
    response = requests.get(url, params=params)
    return response.json()['access_token']
```

## 🛠️ 常见问题和解决方案

### 问题 1：推送失败（Access Token 过期）

**原因**：Access Token 有效期 2 小时

**解决方案**：
```python
# 每次发送前刷新 Token
ACCESS_TOKEN = get_access_token()
```

### 问题 2：消息过长（3000 字节限制）

**解决方案**：
- 使用消息拆分工具
- 每条不超过 3000 字节
- 标注"第 X 条/共 Y 条"

### 问题 3：推送频率限制

**解决方案**：
- 每条消息之间等待 3-5 秒
- 避免短时间内大量推送

### 问题 4：内容审核失败

**解决方案**：
- 避免敏感词
- 不违反平台规则
- 提供明确的来源链接
